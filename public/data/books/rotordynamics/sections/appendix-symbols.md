## この本の約束事

記号そのものより、**符号と単位の取り決め**のほうが、本を読み違える原因になります。本書では次のように決めています。

- **回転の速さは二つの書き方を使い分けます。** 式の中では角速度 [[Omega|Ω]]（rad/s）、計測やスペクトルの話では回転周波数 [[f_rot|f_rot]]（Hz、毎分回転数 rpm を 60 で割った値）です。Ω = 2π f_rot の関係にあり、どちらも同じ回転を指します。
- **回転数比 r は、回転数を固有振動数で割ったものです。** [[r_ratio|r]] = Ω/ω_n で、r = 1 は「回転数が固有振動数に一致する点」です。外部加振の節だけは、r の分子が加振振動数になります。応答の山は正確には r = 1 ではなく、不釣り合い応答（分子が r² の式）では r = 1 のわずかに上、一定の力で揺らす外力応答や伝達率ではわずかに下に立ちます。減衰が小さいほど、どちらも r = 1 に近づきます。
- **次数は「回転数を 1 とする物差し」です。** [[order_1x|1×]] は回転と同じ速さ、2× はその 2 倍、0.43× は回転より遅い成分を指します。横軸を Hz でなく次数で読むと、回転数が変わっても原因の住所が動きません。
- **振れ回りの向きは、回転と同じ向きが前向き、逆が後ろ向きです。** 翼振動の章では、進行波の向きを翼間位相角 [[IBPA|σ]] の符号で表し、**σ > 0 を後ろ向き**と決めています。文献によって符号の取り方が逆のものがあるので、他書と見比べるときは注意してください。
- **励起次数の折り返しは、符号付きで書きます。** 励起次数 k を翼数 N で折り返した [[q_signed|q]] は、絶対値が節直径、符号が進行波の向きを表します。
- **減衰の大きさは三つの顔を持ちます。** 減衰比 [[zeta|ζ]] が基本で、共振の鋭さを表す [[Q|Q 値]] と、規格が半値幅で定義する増幅係数 [[AF|AF]] は、軽い減衰の孤立した一つのモードでは Q ≈ AF ≈ 1/(2ζ) と結ばれます。定義は別物なので、強い減衰や近接したモードでは一致しません。
- **安定判定の q と c は無次元で比べます。** クロスカップリング剛性 [[q|q]] と減衰係数 [[c|c]] は単位が違うので、部品では q̂ = q/k と ĉ = c/(mω_n) にそろえて比べています。

## 単位の読み方

振動の大きさは、何を・どの量で・どう丸めたかを添えて初めて意味を持ちます。

- **軸の変位**は μm で、ふつう **p-p（peak-to-peak、全振幅）**で言います。「50 μm p-p」は、軸心が往復で 50 μm 動くという意味で、片振幅なら 25 μm です。
- **軸受台の振動**は mm/s で、ふつう **rms（[[rms|実効値]]）**で言います。「4.5 mm/s rms」は、速度波形の 2 乗平均の平方根です。正弦波なら片振幅の 1/√2 になります。
- 変位・速度・加速度は同じ振動の三つの顔で、周波数 f の正弦振動なら速度は変位の 2πf 倍、加速度はさらに 2πf 倍です。どの量で測るかで、低い周波数と高い周波数のどちらが目立つかが変わります（計測の章の「何で測るか」を参照）。
- **釣り合い品質等級** [[G|G]] の単位は mm/s です。許容できる残留偏心と角速度の積で、G2.5 なら e_per × Ω = 2.5 mm/s です。
- 応力は MPa、周波数は Hz、角振動数は rad/s、位相 [[phi|φ]] は式では rad、図では度で表示します。

## ギリシャ文字の早見

本文で使う文字だけを挙げます。読みは本書での呼び方です。

- Ω（オメガ、大文字）＝回転角速度。ω（オメガ、小文字）に添字 n を付けた ω_n が固有角振動数。
- ζ（ゼータ）＝減衰比。
- φ（ファイ）＝位相。重い点と揺れの向きのずれ。
- σ（シグマ）＝文脈で三つの意味があります。安定性の章では成長率、翼振動の章では翼間位相角、疲労の節では添字付きで応力（σ_m 平均応力、σ_a 応力振幅、σ_e 疲労限度、σ_u 引張強さ）。
- γ（ガンマ）＝円板の扁平さ（極慣性と直径慣性の比）。ジャイロ効果の強さ。
- α（アルファ）＝影響係数（複素数）。昇速の節の無次元昇速率とは別物。
- κ（カッパ）＝遠心剛性化の係数。
- ε（イプシロン）＝部分噴射率。すべり軸受の節の偏心率も同じ文字を使いますが、部品の中で定義しています。
- θ（シータ）＝角度。ねじり振動の章ではねじれ角、転がり軸受の式では接触角。
- Δ（デルタ、大文字）＝差。Δf は周波数の目盛り間隔。

## 記号の衝突と使い分け

本が大きくなると、同じ文字が別の意味で使われる場面が出てきます。本書では次のように線を引いています。

- **N は翼の枚数**です（[[N_b|N]]）。転がり軸受の転動体の数には Z を使い、歯車の歯数にも Z を使います。
- **q は二つあります。** 軸受と安定性の章の q はクロスカップリング剛性、翼振動の章の q は符号付き折り返し次数です。ポップの説明で区別できます。
- **c も二つあります。** 減衰係数の c と、すべり軸受の半径すきま c_r です。
- **k は軸の硬さ**ですが、翼振動の章では励起次数（Engine Order）にも k を使います。励起次数の k には必ず「次数」と添えています。
- **σ の三つの意味**は上の早見のとおりです。
