# 波は正弦波の足し算でできている

![グランドピアノのアクションとハンマー](data/books/rotordynamics/images/fourier-synthesis-1.jpg "写真：グランドピアノのアクション（ハンマーの列）。ハンマーが弦を叩くと、弦は基本の音と一緒にたくさんの倍音を同時に鳴らす。（Wikimedia Commons, Rhona-Mae Arca, CC BY 2.0）"){right}

ピアノで「ラ」の鍵盤を押すと、弦は 1 秒に 440 回の往復で揺れます。フルートで同じ「ラ」を吹いても 440 回です。それなのに、目を閉じていてもピアノとフルートは聞き分けられます。高さは同じなのに、何が違うのでしょう。違うのは**音色**で、音色の正体は「基本の 440 Hz に、その 2 倍・3 倍・4 倍の速さの小さな波がどんな割合で混ざっているか」という**配合**です。ピアノとフルートでは、この配合が違います。

振動の測定でも同じことが起きています。回転機械の揺れを測ると、たいてい波形はごちゃっとしていますが、[[link:spectrum|スペクトル]]に直すと、きれいに分かれた何本かのピークになります。それができるのは、**どんな波も正弦波の足し算でできている**という、フーリエの考え方があるからです。この章では、その考え方を手を動かしながら掴みます。この節はまず「足し算で波を作る」側、次の節で「足し算をほどく」側を見ます。

出発点は、にわかには信じがたい一つの主張です。**どんなにギザギザした波も、なめらかな正弦波の足し算だけで作れる**。角張った矩形波を、丸い波だけで？ 本当にできるのか、確かめてみましょう。

1 本目は、ただの正弦波。2 本目、**3 倍の速さで揺れる小さな正弦波**を足すと、山がつぶれて肩が張り出します。3 本、4 本と足すほど、平らな天井とスパッと切れた壁ができていく。魔法のようですが、種はただの**足し算**です。

:::analogy @piano 音色は、倍音の配合表
ピアノの弦を一本はじくと、弦は全体で一つの山になって揺れるだけでなく、真ん中に節を持って二つの山で揺れる動き、三つの山で揺れる動きも**同時に**起こしています（右の図）。山が二つなら速さは 2 倍、三つなら 3 倍。耳にはこれらが混ざって届き、混ざり方の違いが音色の違いになります。ピアノの「ラ」とフルートの「ラ」は、同じ 440 Hz の土台の上に、違う配合の倍音を載せた音です。上のブロックで「本数」を増やしていく操作は、音色を一つずつ足していく操作と同じことです。限界：理想の弦なら倍音は端の固定条件で整数倍になりますが、実際のピアノ弦は曲げ剛性のためにわずかに高い側へずれます（インハーモニシティ）。そして回転機械の揺れに混ざる成分は整数倍とは限らず、回転数と無関係な固有振動数の成分も混ざります。
:::

## 下の棒グラフが「スペクトル」の正体

![弦の基本振動と 2 倍・3 倍の倍音](data/books/rotordynamics/images/fourier-synthesis-2.jpg "イメージ図（生成画像・模式）：一本の弦が、山一つ・山二つ・山三つで揺れる三つの形。節を臙脂の点で示した。"){right}

このブロックの下半分に出ている棒グラフは、**レシピ**です。「何次の正弦波を、どれだけ入れるか」という配合表で、各成分の大きさと位相（符号）がそろっていれば、波形はそこから再現できます。つまり、**波形とレシピは、同じ情報の二つの顔**なのです。なお、このブロックの棒は各成分の大きさ（係数の絶対値）だけを示していて、符号は棒には出していません。のこぎり波と三角波では符号が一本おきに反転しています。

- **時間波形**：波を「時間の流れ」で見た顔。
- **スペクトル**：同じ波を「配合表」で見た顔。

どちらか一方があれば、もう一方は作れます。レシピから波形を作るのが**合成**（この節）、波形からレシピを読み取るのが**分解**（[[link:dft-probe|次の節]]）。振動診断とは、測った波形からレシピを読み取り、**どの成分が誰の仕業か**を突き止める仕事です。

:::analogy @mixing-bowl 料理とレシピ
出来上がった料理を一口食べて「砂糖がこれだけ、塩がこれだけ」と言い当てるのは難しい。でもレシピを見れば一目です。波形は出来上がった料理、スペクトルはレシピ。同じものを表していますが、「何が入っているか」を知りたいときはレシピの顔で見たほうが早い。フーリエの考え方が強いのは、どんな料理にも必ずレシピが存在し、しかも料理からレシピを**逆算する手順**が決まっているからです。限界：料理は材料を混ぜると化学変化で別の味になることがありますが、線形な振動では成分どうしが混ざっても互いを変えません。この「混ざっても変わらない」が、分解が成り立つ条件です。
:::

## レシピには個性が出る

![オシロスコープに映る三角波と矩形波](data/books/rotordynamics/images/fourier-synthesis-3.jpg "写真：オシロスコープの画面に映る三角波（上）と矩形波（下）。角の鋭さが、レシピの裾の長さの違いになる。（Wikimedia Commons, Xato, CC0）"){right}

波の種類を切り替えると、レシピの形がまるで違うことに気づきます。

- **矩形波**：奇数次だけが入り、振幅は $1/k$ でゆっくり減る。高い次数までしぶとく残る。**角が鋭い波ほど、高い成分を多く含む**。
- **のこぎり波**：すべての次数が入る。回転機械では歯車のかみ合いなど、周期的な「引っかかり」がこの系統の波を作ります。
- **三角波**：奇数次だけ、振幅は $1/k^2$ で急減。数本でほぼ完成する。頂点は尖っていますが値は飛ばず、傾きだけが跳ぶ波です。**値そのものが飛ぶ波に比べ、低い成分だけでほぼ描ける**。

「波形のとがり具合」と「スペクトルの裾の長さ」が結びついている。この感覚は、実測スペクトルを読むときの勘所になります。一般の周期波を式で書くと、

$$f(t) = a_0 + \sum_{k=1}^{\infty}\left(a_k \cos k\omega t + b_k \sin k\omega t\right)$$

です。言葉にすると、周期 $2\pi/\omega$ で繰り返す波は（ふつうの条件を満たすものなら。値が飛ぶ点では左右の値の中点に収束します）、「平均の高さ $a_0$」に「基本の速さ $\omega$ の正弦波」「その 2 倍の速さの正弦波」「3 倍…」を、それぞれ決まった量 $a_k, b_k$ だけ足したものとして書ける、ということです。$\cos$ と $\sin$ が両方あるのは、各成分の**大きさ**だけでなく**位相**（どこで山が来るか）も指定する必要があるからです。この $a_k, b_k$ の表がレシピで、レシピを棒グラフにしたものがスペクトルです。

:::analogy @prism プリズムと「スペクトル」という言葉
白い光をプリズムに通すと、赤から紫までの帯に分かれます。ニュートンはこの帯を spectrum と呼びました。白く見えていた光が、実はたくさんの色（波長）の混合だった。音や振動の「スペクトル」という言葉は、ここから借りたものです。ごちゃっとした波形が、実は何本かの正弦波の混合だった、と分けて見せる道具がフーリエのプリズムです。限界：光のスペクトルは物理的に分かれて見えますが、振動のスペクトルは計算で取り出す「配合表」で、測定の仕方（切り取り方や点の間隔）によって見え方が変わります。それがこの章の後半の主題です。
:::

## 回転機械では、誰が倍音を作るのか

ピアノの倍音は弦の形が作りました。回転機械では、[[order_1x|1×]]（回転と同じ速さ）の成分は、重い点が一周に一度だけ外へ引っ張る**不釣り合い**が作ります。理想的には素直な正弦波なので、レシピは 1× の一本が主役です。では 2×、3× は誰が作るのでしょう。

答えは「一周に一度は繰り返すが、形が正弦波ではない力」です。たとえば軸心のずれた継手は、一周のあいだに二度、軸を押したり引いたりするので、典型的には 2× が立ちます（1× や軸方向の成分、さらに高い次数を伴うことも多く、条件で変わります）。軸が何かに軽く触れると、触れている間だけ波形が削られて角ができ、角ができれば矩形波と同じ理屈で高い次数がずらりと並びます。歯数 $N$ の歯車は一周に $N$ 回のかみ合いの衝撃を作るので $N$× が、翼数 $N_b$ の羽根車は一周に $N_b$ 回の圧力の脈動を作るので [[N_b|翼数]]倍の成分が立ちます。[[link:blade-excitation|翼を叩く手]]として見たノズル後流の話と同じ構図です。

つまり、**レシピを読めば「一周に何回」の出来事かが分かる**。ただし一本のピークだけで原因が確定するわけではなく、ピークは候補を絞る手がかりです。これがスペクトル診断の土台で、[[link:fault-signatures|故障の指紋]]の節で一覧にします。

:::history Fourier、熱の理論から「どんな関数も三角関数の和」へ
Joseph Fourier（1768〜1830）は、ナポレオンのエジプト遠征に同行し、帰国後はグルノーブルで県知事を務めながら、固体の中を熱がどう伝わるかを研究しました。1807 年にパリの学士院へ提出した論文で、彼は熱の伝わり方の方程式を解くために「どんな初期温度の分布も三角関数の和で書ける」と主張します。審査にあたった Lagrange らは、この表現がどこまで一般に成り立つのか、その証明と意味に異議を唱えました。三角関数の和は、Lagrange 自身がかつて弦の振動の問題で論争した題材です（Lagrange が級数そのものを全面的に否定していたのかは、科学史の研究で見方が分かれています）。学士院は 1811 年に熱の伝導を懸賞問題にし、Fourier の論文が受賞しますが、審査は「厳密さと一般性」に注文を付けました。彼の理論が本の形になったのは 1822 年の『熱の解析的理論』で、1807 年の提出から 15 年後のことです。三角関数の和がどこまで「どんな関数」を表せるかという問いは、19 世紀の数学を長く動かし続けました。
:::

![Joseph Fourier の肖像](data/books/rotordynamics/images/fourier-synthesis-4.jpg "図版：Joseph Fourier（1768〜1830）。Boilly の素描に基づく版画。（Wikimedia Commons, パブリックドメイン）"){small}

:::history 80 本の正弦波を足す機械と、Gibbs の飛び越し
上のブロックで本数を増やしても消えなかった「角のそばの飛び越し」には名前があります。1898 年、Albert Michelson は Samuel Stratton と共に、80 本までの正弦波を機械的に足し合わせて波形を描く**調和解析器**を発表しました。ばねとてこで 80 個の成分を同時に動かし、合計をペンで紙に描く装置です（下の図は、その論文に載った矩形波の近似の例）。同じ年、Michelson は Nature 誌に「正弦波の和で不連続な関数を表せるという主張はおかしい」と手紙を書き、翌 1899 年にかけて J. Willard Gibbs が返事を寄せて、「級数の和の極限」と「グラフの極限」は別物であり、角のそばには部分和の本数を増やしても消えない一定の飛び越しが残ることを示しました。この飛び越しは 1906 年に Bôcher が「Gibbs 現象」と名付け、実はそれより半世紀前の 1848 年に Henry Wilbraham が見つけていたことも後に分かります。よく語られる「Michelson の機械が飛び越しを描いて見せた」という逸話は、機械の精度ではそこまで鮮明には出なかったという指摘があり、本書では採りません。
:::

![Michelson と Stratton の調和解析器が描いた矩形波の近似](data/books/rotordynamics/images/fourier-synthesis-5.jpg "図版：Michelson と Stratton の 1898 年の論文に載った、正弦波の本数を増やしながら矩形波に近づけていく記録。（Wikimedia Commons, パブリックドメイン）"){small}

:::field 「角が立つ波は高い成分を含む」の、現場での意味
実測の波形に鋭い角やとがったピークが見えたら、それは「高い周波数の成分がたくさん混ざっている」と宣言しているのと同じです。その成分を正しく測るには、センサがそこまで速い揺れに追従でき、計測器の点の間隔がそこまで細かい必要があります（[[link:aliasing|サンプリングの罠]]）。逆に、スペクトルの高い側に成分が整然と並んでいるのに波形はなめらかに見える、ということもあります。小さな衝撃が繰り返す転がり軸受の損傷がその典型で、波形では埋もれていてもレシピには現れます。波形とレシピを**両方**見るのが、診断の作法です。
:::

:::deep 式で言うと：三つの波のフーリエ級数
周期 $2\pi$ の波 $f(t)$ は、正弦波の無限和で書けます（フーリエ級数）。上のブロックの三つの波は、

$$\text{矩形波} = \frac{4}{\pi}\left(\sin t + \frac{\sin 3t}{3} + \frac{\sin 5t}{5} + \cdots\right)$$

言葉にすると、矩形波は基本の正弦波に、3 倍・5 倍・7 倍と奇数倍の正弦波を、1/3・1/5・1/7 の大きさで足したものです。

$$\text{のこぎり波} = \frac{2}{\pi}\left(\sin t - \frac{\sin 2t}{2} + \frac{\sin 3t}{3} - \cdots\right)$$

言葉にすると、のこぎり波はすべての整数倍を 1/k の大きさで、符号を交互に変えながら足したものです。

$$\text{三角波} = \frac{8}{\pi^2}\left(\sin t - \frac{\sin 3t}{9} + \frac{\sin 5t}{25} - \cdots\right)$$

言葉にすると、三角波は奇数倍だけを、1/k² というずっと速く小さくなる大きさで足したもので、数本でほぼ形が決まります。係数の減り方（$1/k$ か $1/k^2$ か）が「レシピの裾の長さ」を決めています。一般の波では係数を**どう求めるか**が問題になりますが、それが次の節のテーマ、「探りの正弦波を掛けて平均する」です。

**ギブス現象**：不連続な角のそばでは、何本足しても、飛びの幅の約 9%（正確には 8.95%）の飛び越しが残ります。−1 から +1 へ飛ぶ振幅 1 の矩形波なら飛びの幅は 2 なので、ピークは 1 を約 0.18 超えて約 1.18 になります。本数を増やすと飛び越しは**細く**なりますが**低く**なりません。上のブロックは部分和を式どおり計算しており、この飛び越しも本物です。
:::

## この章の見取り図

フーリエの目で振動を読むために、この章では次の順で進みます。

- 波は正弦波の足し算でできている（この節）。**合成**の体感。
- [[link:dft-probe|周波数を取り出す仕組み]]。**分解**は「探りの正弦波との内積」。
- [[link:aliasing|サンプリングの罠]]。ストロボで回るロータが止まって見える話。
- [[link:leakage|窓とリーケージ]]。波形の「切り取り方」がスペクトルを汚す。
- [[link:resolution|分解能と平均化]]。時間と細かさの取引。
- [[link:order-reading|回転機械ならではの読み方]]。次数の物差しと回転同期平均。

## ひとことで

- どんな周期的な波も、基本の正弦波とその整数倍の正弦波の足し算で作れる。配合表（係数の表）がレシピで、レシピを棒グラフにしたものがスペクトル。
- 波形とスペクトルは同じ情報の二つの顔。「何が入っているか」を知りたいときはスペクトルの顔で見る。
- 値が飛ぶ波ほど高い次数まで成分が残る。値が飛ばず傾きだけが跳ぶ波は、低い成分だけでほぼ描ける。
- 回転機械では、一周に一度の素直な力はおもに 1× を作り、一周に何度も押す力や、形が削られた力が 2×、3×、N× を作る。ピークは原因の候補を絞る手がかりで、それだけで確定はしない。
- 角のそばの飛び越し（Gibbs 現象）は本数を増やしても消えない。
