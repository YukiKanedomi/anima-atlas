# 波は正弦波の足し算でできている

第6章では、振動をスペクトルに分解して原因を探しました。でも、そもそも**なぜ、どんな波でも周波数に分解できる**のでしょうか。この章では、スペクトルの土台にある**フーリエの考え方**そのものを、手を動かしながら掴みます。

出発点は、にわかには信じがたい一つの主張です——**どんなにギザギザした波も、なめらかな正弦波の足し算だけで作れる**。

1本目は、ただの正弦波。2本目——**3倍の速さで揺れる小さな正弦波**——を足すと、山がつぶれて肩が張り出します。3本、4本と足すほど、平らな天井とスパッと切れた壁ができていく。魔法のようですが、種はただの**足し算**です。

## 下の棒グラフが「スペクトル」の正体

このブロックの下半分に出ている棒グラフは、**レシピ**です。「何次の正弦波を、どれだけ入れるか」——この配合表さえあれば、波形は完全に再現できます。

つまり、**波形とレシピは、同じ情報の二つの顔**なのです。

- **時間波形**：波を「時間の流れ」で見た顔。
- **スペクトル**：同じ波を「配合表」で見た顔。

[[link:spectrum|第6章のスペクトル]]でやった「分解」は、この逆向きの操作です。合成が「レシピ→波形」なら、分解は「波形→レシピ」。振動診断とは、測った波形からレシピを読み取り、**どの成分が誰の仕業か**を突き止める仕事でした。

## レシピには個性が出る

波の種類を切り替えると、レシピの形がまるで違うことに気づきます。

- **矩形波**：奇数次だけが入り、振幅は $1/k$ でゆっくり減る。高い次数までしぶとく残る——**角が鋭い波ほど、高い成分を多く含む**。
- **のこぎり波**：すべての次数が入る。回転機械では歯車のかみ合いなど、周期的な「引っかかり」がこの系統の波を作ります。
- **三角波**：奇数次だけ、振幅は $1/k^2$ で急減。数本でほぼ完成する——**角が丸い波は、低い成分だけでほぼ描ける**。

「波形のとがり具合」と「スペクトルの裾の長さ」が結びついている——この感覚は、実測スペクトルを読むときの勘所になります。

:::deep 式で言うと——フーリエ級数
周期 $2\pi$ の波 $f(t)$ は、正弦波の無限和で書けます（フーリエ級数）。上のブロックの3つの波は：

$$\text{矩形波} = \frac{4}{\pi}\left(\sin t + \frac{\sin 3t}{3} + \frac{\sin 5t}{5} + \cdots\right)$$

$$\text{のこぎり波} = \frac{2}{\pi}\left(\sin t - \frac{\sin 2t}{2} + \frac{\sin 3t}{3} - \cdots\right)$$

$$\text{三角波} = \frac{8}{\pi^2}\left(\sin t - \frac{\sin 3t}{9} + \frac{\sin 5t}{25} - \cdots\right)$$

係数の減り方（$1/k$ か $1/k^2$ か）が「レシピの裾の長さ」を決めています。一般の波では係数を**どう求めるか**が問題になりますが、それが次節のテーマ——「探り正弦波を掛けて平均する」です。

**ギブス現象**：不連続な角のそばでは、何本足しても波高の約 9%（振幅 1 の矩形波でピーク約 1.18）の飛び越しが残ります。本数を増やすと飛び越しは**細く**なりますが**低く**なりません。上のブロックは部分和を式どおり計算しており、この飛び越しも本物です。
:::

## この章の見取り図

フーリエの目で振動を読むために、この章では次の順で進みます。

- 波は正弦波の足し算でできている（この節）——**合成**の体感
- 周波数を取り出す仕組み——**分解**は「探り正弦波との内積」
- サンプリングの罠——エイリアシング。ストロボで回るロータが止まって見える話
- 窓とリーケージ——波形の「切り取り方」がスペクトルを汚す
- 分解能と平均化——時間と細かさの取引

**模式・出典について**：本節の図は模式ではなく、フーリエ級数の部分和を式どおり計算した**厳密な描画**です（収束・ギブスの飛び越し≈1.179 を独立検証済み）。級数の係数は標準的なフーリエ級数展開によります。
