# 振幅と位相を1枚に——ボード線図とポーラ線図

![大型タービンの軸受台に取り付けたセンサ](data/books/rotordynamics/images/bode-polar-2.jpg "イメージ図（生成画像・模式）：大型蒸気タービンの軸受台。軸受ふたの上に非接触プローブの取付け金具、台の側面に加速度計（臙脂）を置いた様子。昇速試験では、これらの信号を回転数とともに連続記録する。"){right}

新しく据え付けた圧縮機や、分解点検を終えた発電機のタービンは、いきなり定格で回しません。止まった状態からゆっくり回転を上げ、各回転数で振動の**大きさ**と**位相**を記録していきます。これが**昇速試験**で、[[link:sensors|前の節]]の変位プローブとキーフェイザがあって初めてできる試験です。

記録は回転数ごとの「振幅と位相の組」の列になります。この列をどう絵にするかで、見えるものが変わります。代表が**ボード線図**と**ポーラ線図**で、同じデータの違う見せ方です。この節では二つの図を触りながら、「位相が 180° 反転する」「山の幅から減衰が読める」「ループの向きが重い点を指す」という、現場で毎日使われる三つの読み方を身につけます。

## ボード線図：振幅と位相を縦に2段

いちばん素直なのは、横軸に回転数をとって、**振幅**と**位相**を上下に並べること。これがボード線図です。

下で **r（回転数）** を動かしてみてください。カーソルが両パネルを走査します。

- **振幅**は固有振動数との一致点（$r=1$）のすぐ近くで山。[[link:natural-frequency|はじめの一歩]]の共振曲線そのものです（山の頂上は厳密には $r=1$ よりわずかに上の $1/\sqrt{1-2\zeta^{2}}$ にあり、$\zeta=0.1$ なら 1.01、減衰が大きいほど離れます）。
- **位相**は、低速の $0°$ から高速の $180°$ へ、$r=1$ で**ちょうど $90°$** を通る S字。[[link:phase-lag|位相の話]]で見た遅れが、回転数の関数として見えています。

この図の位相は、**重い点の向きを 0° に置いた理論の遅れ**です。実測のボード線図では位相の基準がキーフェイザの切り欠きなので、低速の値は 0° とは限らず、プローブの取付け方位や信号の極性ぶんの一定のずれが乗ります。それでも「低速の値から 90° 動いた点が固有振動数との一致点、通り過ぎれば 180°」という**変化量**は変わりません。振幅の山が多少なまっていても、位相のほうがくっきり危険速度を指してくれる、という現場の知恵はここから来ています。

## なぜ位相は 180° 反転するのか

位相の S 字は、不釣り合い応答の式から出てきます。回転数比 $r$ と減衰比 $\zeta$ で、振幅 $M$ と遅れ $\varphi$ は

$$M(r) = \frac{r^{2}}{\sqrt{(1-r^{2})^{2} + (2\zeta r)^{2}}}, \qquad \tan\varphi = \frac{2\zeta r}{1-r^{2}}$$

です。言葉にすると、「分母の $1-r^{2}$ は、ばねの復元力と慣性力の差。低速では復元力が勝って振れは重い点と同じ側（遅れ 0°）、高速では慣性が勝って反対側（遅れ 180°）。ちょうどつり合う $r=1$ では減衰だけが残り、遅れは 90°」ということです。減衰 $\zeta$ が小さいほど切り替わりは急で、大きいほどなだらかな S 字になります。

:::analogy @swing ブランコを押すタイミング
ブランコをゆっくり押したり引いたりすれば、座板は押す力の向きにそのまま付いてきます。力が前向きに最大のとき、座板は前端にいる。ちょうど固有の周期で押すと、座板は力より四分の一周期遅れます。力が前向きに最大の瞬間、座板は中央を前へ最速で通過していて、前端に着くのはその四分の一周期あとです。もっと速く押そうとすると、座板は力と逆向きに動きます。力が前向きに最大のとき座板は後端。これが 0°、90°、180° の三段階で、ボード線図の位相パネルはこの三段階を回転数の順に並べた絵です。限界：ブランコでは押す人が周期を変えますが、ロータでは回転数が上がるにつれて不釣り合いの力の周期が変わっていきます。また、ここで比べているのは「力」と「座板の位置」で、手の位置そのものではありません。
:::

## 山の幅から減衰を読む

![地上振動試験で翼に貼られた加速度計](data/books/rotordynamics/images/bode-polar-3.jpg "写真：NASA の試験機 F/A-18 の地上振動試験。主翼の上面に多数の加速度計が貼られている。構造の固有振動数と減衰を測る試験で、減衰は応答の山の幅から読む。（NASA Dryden, Tom Tschida, パブリックドメイン）"){right}

ボード線図の振幅の山は、高さだけでなく**幅**にも情報があります。山の頂上を $M_{\max}$ として、高さが $M_{\max}/\sqrt{2}$（約 0.707 倍）になる両側の回転数を $N_1$、$N_2$、頂上の回転数を $N_c$ とすると、減衰が小さいとき

$$\mathrm{AF} = \frac{N_c}{N_2 - N_1} \approx \frac{1}{2\zeta}$$

です。言葉にすると、「山の幅が頂上の回転数の何分の一か」が**増幅係数** AF で、それは減衰比の 2 倍の逆数にほぼ等しい、ということです。幅が狭い鋭い山ほど AF は大きく、減衰は小さい。[[link:multi-critical|離隔余裕の節]]で見たとおり、API の規格はこの AF で「危険速度からどれだけ離れていればよいか」を決めます。昇速試験のボード線図は、その AF を実測する手段そのものです。

:::analogy @ruler 山の肩幅をものさしで測る
遠くから山を見て、頂上の高さだけでなく「肩の張り具合」を見ます。すそ野まで広がるなだらかな山と、針のように立った山では、同じ高さでもまるで違う。ボード線図の山で肩の幅を測るのが半値幅法で、幅が狭い山ほど減衰が小さく、危険速度の上で振幅が大きく膨らみます。限界：山が二つ近くに並んでいると肩が重なって幅が読めず、近い危険速度が二つあるロータでは別の方法（モード試験や曲線あてはめ）が要ります。
:::

:::deep 半値幅法の導出と、使える条件
振幅の 2 乗 $M^{2}$ が頂上の半分になる点が「半値幅」の名の由来です。$r = 1 \pm \delta$ とおいて小さな $\delta$ と $\zeta$ で展開すると、$M^{2}$ が半分になるのは $\delta \approx \zeta$ のときで、両側の幅は $2\zeta$、したがって $N_2 - N_1 \approx 2\zeta N_c$ となり AF $\approx 1/(2\zeta)$ が出ます。この近似が効くのは $\zeta$ が 0.1 程度以下のときで、減衰が大きいと山が低くなだらかになり、半値点そのものがはっきりしなくなります。なお、共振の鋭さを表す量としては [[Q|Q 値]]もあり、減衰が小さく他のモードから離れた一つの山であれば AF と Q はどちらも $1/(2\zeta)$ に近づきますが、AF は実測の半値幅で定義される規格上の量、Q はエネルギーの比で定義される一般の量で、常に同じ数ではありません。API 684 では、山がはっきりしないほど減衰が大きい場合（AF が 2.5 未満）は「危険速度とみなさない」という扱いになります。
:::

## ポーラ線図：振幅と位相を1枚に束ねる

![ポーラ線図のループ](data/books/rotordynamics/images/bode-polar-1.jpg "イメージ図（生成画像・模式）：ポーラ線図。各回転数の応答を長さと向きのベクトルとして描き、先端をつないだ軌跡がループになる。原点近くの短い矢印（臙脂）は低速の応答。"){right}

ボードが「振幅」と「位相」を別々のグラフにするのに対し、**ポーラ線図**はこの2つを**1枚の複素平面**にまとめます。各回転数での応答を、**長さ＝振幅・向き＝位相**のベクトルと見て、その先端の軌跡を描くのです。

下のポーラ線図の**再生**を押してください。回転数を上げていくと、応答ベクトルが原点から伸びて**輪のような軌跡**を描きます。そして**上のボード線図のカーソルも一緒に動きます**。同じ昇速を、2つの目で同時に見ているわけです。

:::analogy @clock 時計の針で振動を書く
ポーラ線図の各点は、時計の針のようなものです。針の長さが振幅、針の向きが位相。回転数を上げるにつれて針は長くなりながら回り、固有振動数との一致点の近くで最も長く、通り過ぎると縮みながらさらに回る。針の先端をつなぐと輪のような曲線になります。限界：時計の針は一定の速さで回りますが、この針は固有振動数の近くで急に回り、離れたところではほとんど回りません。また輪は閉じません。回転数を上げきった先で針は原点に戻らず、重い点と反対側の一定の長さ（偏心そのもの）に落ち着きます。
:::

2つは同じ `link` グループでつながっているので、**ポーラの再生でボードのカーソルが走り**、**どちらの ζ スライダーを動かしても両方が変わります**。表現は違っても、中身は一つの応答だと体で分かります。

:::deep ベクトルの長さと向きが、振幅と位相そのもの
ポーラ線図の各点は、複素応答ベクトルの先端です。

$$Z(r) = \frac{r^2}{(1-r^2) + i\,2\zeta r} = M(r)\,e^{-i\varphi(r)}$$

言葉にすると、「分母の実部 $1-r^{2}$ が符号を変える瞬間に、ベクトルは実軸の片側から反対側へ渡る。その途中、$r=1$ で分母が純虚数になり、ベクトルは真下を向く」ということです。

- **長さ** $|Z| = M(r) = r^2/\sqrt{(1-r^2)^2+(2\zeta r)^2}$ ＝ ボード上段の振幅。
- **向き** $-\varphi(r) = -\operatorname{atan2}(2\zeta r,\ 1-r^2)$ ＝ ボード下段の位相（遅れ）。

$r=1$ を入れると $Z = -i/(2\zeta)$。実部ゼロ・真下向きで長さ $1/(2\zeta)$。厳密に $r=1$ で起きるのは「位相 $90°$」と「長さ $1/(2\zeta)$」の二つです。振幅の山はそれより少し上の $r_p = 1/\sqrt{1-2\zeta^{2}}$ にあり、軌跡のいちばん低い点も同様にわずかに上へずれます。$\zeta = 0.1$ では $r_p = 1.01$ で三つはほぼ同じ瞬間ですが、$\zeta = 0.6$ では $r_p = 1.89$ とはっきり離れます。「位相 90° の点を固有振動数の目印にする」のは、減衰によらず $r=1$ を指すからです。$r \to \infty$ では $Z \to -1$、つまり軌跡は原点へは戻らず、重い点と反対向きの長さ 1（偏心と同じ振幅）へ収束する開いた曲線です。
:::

## スローロールを引く——ループの始点を原点に戻す

実機のポーラ線図は、原点から始まりません。[[link:sensors|前の節]]のランナウトがあるからで、低速でまだ振動していないのに、プローブは軸の形や表面のむらを「振幅と位相の組」として出してきます。ポーラ線図ではこれが原点からずれた**始点**として現れ、ループ全体がその分だけ平行移動します。

そこで低速の読み（スローロールのベクトル）を全点から引き算し、始点を原点へ戻してから読みます。これをしないと、軌跡全体の向きが狂い、[[link:balancing|重い点の角度]]を読み違えます。ボード線図でも同じ引き算をしますが、ポーラ線図は「始点が原点にあるか」を一目で確かめられるので、引き忘れに気づきやすい図です。

:::analogy @scale-weight 風袋引きをしてから量る
はかりに容器を載せたままゼロを合わせないと、中身の重さに容器の重さが足されます。スローロールの引き算はこのゼロ合わせで、ポーラ線図ではゼロ合わせを忘れると輪が原点からずれて見えるので、すぐ分かります。限界：容器の重さは変わりませんが、軸の形は温度で変わるので、暖機後にスローロールを取り直すことがあります。
:::

## どちらを使うか

- **ボード**は「どの回転数で何が起きたか」を読むのに強い。複数の危険速度があるとき、山と位相段差がいくつ並ぶかで本数が分かります。
- **ポーラ**は「危険速度の近くの振る舞い」と**バランシング**に強い。応答ベクトルは重い点の向きから回転数で決まる遅れ $\varphi$ ぶん（実測ではさらにキーフェイザとプローブの取付け角のぶん）回っているので、向きだけで重い点を直接当てることはできません。けれども試しおもりを付けたときのベクトルの**変化**を同じ図の上で読めば、その遅れごと測れて補正角が決まります。これが[[link:balancing|影響係数法]]で、ポーラ線図はその作業台です。

同じ昇速データを、ボードで「回転数の順に」、ポーラで「ベクトルとして」読む。この往復が、現場の振動診断の基本動作です。

:::field 昇速と降速、どちらの記録を信じるか
昇速試験は、駆動機のトルクや蒸気の流れが同時に変わる中での記録です。降速（コーストダウン）は駆動を切って惰性で回転が落ちていく間の記録で、外乱が少なく、ボード線図がきれいに出ることが多い。ただし降速は速く過ぎるので、記録間隔が粗くなりがちです。熱の影響にも注意が要ります。長く止めていたタービンの軸は自重でわずかに曲がり（熱的・重力的なボウ）、暖機の前後で 1× のベクトルが変わります。昇速で見えた「危険速度」が降速で位置を変えていたら、まず温度と軸受の状態を疑います。
:::

:::history Bode と Nyquist——通信の数学が回転機械へ
二つの図の名は、どちらもベル研究所の技術者に由来します。Harry Nyquist は 1932 年の論文「Regeneration Theory」で、増幅器の帰還が発振するかどうかを、周波数応答を複素平面に描いた曲線（ナイキスト線図）で判定する方法を示しました。Hendrik Wade Bode（1905〜1982）は 1938 年に、利得と位相を周波数の対数に対して折れ線で描く図法を考案し、1945 年の著書「Network Analysis and Feedback Amplifier Design」にまとめました。第二次大戦中は対空砲の自動照準装置の研究にも加わっています。

ロータ診断で使うボード線図とポーラ線図は、この二人の名を冠した図法と同じ形式（周波数に対する振幅と位相、複素平面上の軌跡）で描かれます。名前は制御工学から来ていますが、ロータ診断の図がどの経路で成立したかを示す一次資料は確認できておらず、ここでは「形式が同じ」という以上のことは言いません。そして中身は違います。制御工学のボード線図は横軸が対数の周波数で、ポーラ線図（ナイキスト線図）は帰還系の安定を判定するための図です。ロータの図は横軸が回転数で、描いているのは不釣り合いという「入力」に対する 1× の応答です。形は似ていても、ロータのポーラ線図を見て安定・不安定を判定するわけではありません。
:::

## ひとことで

- ボード線図は回転数に対する振幅と位相の二段。低速の値から位相が 90° 動いた点が固有振動数との一致点で、山がなまっていても位相はそこを指す。実測の位相は切り欠き基準なので、見るのは変化量。
- 位相が 0° から 180° へ反転するのは、復元力と慣性力の勝ち負けが固有振動数で入れ替わるから。減衰が小さいほど反転は急。振幅の山は r=1 のわずかに上。
- 山の幅から減衰が読める。AF = Nc/(N2 − N1) ≈ 1/(2ζ)。離隔余裕の規格はこの AF を使う。
- ポーラ線図は振幅と位相を一本のベクトルにし、先端の軌跡が輪のような開いた曲線になる。真下を向く点が r=1。向きだけで重い点は決まらず、試しおもりによる変化を読んで補正角を決める。
- スローロールのベクトルを引いてから読む。ポーラ線図なら始点が原点にあるかで引き忘れが分かる。

**模式・出典について**：両図ともジェフコット不釣り合い応答 $Z(r)=r^2/((1-r^2)+i2\zeta r)$ をそのまま描いた**模式**で、位相は重い点を 0° に置いた理論値、振幅・位相・軌跡の形はすべて式どおりです。ポーラ線図の縮尺は $\zeta$ ごとに軌跡が収まるよう自動で合わせているので、$\zeta$ を変えたときの絶対的な大きさの変化は図の上では見えません。2図は同一パラメータ（$\zeta$ と掃引中の $r$）を共有しています。半値幅法と AF の定義、AF が 2.5 未満なら危険速度とみなさない扱いは API 684（ロータダイナミクスのチュートリアル）に基づく一般的な記述で、[[link:multi-critical|離隔余裕の節]]と同じ定義です。Nyquist の 1932 年論文は Wikipedia「Nyquist plot」、Bode の経歴（1905〜1982 年、1938 年の図法、1945 年の著書、戦時の照準装置）は Wikipedia「Hendrik Wade Bode」によります。地上振動試験の写真は NASA Dryden（現 Armstrong）飛行研究センターの公開写真です。生成画像は「イメージ図」と明記し、事実を担わせていません。
