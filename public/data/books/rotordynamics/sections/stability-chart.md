# 安定の地図——q と c の綱引きを俯瞰する

![谷の球と丘の球の模式図](data/books/rotordynamics/images/stability-chart-1.jpg "イメージ図（生成画像・模式）：谷の底の球、丘の上の球、鞍の上の球を並べて描いた絵。安定・不安定・境目のイメージ。"){right}

[[link:whirl-instability|前々節]]では、ある q と c の組み合わせを1つ選んで、軌道が収束するか発散するかを見ました。いわば「いま立っている1地点の天気」です。でも設計者が本当に知りたいのは、**平面全体の地図**——どこが安全でどこが危険か、そして自分の機械が地図のどこに立っているか、です。

横軸に[[c|減衰 c]]、縦軸に[[q|クロスカップリング q]]をとった平面を考えます。前々節の結論「境目は q = c·ωₙ」は、この平面では**原点から伸びる1本の斜め線**になります。線の下側（q < c·ωₙ）が安定、上側（q > c·ωₙ）が不安定。たったこれだけで、あらゆる q と c の組み合わせの運命が1枚に描けてしまいます。なお部品は質量と剛性を 1 に無次元化してあるので、軸の目盛りは $\hat q = q/k$ と $\hat c = c/(m\omega_n)$ で、境界線は $\hat q = \hat c$ です。以下、本文で「q < c」と書くときはこの無次元量の意味です。

:::analogy @ball-hill 地図は「谷」と「丘」の境目を描いたもの
谷の底の球はつついても戻り、丘の上の球は転げ落ちます。安定の地図の斜め線は、ロータという球が「谷」に置かれているか「丘」に置かれているかの境目です。線のすぐ近くは、谷が浅いか丘が低い場所で、戻るにしても転げ落ちるにしてもゆっくりです。線から離れるほど、谷は深く（素早く収束）、丘は高く（素早く発散）なります。限界：本物の谷や丘は目に見えますが、ロータの「地形」は軸受やシールの流れが作るもので、運転中に刻々と形を変えます。
:::

## 設計とは、運転点を安定域の奥に置くこと

この地図の見方がわかると、[[link:whirl-instability|前々節]]で挙げた対策が、すべて**地図上の移動**として読めるようになります。

- **ダンパ軸受・スクイーズフィルムダンパ**：[[c|減衰 c]] を増やす＝運転点を**右へ**動かす。境界線から遠ざかります。
- **スワールブレーキ**：シール内の旋回流を弱めて [[q|クロスカップリング q]] を減らす＝運転点を**下へ**動かす。
- **ティルティングパッド軸受**：パッドが首を振るため、固定形状の軸受より**交差連成剛性 q が大幅に小さい**。運転点を地図の**ずっと下**へ動かす、最も根本的な一手です（支点位置や荷重の向きによってゼロにはなりません）。
- **固有振動数を上げる**：地図には現れませんが、境界 q = c·ωₙ の ωₙ を上げることなので、縦軸の目盛りを引き伸ばすのと同じです。[[link:oil-whirl-whip|SSME の燃料ターボポンプ]]で「軸と軸受支持を硬くした」のは、この移動でした。

大事なのは、境界線ぎりぎりの安定では足りないこと。運転条件が変わればロータは地図の上を動きます。負荷が上がれば q は育ち（アルフォード力は出力に比例します）、油温が変われば c も変わる。だから設計では、想定される変動があっても境界を踏まないよう、**余裕（ĉ − q̂、次元つきなら c·ωₙ − q）を持たせて**運転点を安定域の奥に置きます。上のブロックの「境界までの余裕」は、その距離感をつかむための読み出しです。

:::analogy @tightrope 綱渡りの綱は、足の幅より広くしておく
綱渡りの綱が足の幅ぴったりなら、風が吹いただけで落ちます。綱を板のように広くしておけば、少しよろけても踏み外しません。安定の地図で「余裕を持たせる」とは、綱を広くすることです。負荷の変動、油温の変化、部品の摩耗で運転点はよろけます。よろけても境界を踏まない幅が、設計の余裕です。限界：綱の幅は目で見えますが、ロータの余裕は計算と計測で推定するしかなく、q の値そのものに大きな不確かさがあります。
:::

## 余裕を数字で言う——対数減衰率

![減衰する波形と育つ波形の模式図](data/books/rotordynamics/images/stability-chart-2.jpg "イメージ図（生成画像・模式）：振幅がしだいに小さくなる波形と、しだいに大きくなる波形を並べ、それぞれの包絡線を破線で描いた絵。"){right}

「境界までの余裕」を実務で表す数が、**対数減衰率** $\delta$ です。揺れを一発叩いて放したとき、隣り合う山の高さの比の自然対数をとったものです。

$$\delta = \ln\frac{X_{i}}{X_{i+1}} = -\frac{2\pi\,\sigma}{\omega}$$

言葉にすると、「隣り合う山の振幅の比の自然対数で、成長率 σ が負（安定）なら正の値、σ が正（不安定）なら負の値になる。境界線の上では、ちょうどゼロ」ということです。1 周期あたりの減り方そのものは $1 - e^{-\delta}$ で、$\delta = 0.1$ なら約 9.5% ずつ減ります。地図の破線は σ の等値線であって、$\delta = -2\pi\sigma/\omega$ の $\omega$ も地図上で少しずつ変わるため、δ の等値線とは厳密には一致しません。ω がほぼ一定の範囲では、おおむね対応すると考えてください。

:::field 規格は「δ が 0.1 以上」を目安にする
圧縮機の規格 API 617（ここでは 2002 年の第 7 版の枠組み）は、ロータの安定性を二段階で審査します。第一段階（Level I）では、Alford の式を改めた簡易式で各段のクロスカップリングを見積もり（$Q_A$）、それをロータモデルに入れて対数減衰率 $\delta_A$ を計算します。さらに $Q_A$ を増やしていって不安定になる値 $Q_0$ も求め、$Q_0/Q_A$ が 2 未満、$\delta_A$ が 0.1 未満、または危険速度比と平均ガス密度が所定の領域に入る、のいずれかに当たると、シールの流体力まで含めた詳しい第二段階（Level II）の解析に回されます。Level II の受入基準は、最終的な対数減衰率 $\delta_f$ が 0.1 を超えることです。δ = 0.1 という値は、共振時の増幅率にすると 30 倍ほどに相当する、かなり減衰の小さい状態です。つまり規格の線は「ここまで来たら要注意」の線であって、設計者は通常もっと奥に運転点を置きます。移行条件の細部は版で変わるので、適用するときは契約で指定された版を確認してください。
:::

:::history Lund、1974 年——地図を計算で描けるようになった日
安定の地図を「1 自由度の式」ではなく実機のロータで描くには、油膜の 8 つの係数とロータの柔軟性をまとめて固有値を解く必要があります。デンマーク出身で Mechanical Technology Inc. にいた J. W. Lund は 1974 年、油膜軸受に支えられた柔軟ロータの減衰固有値（複素固有値）を伝達行列法で求める方法を発表しました。固有値の実部が成長率 σ、虚部が振れ回りの振動数で、これは上の地図を実機で描く計算そのものです。以後、設計者は「危険速度」だけでなく「減衰危険速度と対数減衰率」で機械を評価するようになり、今日の規格の審査方法もこの系譜の上にあります。
:::

:::deep 地図の中身——固有値の実部を等高線にする
複素座標の運動方程式 $m\ddot z + c\dot z + (k - i\,q)\,z = 0$（$m=k=1$）の前向き固有値は

$$\lambda = \frac{-c + \sqrt{c^2 - 4 + 4qi}}{2}$$

で、実部 $\sigma = \mathrm{Re}\,\lambda$ が成長率です。言葉にすると、「減衰 c は固有値を左（安定側）へ押し、クロスカップリング q は根号の中の虚数部を通じて右（不安定側）へ引き戻す」ということです。振幅は $e^{\sigma t}$ で変わるので、$\sigma$ の符号が安定・不安定を分けます。地図の破線は $\sigma$ が一定の等値線で、$\sigma$ を与えると

$$q = (c + 2\sigma)\sqrt{1 + \sigma c + \sigma^2}$$

という曲線になります。言葉にすると、「同じ成長率を保つには、減衰を増やした分だけクロスカップリングを許せる。境界付近では両者はほぼ一対一」ということです。$\sigma = 0$ を代入するとちょうど $q = c$（無次元量で）——境界線は「成長率ゼロの等高線」だったわけです。境界の近くで一次近似すると $q - c \approx (2 + c^2/2)\,\sigma$、つまり $c$ が小さい範囲では $\sigma \approx (q - c)/2$ と、境界からの距離にほぼ比例します。等高線が境界線とほぼ平行に並ぶのはこのためで、「余裕 c − q」がそのまま減衰の速さの目安になります。
:::

## ひとことで

- 減衰 c とクロスカップリング q の平面に引いた斜め線 q = c·ωₙ が、谷と丘の境目。設計とは運転点をこの線から遠い谷側に置くこと。
- 対策はすべて地図上の移動として読める。ダンパは右へ、スワールブレーキとティルティングパッドは下へ、軸を硬くするのは縦軸の目盛りを伸ばすこと。
- 余裕は対数減衰率 δ で数えられ、規格は δ ≥ 0.1 を目安にする。運転点は負荷や油温でよろけるので、綱は足幅より広くしておく。

**模式・出典について**：地図は1自由度（複素）のクロスカップリング・モデル $m\ddot z+c\dot z+(k-iq)z=0$ を $m=k=1$ に無次元化したものです。境界 $q=c\,\omega_n$、[[sigma|成長率 σ]] と等値線はすべて固有値の式どおりで、作図上の誇張はありません。実機では q も c も回転数や負荷とともに変わるため、地図上の「点」は運転中に動く——その動きを見込んで余裕をとるのが安定性設計です。API 617 の Level I／Level II と δ の目安 0.1、増幅率 30 倍の対応は、以下の解説資料によります（規格本文は有償のため直接は参照していません）。Lund 1974 は ASME J.
