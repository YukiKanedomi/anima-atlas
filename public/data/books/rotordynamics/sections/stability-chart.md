# 安定の地図——q と c の綱引きを俯瞰する

[[link:whirl-instability|前節]]では、ある q と c の組み合わせを1つ選んで、軌道が収束するか発散するかを見ました。いわば「いま立っている1地点の天気」です。でも設計者が本当に知りたいのは、**平面全体の地図**——どこが安全でどこが危険か、そして自分の機械が地図のどこに立っているか、です。

横軸に[[c|減衰 c]]、縦軸に[[q|クロスカップリング q]]をとった平面を考えます。前節の結論「境目は q = c」は、この平面では**原点から伸びる1本の斜め線**になります。線の下側（q < c）が安定、上側（q > c）が不安定。たったこれだけで、あらゆる q と c の組み合わせの運命が1枚に描けてしまいます。

## 設計とは、運転点を安定域の奥に置くこと

この地図の見方がわかると、[[link:whirl-instability|前節]]で挙げた対策が、すべて**地図上の移動**として読めるようになります。

- **ダンパ軸受・スクイーズフィルムダンパ**：[[c|減衰 c]] を増やす＝運転点を**右へ**動かす。境界線から遠ざかります。
- **スワールブレーキ**：シール内の旋回流を弱めて [[q|クロスカップリング q]] を減らす＝運転点を**下へ**動かす。
- **ティルティングパッド軸受**：パッドが首を振って油膜力をつねに変位方向へ向けるため、**構造的に q がほぼゼロ**。運転点を地図の**いちばん下の縁**に置いてしまう、最も根本的な一手です。

大事なのは、境界線ぎりぎりの安定では足りないこと。運転条件が変わればロータは地図の上を動きます。負荷が上がれば q は育ち（アルフォード力は出力に比例します）、油温が変われば c も変わる。だから設計では、想定される変動があっても境界を踏まないよう、**余裕（c − q）を持たせて**運転点を安定域の奥に置きます。上のブロックの「境界までの余裕」は、その距離感をつかむための読み出しです。

:::deep 地図の中身——固有値の実部を等高線にする
複素座標の運動方程式 $m\ddot z + c\dot z + (k - i\,q)\,z = 0$（$m=k=1$）の前向き固有値は

$$\lambda = \frac{-c + \sqrt{c^2 - 4 + 4qi}}{2}$$

で、実部 $\sigma = \mathrm{Re}\,\lambda$ が成長率です。振幅は $e^{\sigma t}$ で変わるので、$\sigma$ の符号が安定・不安定を分けます。地図の破線は $\sigma$ が一定の等値線で、$\sigma$ を与えると

$$q = (c + 2\sigma)\sqrt{1 + \sigma c + \sigma^2}$$

という曲線になります。$\sigma = 0$ を代入するとちょうど $q = c$——境界線は「成長率ゼロの等高線」だったわけです。境界の近くでは $\sigma \approx (q - c)/2$ と、境界からの距離にほぼ比例します。等高線が境界線とほぼ平行に並ぶのはこのためで、「余裕 c − q」がそのまま減衰の速さの目安になります。
:::

**模式・出典について**：地図は1自由度（複素）のクロスカップリング・モデル $m\ddot z+c\dot z+(k-iq)z=0$ を $m=k=1$ に無次元化したものです。境界 $q=c\,\omega_n$、[[sigma|成長率 σ]] と等値線はすべて固有値の式どおりで、作図上の誇張はありません。実機では q も c も回転数や負荷とともに変わるため、地図上の「点」は運転中に動く——その動きを見込んで余裕をとるのが安定性設計です。
