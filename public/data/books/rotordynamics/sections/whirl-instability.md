# 軸受が振れ回りを発散させる——自励振動とクロスカップリング

発電所の監視室で、運転員がスペクトルの画面に見慣れないピークを見つけたとします。回転数の 1 倍（1×）の山は、不釣り合いの山としていつもあります。ところが今日はその左、1× の半分弱のところに、小さな山が立っている。回転数を少し上げると、その山はするすると育ち、やがて 1× を追い越す勢いで大きくなっていきます。ロータには何も当たっていないし、不釣り合いも変わっていない。それなのに揺れが**勝手に**育つ。

これまでの揺れは、不釣り合いという**外からの加振**に対する応答でした。回転数を上げても、共振の山を過ぎれば収まる。でもロータには、もっと厄介な揺れがあります。外から揺らさなくても、勝手に大きくなっていく揺れ。これが**自励振動（self-excited vibration）**で、その代表が[[link:journal-bearing|前の節]]の油膜が起こす**オイルホワール**です。この節では、油膜に限らず自励振動に共通する「からくり」を一つの式にまとめます。

犯人は、軸受やシールの中で生まれる**「変位に直角な力」**です。

ふつうのばねは、変位した向きに**引き戻す**力（直接剛性）を出します。ところが油膜やシール内の流れは、それに加えて**変位と直角な向き**の力を出す。これを**クロスカップリング剛性**（[[q|記号 q]]）と呼びます。[[link:journal-bearing|前の節]]で、荷重をかけた軸が真下ではなく斜めに逃げるのを見ました。押した向きと逃げる向きがずれる、あの油膜の非対称を、「軸を少し動かしたときに直角方向に生まれる力の係数」として表したのがクロスカップリングです。この横向きの力が、ロータを**回転と同じ向きに押し続け**、振れ回りにエネルギーを注ぎ込んでしまうのです。

:::analogy @swing 揺れの「進む向き」に、いつも手を添える
ブランコが手前に来るたびに押し返せば揺れは収まり、遠ざかる瞬間に背中を押せば揺れは育ちます。減衰は前者、クロスカップリングは後者です。油膜やシールの流れは、軸がどちらへ動いても、その動きの 90° 先を押すように働きます。振れ回る軸にとって「90° 先」とは、いま進んでいる向きそのものです。だから直角の力は、振れ回りの一周ごとに正味の仕事をして、エネルギーを注ぎ続けます。限界：ブランコでは押す人が向きを選びますが、軸受では流れが自動的に向きを決めてしまうので、回転している限り手を止められません。
:::

ポイントは、**減衰 c とクロスカップリング q の綱引き**だということ。q は変位あたりの力（N/m）、c は速度あたりの力（N·s/m）で単位が違うので、そのままでは比べられません。部品では質量と剛性を 1 に無次元化した $\hat q = q/k$ と $\hat c = c/(m\omega_n)$ を比べていて、次元つきで書けば境目は $q = c\,\omega_n$ です。

- **q̂ < ĉ**（q < c·ωₙ）：減衰が勝つ → 軌道は内へ収束。少々つつかれても揺れは収まる（安定）。
- **q̂ > ĉ**（q > c·ωₙ）：直角な力が勝つ → 軌道は外へ発散。何もしなくても揺れが育つ（**不安定**）。
- 境目は **q = c·ωₙ**。この一線を越えるかどうかが、安定性の分かれ目です。ちょうど境目の上では、揺れは育ちも減りもせず一定の振幅で回り続けます。

そしてこの模型で発散する振れ回りは、いつも**前向き**で、振動数は**ほぼ固有振動数 ωₙ**。回転数そのものではありません。一般に自励振動の周波数は不安定になった固有値の虚部で決まります。すべり軸受のオイルホワールだけは例外で、[[link:spectrum|計測と診断の章のスペクトル]]で見た **0.43×** のように回転数に追随して現れ、その周波数がロータの固有振動数に追いつくと、そこにロックして**オイルホイップ**に変わります（次の節）。高速ロータで代表的な自励（油膜のホワールとホイップ、シールの旋回流）はどちらも 1× より**遅い**所に現れやすいので、「1× より低い位置のピーク」を警戒するのは、この自励不安定を見つけるためでした。ただし向きに注意してください。「回転より遅い山があれば自励を疑う」であって、自励なら必ず回転より遅いというわけではありません（自励の周波数は不安定になった固有値で決まり、回転数との大小は一般には決まりません）。冒頭の運転員が見た「1× の左の山」が育っていったのは、q が c·ωₙ に勝った瞬間だったわけです。

## 不釣り合いの揺れとは、何が違うのか

:::analogy @ball-hill 丘の上の球と、谷の底の球
谷の底に置いた球は、つついても転がって戻ってきます。丘の上に置いた球は、ほんのわずかにつつくだけで転げ落ち、戻ってきません。不釣り合いによる揺れは「谷の底の球を外から揺さぶっている」状態で、揺さぶりの強さに応じた振幅で収まります。自励振動は「球が丘の上に置かれている」状態で、きっかけの大きさとは無関係に、系そのものが揺れを育てます。限界：丘の上の球は転げ落ちて終わりですが、ロータの自励振動は振幅が大きくなると油膜やすきまの非線形性で頭打ち（限界サイクル）になり、擦れながら回り続けることがあります。
:::

見分け方は三つあります。第一に**周波数**。不釣り合いの揺れは回転数の 1 倍ですが、自励振動は固有振動数（オイルホワールなら回転数の半分弱）で、1× とは一致しません。第二に**回転数への反応**。不釣り合いの揺れは危険速度を過ぎれば収まりますが、自励振動は始まったら回転数を上げても収まらず、むしろ育ちます。第三に**釣り合わせへの反応**。不釣り合いならバランス取りで小さくできますが、自励振動は Newkirk が 1925 年に確かめたとおり、どれだけ精密に釣り合わせても消えません（[[link:oil-whirl-whip|次の節]]）。

:::field 現場で自励振動を疑う三つの場面
第一に、暖機中や軽負荷のときだけ出る揺れ。油温が低く粘度が高いと油膜の性質が変わり、荷重が軽いと姿勢角が大きくなるので、油膜の q が効きやすくなります。第二に、出力や圧力を上げたとたんに出る揺れ。アルフォード力やシール力は仕事や圧力差に比例するので、アップレート後に 1× より低いピークが育ち始めたら、まずこれを疑います。第三に、釣り合わせをしても減らない揺れ。不釣り合いなら補正おもりで小さくなりますが、自励振動は Newkirk の模型と同じく、釣り合わせでは消えません。三つのどれかに当たったら、スペクトルで周波数が固有振動数に一致しているか、振れ回りが前向きかを確かめ、[[link:oil-whirl-whip|次の節]]の見分け方へ進んでください。
:::

## 同じ機構が、いろいろな顔で現れる

![ラビリンスシールの中の旋回流の模式図](data/books/rotordynamics/images/whirl-instability-1.jpg "イメージ図（生成画像・模式）：軸のまわりのラビリンスシールの断面。流体がシールの歯のあいだを旋回しながら通り抜ける様子と、入口に立てた小さな羽根（スワールブレーキ）を描いた絵。"){right}

クロスカップリング剛性 **q** は、ターボ機械のあちこちで生まれます。**犯人は違っても、数学は同じ**——どれも「q が減衰に勝つと前向きに発散」です。

- **オイルホワール／ホイップ**（すべり軸受）：油膜の周方向の流れが q を生む。最も古典的で、[[link:journal-bearing|前の節]]の姿勢角の裏返し。
- **シール力**（ラビリンス・バランスピストン）：旋回流（スワール）が q を生む。油がなくても、シールの中で軸と一緒に回る流体は油膜と同じ役をします。**スワールブレーキ**で旋回を弱めると安定化する。一方、シールの直接剛性（**Lomakin効果**）はむしろ安定化に働く。
- **アルフォード力／トーマス力**（動翼の先端すきま）：ロータが偏ると、すきまの狭い側の動翼が効率よく働き、**接線方向の力**＝q が出る。段の動力（トルク）に比例するので、**高出力機ほど危ない**（[[link:alford-force|この章の最後の節]]）。
- **軸の内部減衰**：軸の材料やはめ合い部の摩擦は、軸と一緒に回る座標系では普通の減衰ですが、静止系に書き直すと回転数に比例する「変位と直角の力」の成分が現れ、危険速度より上の回転数で q と同じ働きをします。Newkirk が油膜の前に見つけていた「はめ合いの食い込みによる振れ回り」がこれです。

:::deep なぜ「直角な力」が発散を生むのか
複素座標 $z=x+iy$ で書くと、クロスカップリング $q$ は剛性を**複素数**にします。

$$m\ddot z + c\dot z + (k - i\,q)\,z = 0$$

言葉にすると、「ふつうのばね $k$ は変位を引き戻すが、$-iq$ の項は変位を 90° 回した向き（振れ回りの進む向き）に押す力で、減衰 $c$ が速度に逆らう力と綱引きをしている」ということです。解を $z=Z\,e^{\lambda t}$（$\lambda=\sigma+i\omega$）と置くと、特性方程式は $m\lambda^2 + c\lambda + (k-iq)=0$。安定限界 $\sigma=0$（$\lambda=i\omega$）を入れると、

- 実部：$-m\omega^2 + k = 0 \Rightarrow \omega=\omega_n$（前向き、固有振動数で振れ回る）
- 虚部：$c\,\omega - q = 0 \Rightarrow q = c\,\omega_n$（安定限界）

$q$ がこれを超えると $\sigma>0$＝振幅が時間とともに $e^{\sigma t}$ で増える。直角な力が1回転ごとに正味の仕事をして、エネルギーを注ぎ込むからです。上の図は、この方程式を実際に数値積分（RK4）して描いています。
:::

## どう抑えるか

![ティルティングパッド軸受](data/books/rotordynamics/images/whirl-instability-2.jpg "写真：ティルティングパッド式のすべり軸受。パッドが個別に首を振るので、固定形状の軸受より直角の力（交差連成剛性）が大幅に小さい。（Wikimedia Commons, MariaSarah2024, CC BY-SA 4.0）"){right}

自励不安定への対策は、**綱引きを減衰側に傾ける**ことに尽きます。

- **減衰 c を増やす**（ダンパ軸受、スクイーズフィルムダンパ）。
- **クロスカップリング q を減らす**（ティルティングパッド軸受は固定形状の軸受より q を大幅に小さくできる。シールのスワールブレーキ）。
- 危険速度や運転点を、不安定が顔を出す回転数から**離す**。固有振動数を上げれば、ホイップの始まる回転数も上がります。

「測って・読んで・直す」が不釣り合いへの対処なら、自励不安定は**そもそも起こさない設計**で対処する——回転機械を高速・高出力にしていくほど、この安定性の見極めが効いてきます。綱引きを平面の地図にして俯瞰するのが[[link:stability-chart|安定の地図]]、犯人の一人の顔を見るのが[[link:alford-force|アルフォード力]]の節、そして実機で起きた二つの事件が[[link:oil-whirl-whip|次の節]]です。

:::history 1924 年の Newkirk と Kimball——「減衰が揺れを育てる」という逆説
自励振動の研究は、1924 年に General Electric の B. L. Newkirk が報告した、はめ合い部の食い込み（軸にきつく嵌めた円板やスリーブの摩擦）による振れ回りから始まります。同じ年に A. L. Kimball が、軸の内部摩擦が危険速度より上の回転数で揺れを育てることを理論的に示しました。回る軸と一緒の座標系では減衰であるものが、静止系から見ると「変位と直角の力」に化けるという逆説で、その翌年に Newkirk と Taylor が油膜による振れ回り（オイルホイップ）を見つけます。半世紀後の 1974 年、J. W. Lund が油膜軸受に支えられた柔軟ロータの減衰固有値を系統的に計算する方法を示し、安定性を設計段階で評価する道具が整いました。
:::

## ひとことで

- 自励振動は、外から揺らさなくても勝手に育つ揺れ。原因は軸受やシールが出す「変位と直角の力」（クロスカップリング q）で、振れ回りの進む向きを押し続けて仕事をする。
- 勝負は q と減衰 c の綱引き。q が c·ωₙ を超えると前向きに、固有振動数の近くで発散する（オイルホワールは回転数の半分弱で追随し、やがて固有振動数にロックする）。だから 1× より低い位置のピークを警戒する。
- 油膜・シール・翼先すきま・内部減衰と犯人は違っても数学は同じで、処方箋も同じ。q を減らし、c を足し、固有振動数を離す。

**模式・出典について**：図は1自由度（複素）のクロスカップリング・モデル $m\ddot z+c\dot z+(k-iq)z=0$ を RK4 で積分した**模式**です。安定限界 $q=c\,\omega_n$、前向き・$\omega\approx\omega_n$ はすべて式どおり。$q$ の物理的な出所（油膜・シール・空力）の係数値までは立ち入らず、機構の共通性を示すことに絞っています。歴史の記述は Newkirk 1924・Kimball 1924・Newkirk & Taylor 1925（General Electric Review）・Lund 1974（ASME J. Eng. Ind. 96, 509–517）によります。生成画像のシールは構造を模式的に描いたもので、特定機種ではありません。
