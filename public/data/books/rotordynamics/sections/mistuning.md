# 同じ翼は二枚とない——ミスチューニング

合唱団が同じ音を歌うとき、全員がぴったり同じ高さなら声はひとつに溶けます。ところが数人がほんの少し高く、数人がほんの少し低いと、うなりが生まれ、ある場所では声が妙に大きく聞こえます。翼付き円盤も同じです。図面上の翼は全部同じでも、削り出した翼の厚みや形、材料の弾性率には製造と材料のばらつきがあります。その結果、翼ごとの固有振動数が**数パーセント程度**ずれることがあります（量は製法や機種ごとの計測値によります）。たったそれだけで、前節までの「きれいな節直径モード」の世界が崩れ、**ある1枚の翼だけが、計算より何倍も大きく揺れる**ことが起きます。これが **ミスチューニング（mistuning）** です。

ここまでの章では、翼は全部同じ（**tuned**：調律された）という前提で、[[link:bladed-disk-nd|節直径]]や[[link:zzenf-reading|ZZENF線図]]を組み立ててきました。この節は、その前提が少し崩れたときに何が起きるかの話です。設計者が「ZZENFで共振は避けた。応力も計算した」と安心した後に、現場で1枚だけ割れる翼が出る——その正体がここにあります。

## なぜ「ばらつき」が「増幅」になるのか

![一体削り出しのブリスク](data/books/rotordynamics/images/mistuning-1.jpg "写真：一体削り出しのブリスク（圧縮機用、パリ航空ショー 2013 の展示品）。翼と円盤が一体なので翼根の摩擦がなく、ミスチューニングと減衰の両方で差込み翼と事情が違う。一般的な例で、ロケットのタービンではない。（Wikimedia Commons, Olivier Cleynen, CC BY-SA 3.0）"){right}

翼が全部同じとき、翼付き円盤のモードは[[link:bladed-disk-nd|節直径]]ごとにきれいに分かれます。節直径 $n$ の実際のモードは cos 型・sin 型の縮退した対ですが、これを複素進行波として組み合わせると、**全ての翼が同じ振幅**で揺れ、隣とは $2\pi n/N$ だけ位相が違う形になります。励起次数 $k$ の力は、[[link:eo-folding|折り返し]]で決まる1つの節直径 $n$ のモードだけを押し、他のモードには仕事をしません。振動のエネルギーは $N$ 枚の翼に均等に配られます。

ところが翼ごとの固有振動数がずれると、この「均等な配分」が成り立たなくなります。

- 節直径 $n$ の**二重根（同じ振動数の2つのモード）が分裂**し、それぞれが少しずつ違う振動数を持つようになります。
- 1つのモードの中に**複数の節直径成分が混ざり**、励起次数 $k$ の力が「本来押せないはずのモード」まで押せるようになります。
- 隣との結合が弱いと、モード形そのものが数枚の翼に**局在**（localization）します。1つのモードが「この翼とその両隣だけが大きく揺れる形」になるのです。

:::analogy @trampoline はねるリズムが少しずつ違う、トランポリンの輪
丸いトランポリンの輪に戻ります。全員の体重と膝のばねが同じ（＝はねるリズムが同じ）なら、一人がはね始めると、膜を通じてはねが隣へ、また隣へと伝わり、輪全体に広がります。リズムが同じ相手には動きを渡せるからです。ところが一人ひとりのリズムが少しずつ違うと、隣にうまく渡せません。動きは渡した先で受け取ってもらえず、**最初のあたりに溜まったまま**になります。これが「局在化」です。翼列では、叩く力は全部の翼にかかりますが、揺れのエネルギーが隣へ流れなくなった結果、流れの行き止まりになった翼に溜まります。

限界：この例えでは「渡せない」だけですが、翼列では分裂した多くのモードが重なり合うので、溜まる場所は乱数の引き方（個体）で変わります。ブロックの「振り直す」はそれを見るためのボタンです。
:::
結果として、特定の翼にエネルギーが集中し、その翼の振幅が tuned の最大値を超えます。この比を **ミスチューニング増幅率（mistuning amplification factor）** と呼びます（以下では単に増幅率と書きます。計測の章で共振の鋭さを表す「増幅係数 AF」とは別の量です）。

$$\text{増幅率} = \frac{\text{ばらついた翼列で最も揺れる翼の最大振幅}}{\text{全部同じ翼列の最大振幅}}$$

言葉にすると、同じはずの翼にばらつきが入ったとき、いちばん損をした一枚が、理想どおりの翼列の何倍まで揺れてしまうか、という比です。

下のブロックは、$N$ 枚の翼を1枚1自由度で表し、隣の翼とばね $\kappa_c$ でつないだ**周期鎖モデル**です。各翼の剛性に正規乱数のばらつき（標準偏差 $\sigma$）を与え、励起次数 $k$ の進行波パターンで押しながら励起振動数を掃引して、各翼の応答を**本当に連立方程式で解いて**います。上段は「最も揺れる翼の振幅」の周波数応答、下段は最悪の周波数での翼ごとの振幅です。

## 読み方：3つのつまみが効き方を決める

動かしてみると、増幅率を決めるのが「ばらつきの大きさ」だけではないことが見えてきます。

- **ばらつき σ**：0 から 1〜2% に上げると増幅率は急に立ち上がります。ところがさらに 4〜5% まで上げると、増幅率は**頭打ちか、むしろ下がる**ことが多い。ばらつきが大きすぎると翼どうしの振動数が離れすぎて「エネルギーをやり取りする相手」がいなくなり、各翼がばらばらに揺れる方向へ戻るからです。増幅が最も危ないのは**「少しだけばらついた」領域**です。
- **結合 κc**：結合が弱いほど局在化が強く、増幅率が上がります。シュラウドやレーシングワイヤで翼どうしをしっかりつなぐと、1枚にエネルギーが溜まる前に隣へ流れていきます。
- **減衰 ζ**：減衰が小さいほど分裂した各モードの峰が高く鋭くなり、周波数を掃引する途中で、局在した一つの峰が大きな応答を出しやすくなります。減衰が大きいと峰が低くなだらかになり、分裂の影響が見えにくくなります。

:::analogy @tuning-fork うなりは「少しだけ」違うときにしか起きない
二本のおんさが同じ高さなら、鳴らすと一つの音に溶けます。ほんの少しだけ高さが違うと「わーん、わーん」とうなりが聞こえます。うなりは、近い高さの二つの波が重なって、聞こえる大きさがゆっくり強弱する現象（干渉）です。ところが高さが大きく違うと、二つは別々の音として聞こえるだけで、うなりは起きません。翼列でも、固有振動数が「少しだけ」違い、しかも隣とばねでつながっている翼どうしが揺れを渡し合って一枚に寄せることがあり、大きく違う翼どうしはただ別々に揺れます。だから危ないのは「ほんの少しのばらつき」であり、ばらつきが大きくなると増幅率はむしろ頭打ちになります。

限界：おんさのうなりは聞く場所での干渉であって、二本の間でエネルギーが行き来しているわけではありません。翼列の局在化は「隣との結合より固有振動数の差が大きいとき、モードが少数の翼に偏る」という別の現象で、この例えと対応するのは「少しだけ違うときが危ない」という一点だけです。翼は何十枚もあり隣とばねでつながっているので、「渡し合いのしやすさ」が結合 κc、「寄った揺れがどこまで育つか」が減衰 ζ で決まります。
:::

つまり、**結合が弱く・減衰が小さく・少しだけばらついている**——この3拍子がそろったときが最悪です。そして、この3拍子がそろいやすい代表が、翼と円盤を1つの塊から削り出した **ブリスク（blisk：bladed disk の一体型）** です。翼の根元に差し込み（ダブテール）がないので摩擦減衰がほぼゼロ、翼どうしをつなぐシュラウドもないことが多い。ロケットターボポンプのタービンでも、小型・高速・軽量化のために一体型が選ばれることがあり、ミスチューニングの評価は設計の必須項目になります。

## どこまで増えうるのか——Whitehead の上限

「増幅率はいくらまで覚悟すればよいか」は、設計者にとって切実な問いです。これに最初の答えを出したのが D. S. Whitehead（1966）です。彼は1翼1自由度・結合弱・減衰小の仮定のもとで、ある対称なばらつきパターンが最悪を与えることを示し、増幅率の上限が

$$\text{増幅率} \le \frac{1 + \sqrt{N}}{2}$$

になると導きました（$N$ は翼の枚数）。1998年には同じ著者が「強制振動がミスチューニングで増えうる最大の係数」としてこの結果を再論しています。24枚なら約 2.95 倍、60枚なら約 4.37 倍。この式が**翼の枚数だけ**で決まるのが印象的です。「枚数が多いほど、1枚にエネルギーが集中したときの最悪が大きい」という直感に対応します。言葉にすると、「翼が多いほど寄せ集められる揺れの元が多い。ただし全部がそっくり一枚に集まるわけではなく、√N 程度にとどまる」という式です。

ただし、これは「最悪のパターン」を仮定した**保守的な上限**です。製造ばらつきを正規乱数で近似し、モンテカルロ（乱数で何百通りも試す）で得られる典型値は上限よりずっと小さい——上のブロックで「振り直す」を何度か押して、増幅率が上限に届かないことを確かめてください。その一方で、「上限そのものは何か」という問いには研究者の間でも長く議論があり、Martel と Corral は $N$ を「励起に関わる活性モードの数」に置き換える改良を提案しています。実務では、Whitehead の式を**安全側の目安**とし、具体的な設計はモンテカルロや縮約モデル（reduced-order model）で評価する、という進め方が一般的です。

:::deep 周期鎖モデルの式と、なぜ tuned は閉形式で解けるのか
翼 $j$（$j = 0, \dots, N-1$）の複素振幅を $x_j$ とし、翼単体の固有角振動数を 1、質量を 1 に規格化します。隣との結合ばねを $\kappa_c$、翼 $j$ の剛性ばらつきを $\delta_j$、減衰比を $\zeta$ とすると、励起次数 $k$ の進行波の力 $e^{i\phi j}$（$\phi = 2\pi k/N$）に対する調和応答は

$$\left[(1 + \delta_j) + 2\kappa_c - \omega^2 + i\,2\zeta\omega\right] x_j - \kappa_c\,(x_{j-1} + x_{j+1}) = e^{i\phi j}$$

言葉にすると、翼 j の揺れは、自分のばね（ばらつき込み）と減衰、両隣から引っ張られる力、そして進行波のパターンで押す力のつり合いで決まる、ということです。

です（添字は $N$ を法とする巡回）。

**tuned（$\delta_j = 0$）のとき**、解は $x_j = X e^{i\phi j}$ の形をとります。代入すると $x_{j-1} + x_{j+1} = X e^{i\phi j}(e^{-i\phi} + e^{i\phi}) = 2\cos\phi \cdot X e^{i\phi j}$ なので、

$$X = \frac{1}{1 + 2\kappa_c(1 - \cos\phi) - \omega^2 + i\,2\zeta\omega}$$

言葉にすると、翼が全部同じなら、隣から受ける力まで含めても「少し硬くなった一台のブランコ」と同じ応答になり、どの翼も同じ大きさで揺れる、ということです。

という**1自由度の応答そのもの**になります。共振振動数は $\omega_k = \sqrt{1 + 2\kappa_c(1-\cos\phi)}$ で、これが[[link:family-curves|モード族の曲線]]の最も単純な形（節直径が大きいほど硬く見える）です。全翼が同じ $|X|$ で揺れるのは、この閉形式が示すとおりです。

**mistuned のとき**は $\delta_j$ が翼ごとに違うので、$e^{i\phi j}$ の形は解になりません。$N \times N$ の複素連立方程式を各 $\omega$ で解く必要があり、ブロックはこれをガウス消去でそのまま解いています（$N \le 36$ なら一瞬です）。各翼の $|x_j|$ が不揃いになり、その最大値が tuned の $|X|$ を超えるのが増幅です。

**局在化と「弱い結合」**：$\kappa_c$ が $\delta_j$ の典型値より小さいとき、隣との結合で生まれる振動数の差（$\sim \kappa_c$）が翼どうしの振動数のずれ（$\sim \sigma$）に負けます。すると固有ベクトルは「ほぼ1枚の翼だけ」の形に近づく——Wei と Pierre（1988）がこの現象を周期構造の**モード局在化**として詳しく解析しました。固体物理の Anderson 局在と同じ数学構造です。
:::

## 意図的にばらつかせる——intentional mistuning

ここまで読むと「ばらつき＝悪」に見えますが、話はもう一段ひねれます。ばらつきを**わざと**、しかも**規則正しく**入れると、ランダムな製造ばらつきに対する感度を下げられるのです。

- **フラッタ抑制**：Kaza と Kielb（1981〜1984年、NASA Lewis）は、解析した翼列モデルでは翼の振動数ばらつきが[[link:flutter|フラッタ]]（自励振動）を**一貫して安定化させる**ことを示しました（空力モデルやばらつきの量によっては一般化できず、実機では固有値解析で確かめます）。フラッタは全翼が足並みをそろえて特定の翼間位相角で振動するときに起きるので、足並みを崩せば起きにくくなるのです。ただし強制応答への影響は励起次数によって有利にも不利にもなる、という注意つきです。
- **強制応答の感度低下**：Castanier と Pierre（2002）は、翼の剛性を周方向に正弦波状や矩形波状のパターンで**意図的に**変えた設計を調べ、ランダムばらつきに対する最悪応答の感度を大きく下げられる場合があることを示しました。ばらつきをある水準より大きくすると増幅率がかえって下がる（上で見た「頭打ち」）性質を、設計として使うわけです。

![ロンドンのミレニアム橋](data/books/rotordynamics/images/mistuning-3.jpg "写真：ロンドンのミレニアム橋。2000 年の開通直後、歩行者の足並みが橋の横揺れとそろって揺れが育ち、閉鎖して減衰器を追加した。「そろう」ことが揺れを育てる例。（Wikimedia Commons, Stephen Craven, CC BY-SA 2.0）"){small}

:::analogy @bridge 橋を渡るときは歩調を崩す
兵隊の隊列が橋を渡るとき、わざと歩調をそろえずに歩く、という決まりがあります。全員が同じリズムで足を踏み鳴らすと橋が共振しかねないからで、足並みを崩せばその危険は消えます。フラッタは「全翼が足並みをそろえて、ある翼間位相角で一斉に揺れる」ときに育つ自励振動なので、翼の固有振動数をわざと不ぞろいにして足並みを崩すと、育ちにくくなります。意図的ミスチューニングがフラッタに有利に働きやすいのは、この理屈です。

限界：強制振動（ノズルが叩く揺れ）に対しては、足並みを崩すことがかえって一枚への集中を招くこともあり、有利とも不利とも言えません。だから「規則正しいパターンで」入れ、縮約モデルで確かめるのです。
:::

実機では、翼を1枚おきに2種類（たとえば翼厚をわずかに変える）で並べる「A-B-A-B パターン」のような形で使われます。ただし効果はモード・励起次数・結合の強さに依存するため、縮約モデルによる評価と実測の確認が前提です。

![A-B-A-B の意図的ミスチューニングの模式図](data/books/rotordynamics/images/mistuning-2.jpg "イメージ図（生成画像・模式）：1 枚おきに翼厚を変える「A-B-A-B」の意図的ミスチューニング。臙脂が B 翼。"){small}

:::field 設計・製造・検査での実際
- **固有振動数の全数計測**：差し込み翼では、組立前に1枚ずつ固有振動数を測り、ばらつきの分布を記録します。ブリスクは翼を外して測れないので、全体の応答から翼ごとのばらつきを逆推定する「ミスチューニング同定」の手法が開発されています（Michigan 大学 Pierre・Castanier・Epureanu らの研究群）。
- **配列の最適化**：差し込み翼なら、測った固有振動数をもとに**翼の並び順**を選ぶことで最悪応答を抑える、という手法があります（高い翼と低い翼を隣り合わせにする、など）。
- **増幅率の見積もり**：設計応力に増幅率を掛けて疲労評価をします。保守的な上限（Whitehead）と、モンテカルロの統計値（たとえば 99 パーセンタイル）のどちらを使うかは、プロジェクトの安全係数の考え方次第です。日本機械学会の事例集 v_BASE には、9枚翼の過給機タービン翼車で翼ごとの応答が数倍の幅で散らばった計測例と、数パーセントの振動数ばらつきが応答の数倍の差を生むことの解析確認が収められています。
- **減衰の過大評価に注意**：解析で減衰をわずかに大きく仮定しただけで増幅率は劇的に下がって見えます。減衰の根拠（[[link:blade-damping|次節]]）を確認せずに「増幅率は小さい」と結論しないことが肝心です。
:::

## 対称性が崩れるときに起きること——ロータ全体との対比

実は、この本ですでに似た現象を見ています。[[link:anisotropy|支持のかたより]]の節では、軸受の硬さが縦横で違うだけで、1つだった危険速度が2つに分裂し、その間で後ろ向きの振れ回りが生まれました。**対称性が崩れると、縮退していたモードが分裂し、新しい応答の形が生まれる**——これはロータ全体でも翼列でも同じ原理です。違いは数です。ロータの異方性は2方向の話ですが、翼列は $N$ 枚ぶんの「ほんの少しずつ違う振動子」の集合で、分裂したモードが何十も重なり合う。その重なりが、1枚の翼への集中という形で現れるのです。

次の節では、翼の揺れを最後に押さえ込む手段——減衰とダンパ——を見ます。ミスチューニングの増幅率も、結局は「減衰が小さいから効く」のでした。減衰を正しく見積もり、足りなければ作り足す。それが実機の翼を守る最後の砦です。

## ひとことで

- 翼が一枚ずつほんの少し違うだけで、「全部が仲良く分担する」揺れ方が崩れ、揺れが一枚に溜まることがあります。
- 危ないのは「少しだけ」の不ぞろいで、結合が弱く減衰が小さいほどひどくなります。ブリスク（一体型）はこの三拍子がそろいやすい構造です。
- 最悪でどれだけ増えるかの目安が Whitehead の式（翼の枚数だけで決まる理想最悪値。弱い結合・小さな減衰・最悪のパターンを仮定した参考値）。わざと規則正しく不ぞろいにして、フラッタやばらつきへの感度を下げる設計もあります。
