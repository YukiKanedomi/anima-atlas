# 落ちないように制御する——PD・PID と位相進み

![磁気軸受の固定子と回転子](data/books/rotordynamics/images/amb-control-1.jpg "写真：NASA ルイス研究所の磁気軸受。磁極の内側に回転子が入り、外から見えないすきまをセンサが見張る。制御器が毎秒何千回も電流を更新して、この軸を浮かせ続ける。（Wikimedia Commons / NASA、パブリックドメイン）"){right}

[[link:amb-intro|前の節]]で、磁気軸受は「見て、直す」ことで浮くのだと分かりました。この節は、その「直す」の中身です。位置を見てどれだけ押し返すか、速さを見てどれだけ踏ん張るか、常に乗っている重さをどう支えるか。制御器の三つのつまみ、P・D・I の意味を、ほうきを手のひらで立てる感覚から始めて、閉ループの固有振動数と減衰比に翻訳します。

後半は、教科書どおりに行かない理由です。センサで見てから電流が流れて力になるまでには、わずかな遅れがあります。その遅れは高い周波数ほど効き、押し返したつもりが押し出す向きに変わる。そして軸はたわむので、曲げのモードが制御の帯域に入ると、センサの位置によっては軸受が揺れを育ててしまいます。磁気軸受の制御設計は、この「遅れ」と「たわみ」との付き合い方で決まります。

## ほうきを立てる手は、何を見ているか

![切断したターボ分子ポンプ](data/books/rotordynamics/images/amb-control-2.jpg "写真：切断模型のターボ分子ポンプ。段ごとに大きさの違う翼列の回転子が、下部の軸受に支えられて毎分数万回転で回る。磁気軸受化された製品では、この回転子を油もグリスもなしに浮かせる。（Wikimedia Commons, Liquidat, CC BY-SA 3.0）"){right}

ほうきの柄を手のひらに立てて倒れないように保つとき、手は何を見ているでしょう。ほうきが右へ傾けば、手を右へ出す。これは位置を見て押し返す動き、P です。ところが位置だけを見ていると、戻ってきた柄がそのまま左へ行きすぎる。上手な人は、柄が「どちらへ動いているか」を見て、戻り始めたら手を止める。速さを見て踏ん張るのが D です。

磁気軸受の制御器も同じことをします。センサが測った位置 $x$ と、それを時間で微分した速さ $\dot x$ から、制御電流を

$$i_c = -\left(k_p\, x + k_d\, \dot x\right)$$

と決めます。言葉にすると、中心からずれた量に比例して逆向きの電流を流し、さらに動いている速さに比例して、動きを止める向きの電流を足す、ということです。$k_p$ が「位置を見て押し返す強さ」、$k_d$ が「速さを見て踏ん張る強さ」です（単位は A/m と A·s/m。電流のゲインなので、力のゲインにするには電流剛性 $k_i$ を掛けます。[[link:amb-rotordynamics|次の節]]ではそうして $K_p = k_i k_p$、$K_d = k_i k_d$ と書きます）。

:::analogy @broom-balance 手のひらのほうき
ほうきを立てられる人と立てられない人の差は、腕力ではなく「先読み」です。倒れ始めの速さを見て、倒れきる前に手を出す。これが D の働きで、位置だけを見る P では、どれだけ素早く動いても後手に回ります。さらに、目で見てから手が動くまでの反応の遅れが大きいと、長いほうきは立てられても短い鉛筆は立てられません。短いほど倒れる速さ（負の剛性の時定数）が速く、反応が間に合わないからです。磁気軸受で「ギャップを狭くして腕力を増やす」と、鉛筆を立てるのに近づきます。限界：ほうきは倒れる向きが 2 方向で重力が相手ですが、磁気軸受は電磁石の負の剛性が相手で、その強さはバイアス電流で変わります。
:::

## 閉ループは、ただの「ばね・質量・減衰」

制御電流を前の節の力の式に入れると、回転子の運動方程式は

$$m\ddot x \;+\; (k_i k_d)\,\dot x \;+\; \left(k_i k_p - k_s\right) x \;=\; 0$$

になります。言葉にすると、制御のかかった磁気軸受は、減衰係数が $k_i k_d$、ばね定数が $k_i k_p$ から負の剛性の大きさ $k_s$ を差し引いた値の、ふつうの 1 自由度振動系になる、ということです。[[link:natural-frequency|固有振動数の節]]で見た式がそのまま使えます。

- **安定の条件**は、ばね定数が正で減衰が正、つまり $k_i k_p > k_s$ かつ $k_d > 0$。腕力に $k_p$ を掛けたものが敵に勝ち、踏ん張りがゼロでないこと。
- **固有振動数**は $\omega_n = \sqrt{(k_i k_p - k_s)/m}$。$k_p$ を上げるほど硬い軸受になります。
- **減衰比**は $\zeta = k_i k_d / (2\sqrt{(k_i k_p - k_s)\,m})$。$k_d$ で自由に決められます。

油膜軸受では、硬さも減衰も油と回転数が決めました（[[link:journal-bearing|すべり軸受の節]]）。ここでは $k_p$ と $k_d$ という二つの数字で決まります。危険速度の通過時だけ $k_d$ を上げる、といった運転中の切り替えも、ソフトウェアの話です。

:::field I は「重さを支える」係
PD だけだと、重力や定常の荷重がかかった回転子は、中心から少し下がった所で釣り合います。下がった分 $x$ に比例した力で荷重を支えるからで、これを定常偏差と呼びます。ずれを消すのが I（積分）で、ずれが残り続けるあいだ電流をじわじわ増やし、荷重を支えきった所で止まります。磁気軸受では、重力・ベルト張力・プロセス流体の静圧のような「常に乗っている力」を I が受け持ち、PD は振動を受け持つ、という分担です。I を強くしすぎると位相が遅れて安定を損なうので、低い周波数だけに効かせるのが作法です。
:::

## 遅れが、押し返しを押し出しに変える

ここまでは、位置を見た瞬間に力が出る前提でした。実機には遅れがあります。センサの信号を整えるフィルタ、ディジタル制御の標本化と計算、電流を流す増幅器の帯域、そして鉄心に生じる渦電流が磁束の立ち上がりを鈍らせる効果。一つひとつは短くても、足し合わせると高い周波数では無視できません。

遅れの効き方は周波数で違います。ゆっくりした動きなら、少し遅れて押し返しても「ほぼ逆向き」のままで、効き目は変わりません。速い振動では、遅れが振動の周期に対して大きくなり、押し返したつもりの力が、回転子がすでに向きを変えた後に届く。[[link:phase-lag|位相の節]]の言葉で言えば、基準は「変位に対する制御力の位相」です。理想の押し返し（変位とちょうど逆向き、遅れゼロ）は純粋なばねで、減衰はゼロ。そこから力が**遅れる**と、速度と同じ向きの成分が生まれて負の減衰になり、逆に**進む**と速度と逆向きの成分、つまり正の減衰になります（これが D の働きです）。遅れが 90° に達すると力はすべて速度の向きで、剛性はゼロ・負の減衰が最大。180° で剛性の符号が反転し、押し出しに変わります。開ループで言えば位相余裕を使い切る所で、D で稼いだ進みを遅れが食いつぶす周波数が、制御の帯域の上限です。

:::analogy @swing 遅れて押すブランコ
揺れているブランコを止めたいなら、動きと逆向きに手を当てます（正の減衰）。ところが手が遅れて、ブランコが向きを変えた後に届くと、押す力は動きと同じ向きになり、止めるつもりが揺らしてしまいます（負の減衰）。制御の遅れも同じで、周波数が高いほど同じ時間の遅れが大きな位相の遅れに化けます。だから磁気軸受の制御器は、低い周波数ではしっかり押し返し、高い周波数では「余計なことをしない」ように、意図的に効き目を落とします。限界：ブランコは一つの固有振動数しか持ちませんが、たわむ軸はいくつもの固有振動数を持ち、そのどれかが「遅れが半周期に近づく」周波数に当たると不安定になります。
:::

対策が**位相進み補償**です。D の項は、動きの速さを見ることで、位置より 90° 進んだ力を出します。これが遅れを打ち消す「貯金」になります。ただし純粋な微分はセンサの雑音を増幅するので、実機では二つの周波数のあいだでだけ位相を進める「位相進み」の回路を使います。注意したいのは、位相進み要素はそれより高い周波数で位相こそ元に戻るものの、ゲインは**上がったまま**になることです。高い周波数で「余計なことをしない」のは位相進み要素の仕事ではなく、別に足す低域通過フィルタ（ロールオフ）の仕事です。[[link:bode-polar|ボード線図の節]]の読み方で言えば、クロスオーバー周波数の近くで位相進みが位相余裕を稼ぎ、それより高い周波数ではロールオフがゲインを落とす、という二段構えの設計です。

## たわむ軸と、センサの置き場所

![机の上で浮く地球儀](data/books/rotordynamics/images/amb-control-3.jpg "写真：机の上で浮く地球儀。1 自由度の能動浮上の実物。ロータの磁気軸受は、これを 2 方向 × 2 か所＋軸方向に増やし、さらに軸のたわみとも付き合う。（Wikimedia Commons, Antonín Ryska, CC BY-SA 4.0）"){right}

軸は剛体ではありません。[[link:mode-shapes|曲げモードの節]]で見たように、第 1 曲げ、第 2 曲げと、いくつもの固有振動数で違う形にたわみます。磁気軸受の制御帯域がこれらのモードに届くと、制御器はモードを「見て」「押す」ことになります。ここで問題になるのが、**センサと電磁石が同じ場所にない**ことです。

電磁石の内側にセンサを置くことはできないので、センサは電磁石のすぐ隣に据えます。隣でも、たわみの節（動かない点）がそのあいだに来るモードでは、センサが見る動きと電磁石の位置の動きが**逆向き**になります。制御器は「右へ寄った」と見て左へ押すつもりが、電磁石の位置では軸はすでに左にあり、押す力はたわみを育てます。これを**非コロケーション**（non-collocation、センサと電磁石の位置が違うこと）の問題と呼びます。

![第 2 曲げモードの節がセンサと電磁石のあいだに来る様子](data/books/rotordynamics/images/amb-control-4.jpg "イメージ図（生成画像・模式）：センサと電磁石のあいだに曲げモードの節が来ると、二つの場所の動きが逆向きになる（非コロケーション）。"){right}

:::analogy @seesaw 支点の向こう側を見て押す
シーソーの支点をまたいで、向こう側の板の高さを見ながら手前の板を押すとします。向こうが上がったから下げようと手前を押し下げると、向こうはもっと上がる。見ている場所と押す場所が支点（節）を挟んで反対側にあるからです。たわんだ軸で、センサと電磁石のあいだに節が来るモードが、まさにこの状態です。限界：シーソーの支点は一つで動きませんが、軸の節の位置はモードごとに違い、回転数でも少し動きます。だから「どのモードが危ないか」は設計段階のモード解析で調べます。
:::

対策は三つあります。第一に、センサを電磁石にできるだけ近づけ、低いモードの節がそのあいだに来ないように配置する。第二に、問題のモードの周波数だけ制御の効き目を落とす**ノッチフィルタ**や帯域制限を入れ、そのモードには力を出さない（**ゲイン安定化**。モードに減衰は足さず、制御の輪から外す）。第三に、そのモードを制御帯域の中に残したまま、モード形とあわせて位相を調べ、その周波数で力が「押し返し」の側に来るように補償器を組んで積極的に減衰を加える（**位相安定化**）。ゲインの上限は、こうしたモードの中で最も危ないものが決めます。

:::field 設計で見る三つの線図
磁気軸受の制御設計では、三つの図を並べて見ます。（1）開ループのボード線図：クロスオーバー周波数と位相余裕、たわみモードの山がどこに出るか。（2）閉ループの剛性と減衰を周波数ごとに描いた図：軸受が「どの周波数でどれだけ硬いか」。（3）感度関数：外乱がどれだけ増幅されるかを周波数ごとに描いた図で、その最大値が安定余裕の指標になります。磁気軸受の国際規格 ISO 14839 は、この感度関数の最大値でゾーンを分けて安定余裕を評価します。読み方は [[link:amb-rotordynamics|次の節]]で扱います。
:::

:::deep 位相進み補償と、ディジタル制御の遅れ
位相進み補償器は伝達関数 $C(s) = K\,\dfrac{1 + s/\omega_z}{1 + s/\omega_p}$（$\omega_z < \omega_p$）の形で、$\omega_z$ と $\omega_p$ のあいだで位相を最大 $\arcsin\!\big((\omega_p - \omega_z)/(\omega_p + \omega_z)\big)$ だけ進めます。言葉にすると、二つの角周波数のあいだでだけ「速さを見る」働きをして位相を進め、それより高い周波数では位相は 0° に戻るものの、ゲインは $K$ ではなく $K\,\omega_p/\omega_z$ に上がったままになる、という補償器です。高い周波数のゲインを落とすのは、別に足す低域通過要素の役目です。ディジタル制御では、1 標本ぶんの計算遅れと零次ホールドの約 0.5 標本ぶんを合わせて、標本化周期 $T_s$ のおおむね $1.5\,T_s$ の無駄時間と見積もることが多く、周波数 $f$ で $360° \times 1.5\,T_s f$ の位相遅れを生みます。この仮定なら、10 kHz で標本化しても 1 kHz では 54° 遅れる計算です（計算の完了時刻や PWM の更新の仕方で、実際は 0.5〜1.5 標本ほどの幅があります）。制御帯域をたわみモードの近くまで広げられない理由がここにあります。
:::

## ひとことで

- P は位置を見て押し返す（ばね）、D は速さを見て踏ん張る（減衰）、I は常に乗っている重さを支える。
- 閉ループは、ばね $k_i k_p - k_s$、減衰 $k_i k_d$ の 1 自由度振動系。安定の条件は $k_i k_p > k_s$ と $k_d > 0$。
- センサから力までの遅れは高い周波数ほど大きな位相遅れになる。押し返しが変位の逆向きから遅れると負の減衰になり、90° で剛性ゼロ・負減衰が最大、180° で押し出しに変わる。
- だから位相進みで貯金を作り（進み要素は高い周波数のゲインを上げるので）、別のロールオフで高い周波数の効き目を落とす。制御帯域の上限は遅れとたわみモードが決める。
- センサと電磁石のあいだに節が来るモードは、制御が揺れを育てる（非コロケーション）。配置、ノッチで外す（ゲイン安定化）、位相を合わせて減衰を足す（位相安定化）で対処する。

**模式・出典について**：閉ループの式は [[link:amb-intro|前の節]]の線形化モデルに PD 制御を入れたもので、センサ・増幅器・渦電流の遅れは本文で定性的に述べるにとどめました。位相進み補償器の式と最大位相進みの関係は制御工学の標準的な記述、ディジタル制御の遅れを標本化周期の約 1.5 倍の無駄時間と見る近似は「1 標本の計算遅れ＋零次ホールド 0.5 標本」という仮定に基づく目安で、本文の 54° はその仮定下の例です。位相と減衰の関係（遅れれば負の減衰）は[[link:phase-lag|位相の節]]と同じ約束です。非コロケーションとノッチフィルタ、感度関数による評価の考え方は Schweitzer & Maslen 編『Magnetic Bearings』（Springer、2009 年）および ISO 14839 シリーズの枠組みに基づく一般的な記述で、規格の数値は転載していません。写真は Wikimedia Commons（NASA、Liquidat、Antonín Ryska）です。
