# 規格というものさし——ISOとAPIの地図

![蒸気タービンのロータを点検する作業員](data/books/rotordynamics/images/standards-intro-1.jpg "写真：発電用蒸気タービンのロータ。何段もの翼列を持つこの重いロータが「どれだけ釣り合っていれば良いか」「運転中の揺れがいくつなら合格か」を、発注者とメーカーが同じ言葉で確かめるために規格がある。（Wikimedia Commons, Siemens Pressebild, CC BY-SA 3.0）"){right}

工場に大型の送風機を新しく据え付けたとき、試運転の立ち会いで必ず交わされる会話があります。「軸受台の振動は 1.8 でした」「はい、A ゾーンですね」。数字一つと記号一つで、その場の全員が納得して次の工程へ進む。揺れが大きいか小さいか、新品として申し分ないか、契約どおりの品質か。こうした判断は本来ひどく主観的で、担当者が変われば答えも変わりかねません。それを、誰が測っても同じ結論になるよう取り決めたのが**規格**です。いわば、世界共通の**ものさし**です。

ここまでの節で、振動を測り（波形・スペクトル）、見渡し（ウォーターフォール）てきました。この節では、測った数字を「合格・不合格」に翻訳するものさしの地図を描きます。ロータダイナミクスの実務で出会う規格は、名前こそ多いものの、問いは大きく二つしかありません。**作る前に、どれだけ釣り合わせるか**。**動かしてから、この揺れは大丈夫か**。この二つを軸に地図を読めば、番号の森で迷いません。

:::analogy @ruler 身長の「高い・低い」は、ものさしがあって初めて言える
「あの子は背が高い」と言うとき、私たちは無意識に同年齢の平均という目盛を使っています。小学生の 150 cm と大人の 150 cm では意味が違う。振動の「大きい・小さい」も同じで、数値そのものには意味がなく、**どの機械の、どの区分の目盛で読むか**が決まって初めて評価になります。規格とは、その目盛を世界で共通にしたものさしです。限界：身長の平均は統計ですが、規格の境界値は長年の運転実績と合意で引かれた線で、改訂のたびに動きます。
:::

## 大きく二つの問い

規格はたくさんありますが、ロータダイナミクスでまず押さえるべきは二つの問いです。

- **作る前に、どれだけ釣り合わせるか** → **ISO 21940-11**。残留不釣り合いの許容量を、[[G|品質等級 G]] と回転数から決めます。「G2.5」「G6.3」といった等級は、許容できる偏心の大きさと回転数の積を表します。
- **動かしてから、この揺れは大丈夫か** → **ISO 20816**。測った振動が、ゾーン A〜D のどこに入るかで評価します。軸受台で測る速度の[[rms|実効値]]が代表的な量ですが、大型機の軸振動は変位で評価するなど、量も境界も該当パートで決まります。

この土台の上に、**機種ごとの約束**（API 610・617・612 など）と、**保護系の約束**（API 670）が乗ります。前者は「この機械はどこまで揺れてよいか、どう試験するか」を発注者とメーカーが取り決める仕様書、後者は「揺れをどう測って、どこで警報を出し、どこで止めるか」を決める監視装置の仕様書です。

![四つの帯に分かれたものさしと針](data/books/rotordynamics/images/standards-intro-3.jpg "イメージ図（生成画像・模式）：目盛が四つの帯に分かれたものさしの上に、針が乗っている。"){small}

:::analogy @speedometer 速度計の目盛と、道路ごとの制限速度
車の速度計は、どの道でも同じ目盛で速さを示します。けれども「速すぎるか」は道路ごとの制限速度で決まり、高速道路の 80 km/h と住宅街の 80 km/h はまるで意味が違います。振動の計測器が速度計で、規格のゾーンが制限速度です。ISO 20816 は、機械の種類という「道路の種類」ごとに制限速度を定めています。限界：制限速度は法律で一つに決まりますが、規格のゾーンは「長期運転に適するか」の目安であって、超えた瞬間に壊れる線ではありません。
:::

## ゾーン A〜D という考え方

![大型の遠心送風機](data/books/rotordynamics/images/standards-intro-2.jpg "写真：工場で使われる大型の遠心送風機。ISO 20816-3 が対象とする「出力 15 kW を超える産業用機械」の典型で、軸受台の上で振動速度を測って評価する。（Wikimedia Commons, SAF, CC BY-SA 4.0）"){right}

ISO 20816 の評価は、測った振動を四つの帯で区切ります。考え方はとても単純です。

- **ゾーン A**：新品・出荷時に期待される、低い振動。
- **ゾーン B**：長期運転して問題ない範囲。
- **ゾーン C**：長期連続運転には不適。短期なら許容、早めに対策を。
- **ゾーン D**：損傷を起こしうる危険な水準。

境界の具体的な数値（mm/s など）は、機械の種類・大きさ・支持の硬さによって変わります。たとえば産業用機械を扱うパート 3 は、出力 15 kW を超え、回転数が毎分 120〜30,000 回転の機械を対象に、軸受台で測った振動速度の実効値を、出力の区分と「剛な基礎か、柔らかい基礎か」の区分でゾーン分けしています。下のゲージはこのパート 3 流の「軸受台の速度実効値」のものさしで、大型の蒸気タービンや発電機（パート 2）、軸の変位で評価する機械には、別のパートの別のものさしがあります。実際にものさしを動かして読んでみましょう。

:::vibration-gauge
{
  "title": "測った振動は、どのゾーンに入る？",
  "vDefault": 3.2,
  "caption": "スライダーで測定値（速度実効値）を動かすと、針がゾーン帯の上を走ります。機械の区分を切り替えると境界そのものが動く——同じ 5 mm/s でも、大型機なら「要対策」、柔らかい支持なら「長期運転可」になり得ます。境界値は広く引用される代表例（模式）です。"

大事なのは数値の暗記ではなく、「機械の区分ごとに、ものさしの目盛が違う」という構造です。だから振動の評価は、必ず「この機械はどの区分か」を確かめるところから始まります。そしてもう一つ、ゾーンの境界は絶対値だけではありません。規格は「普段の値からどれだけ変わったか」も評価の軸にしています。ゾーン B の中にいても、ある日から急に値が増え始めたら、それは警戒の合図です。

:::field 現場での使い方——「どこで、何を、どう測る」まで決まっている
規格が決めているのは境界値だけではありません。たとえばパート 3 の軸受台での測定なら、測る場所（軸受台のどの方向か）、測る量（振動速度の実効値と、その周波数帯域）、測る条件（定格の定常運転）まで、該当パートに書いてあります。帯域や方向、条件は機種と回転数とパートで違うので、別の場所で測った値や、瞬間値のピークを規格の表に当てはめても意味がありません。

発電所や化学プラントでは、据え付け時の試運転でゾーン A に入ることを確認して「基準値」を記録し、その後は月例の巡回計測で基準値からの変化を追う、という運用が一般的です。異常の兆候は「値が大きい」よりも先に「値が動き始めた」として現れることが多く、だからこそ最初の基準値が大切になります。回転軸の変位を渦電流センサで測る大型機では、同じ ISO 20816 系の軸振動のパートを使い、軸受すきまに対する相対的な振れとして評価します。
:::

## 品質等級 G という考え方

ISO 21940-11 の釣り合い品質等級は、**許容残留偏心と角速度の積が一定（＝G）**という関係でできています。

$$e_{per}\,[\mu\mathrm{m}] \approx \frac{1000 \times G\,[\mathrm{mm/s}]}{\Omega\,[\mathrm{rad/s}]}$$

言葉にすると、「許してよい残留偏心（μm）は、等級の値 G（mm/s）を角速度で割ったもの。だから回転が速い機械ほど小さくなる。G は『許される残留不釣り合いを質量で割った等価な偏心』を速さに換算した尺度で、不釣り合いが一点に集まった静不釣り合いなら、その偏心で回る重心の速さそのものである」ということです。同じ等級 G でも、回転数が 10 倍になれば許される偏心は 10 分の 1 になります。高速機ほど厳しく釣り合わせなければならない、という現場の感覚が、この一本の式に表れています。等級の選び方と許容量の計算は、[[link:balancing|バランシングの節]]で部品を使って具体的に扱います。

:::analogy @scale-weight 重心が動く「速さ」で釣り合いを測る
なぜ偏心（長さ）ではなく、偏心と角速度の積（速さ）で等級を決めるのでしょう。偏心 $e$ で回るロータの重心は、半径 $e$ の円を角速度 $\Omega$ で回っています。その重心の速さが $e\Omega$ です。不釣り合いが軸受に及ぼす力は質量と $e\Omega^2$ の積ですから、重心の速さが同じなら、回転数が違っても「質量あたりの軸受荷重が回転数に比例する」という同じ土俵で比べられます。限界：重心が円を描くという絵は静不釣り合いの場合の直観で、重心は軸上にあるのに慣性主軸が傾く偶不釣り合いでは、e_per は実在する重心の軌道半径ではなく等価な尺度です。ISO 21940-11 はこの許容量を修正面へ配分する手順まで扱います。また、たわむロータでは偏心という一つの数で釣り合いを語れません。
:::

## 番号の歴史——なぜ似た規格がいくつもあるのか

:::history 1964 年のものさしから、2016 年の統合まで
機械の振動を「速度で測って帯で評価する」という考え方は、ドイツの VDI 指針 2056（1964 年 10 月）が先行例で、これを国際化したのが ISO 2372 です。ISO 2372 は 1974 年 11 月に定めた「毎秒 10〜200 回転で運転される機械の機械振動——評価基準を定めるための基礎」にさかのぼります。この規格は軸受キャップなど機械表面での測定を対象に、10〜1,000 Hz の帯域で振動速度の実効値を使い、機械の級ごとに「振動シビアリティ」の帯を示しました。1995 年 12 月に廃止され、ISO 10816-1 に引き継がれます。

1990 年代の体系では、「非回転部（軸受台）の振動」を ISO 10816 が、「回転軸の振動」を ISO 7919 が、別々の規格として扱っていました。測る量も場所も違うのに、評価の考え方は共通だったため、2016 年に両者を統合した ISO 20816 への再編が始まり、パートごとに順次置き換えられています。ゾーン A〜D の考え方は、この再編でも引き継がれました。釣り合いの側では、長く ISO 1940-1 として知られた剛性ロータの等級が、2016 年に ISO 21940-11 へ置き換わっています（等級 G の考え方は同じです）。

日本工業規格（JIS）では、JIS B 0906（1998 年）が ISO 10816-1:1995 と一致する規格として、JIS B 0905（1992 年）が ISO 1940-1 の 1986 年版を基にした規格として作られました。ISO 側がその後 2003 年版、さらに ISO 21940-11 へと改訂されても JIS の番号と版はすぐには追随しないので、古い図面や社内基準で JIS 番号を見たときは、対応する ISO の版を確かめてください。
:::

:::deep 対応表——古い番号を見たらこう読み替える
- **振動評価**：VDI 2056（1964）→ ISO 2372（1974）→ ISO 10816 系（1995〜、非回転部）と ISO 7919 系（回転軸）→ ISO 20816 系（2016〜、両者を統合）。古い図面や論文で 2372・7919・10816 を見たら、現在の 20816 の該当パートに対応すると考えます。
- **釣り合い**：ISO 1940-1 → ISO 21940-11（2016）。たわみロータはパート 12 が扱います。
- **ISO と API の関係**：ISO は国際的な共通土台、API（米国石油協会）は石油・ガス機械向けの、より具体的で厳しい調達仕様。実務では「ISO を土台に、API や各社仕様で上乗せ」という重ね方をします。API 617 は遠心・軸流圧縮機、API 610 は遠心ポンプ、API 612 は蒸気タービンの仕様で、ロータダイナミクスの解析と釣り合いの受け入れ基準を含みます。
- **API 670**：機械保護システムの規格で、第 5 版（2014 年）は軸の半径方向振動、ケーシング振動、軸の軸方向位置、回転数、位相基準、過速度、軸受メタル温度などの監視と、センサ・モニタの要件、据え付け、文書、試験まで定めています。[[link:sensors|センサの節]]で見た渦電流センサやキーフェイザの据え付け作法は、この規格が出どころです。
- **API 684**：規格本体ではなく「チュートリアル」で、API 各仕様書のロータダイナミクス条項（横振動の危険速度、不釣り合い応答、安定性、ねじり、釣り合い）を解説します。第 2 版（2005 年）のあと、2019 年に API TR 684-1（第 1 版）が出ています。API のカタログには別の版番号の TR 684 も載っており、番号と版の関係は改訂のたびに変わるので、参照するときは API の最新カタログで現行版を確かめてください。[[link:multi-critical|離隔余裕の節]]で触れた増幅係数の扱いは、この系統の文書に由来します。
:::

## ひとことで

- 規格は、揺れの「大きい・小さい」を誰が測っても同じ結論にするための、世界共通のものさし。
- 問いは二つ。作る前の「どれだけ釣り合わせるか」（ISO 21940-11、等級 G）と、動かしてからの「この揺れは大丈夫か」（ISO 20816、ゾーン A〜D）。
- ものさしの目盛は機械の区分で変わる。評価は「この機械はどの区分か」を確かめるところから。
- 数値だけでなく「普段からの変化」も評価の軸。据え付け時の基準値が後の診断を支える。
- API は ISO の上に乗る調達と保護の約束。番号は改訂で変わるので、必ず版を確かめる。

**模式・出典について**：本節は規格の全体像をつかむための概観です。ゾーンの境界値や等級の許容量といった具体的な数値、適用範囲（機械の種類・パート番号）は規格ごと・改訂ごとに定められ、有料で頒布されています。実際の判定・設計には、必ず各規格の最新版と該当パートを参照してください。評価ゲージの境界値は広く引用される代表例の模式です。VDI 2056 の発行（1964 年 10 月）と廃止・後継は DIN Media の規格目録、ISO 2372 の発行（1974 年 11 月）・廃止（1995 年 12 月）・内容は DIN Media と Genorma の規格目録、ISO 20816-1 が ISO 10816-1 を置き換えたことは ISO の目録、ISO 21940-11:2016 が ISO 1940-1:2003 を置き換えたことは AFNOR と BIS の目録、JIS B 0906（1998 年、ISO 10816-1:1995 対応）と JIS B 0905（1992 年 8 月、ISO 1940-1:1986 対応）は AFNOR の規格目録、API 670 第 5 版（2014 年）の範囲は Meggitt 社の解説記事、API 684 第 2 版（2005 年）と API TR 684-1（2019 年）は規格販売サイトの目録によります。ISO 20816-3 の対象範囲（15 kW 超、120〜30,000 rpm）は規格解説サイトの記述です。写真は Wikimedia Commons（Siemens Pressebild CC BY-SA 3.0、SAF CC BY-SA 4.0）です。
