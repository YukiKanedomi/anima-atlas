# 磁気軸受のロータダイナミクス——剛性を設計で決める・ISO 14839

![NASA Lewis 研究所の能動磁気軸受の固定子](data/books/rotordynamics/images/amb-rotordynamics-1.jpg "写真：NASA Lewis（現 Glenn）研究所で試作された能動磁気軸受の固定子。内側に並ぶ磁極にコイルが巻かれ、中に軸を通して浮かせる。（Wikimedia Commons / NASA、パブリックドメイン）"){right}

[[link:journal-bearing|油の膜で軸を浮かせる軸受]]では、硬さも減衰も油の粘さと回転数が勝手に決めていました。設計者にできるのは、すきまと幅と油を選ぶことまでです。磁気軸受は違います。硬さと減衰は制御器の**数字**で決まり、運転中でも書き換えられます。この一点が、磁気軸受のロータダイナミクスを他の軸受と別物にします。

この節では、その自由を設計者がどう使うか（柔らかく支えて危険速度の上で回す）、自由の代わりに背負う制約（力に上限がある、停電すると落ちる）、不釣り合いへの二つの流儀、そして安定の余裕をどう測るか（感度関数と ISO 14839）を見ていきます。顔ぶれは、天然ガスの圧縮機とターボ分子ポンプです。

## 硬さも減衰も、制御器が作る

:::analogy @broom-balance 手のひらでほうきを立てる
ほうきを手のひらに立てて支えるとき、ほうきを「硬く」支えているのは手の筋肉ではなく、目で傾きを見て手を動かす反射です。傾きに比例して手を動かせばばねのように、傾く速さに応じて動かせばダンパのように働きます。反射が速く強い人ほど硬く支えられ、疲れて反応が鈍ると倒れます。磁気軸受の硬さと減衰も、センサで見て電磁石を動かす「反射」が作るもので、電磁石そのものはむしろ倒す向きに働いています。限界：ほうきは重力で倒れますが、磁気軸受の軸は電磁石の吸引で偏った向きへ引かれます。倒す力の出どころが違うだけで、「見て押し返す」構造は同じです。
:::

[[link:amb-intro|仕組みの節]]で見たとおり、電磁石は偏った軸をさらに偏った向きへ引きます。これが**負の剛性**で、この本ではその大きさを $k_s$（正の値）と書きます。制御がなければ軸は必ずどちらかの磁極に吸い付きます。制御器が位置に比例した電流と速度に比例した電流を流すと、[[k_i|電流剛性]] $k_i$ を通じて復元力と減衰力が生まれます。ここでは[[link:amb-control|制御の節]]の電流ゲイン $k_p$・$k_d$ に電流剛性を掛けた $K_p = k_i k_p$、$K_d = k_i k_d$（単位は N/m と N·s/m）で書きます。軸の一方向だけを取り出した最も単純な形で書くと

$$m\ddot{x} = k_s x + k_i i,\qquad i = -\frac{K_p x + K_d \dot{x}}{k_i}\ \Rightarrow\ m\ddot{x} + K_d \dot{x} + (K_p - k_s)\,x = 0$$

言葉にすると、制御がかかった磁気軸受は「硬さ $K_p - k_s$、減衰 $K_d$ のふつうのばねとダンパ」と同じ運動方程式になる、ということです。有効な硬さは比例ゲインから負の剛性を引いた残りなので、$K_p$ が $k_s$ を上回らなければそもそも支えられません。そして上回ったぶんが固有振動数を決めます。

$$\omega_n = \sqrt{\frac{K_p - k_s}{m}},\qquad \zeta = \frac{K_d}{2\sqrt{m\,(K_p - k_s)}}$$

言葉にすると、固有振動数は「有効な硬さを質量で割った平方根」、減衰比は「微分ゲインを臨界減衰で割ったもの」で、どちらも制御器の二つの数字で決まる、ということです。[[link:jeffcott-intro|一番単純なロータ]]の $k$ と $c$ が、ここでは $K_p - k_s$ と $K_d$ に置き換わっただけです。実機では位置は変位センサで測り、速度は差分やフィルタで作り、位相の遅れを補う進み要素を足します。その話は[[link:amb-control|制御の節]]に譲り、ここでは「硬さと減衰を自由に選べる」という結果だけを持って先へ進みます。

## 柔らかく支えて、危険速度の上で回す

硬さを選べるなら、どう選ぶか。油膜やころがり軸受の機械では、軸受は「あるものを使う」しかなく、危険速度は結果としてどこかに決まり、それを運転範囲から離すのが設計でした。磁気軸受では逆向きに考えられます。**剛体モードの危険速度を運転範囲の下に置く**ように軸受を柔らかくし、減衰をたっぷり付けて起動時にそこを通り抜けるのです。運転速度では軸は固有振動数よりずっと速く回っているので、[[link:transmissibility|伝達率の節]]で見たとおり、不釣り合いの力はほとんど軸受に伝わりません。

:::transmissibility

:::

もちろん、柔らかくするほど軸の変位は大きくなり、すきまの中で動ける範囲には限りがあります。磁気軸受のエアギャップは数百 μm から 1 mm 程度で、その内側に[[link:amb-intro|バックアップ軸受]]のすきま（エアギャップの半分程度）がありますから、変位の余裕は油膜の機械と桁は変わりません。「どこまで柔らかくできるか」は、すきまと不釣り合いの大きさで決まります。また、軸がたわむ機械では、軸自身の曲げモードの固有振動数は主に軸の曲げ剛性で決まり、軸受の動剛性で多少は動くものの、制御器で剛体モードほど自由には動かせません。こちらは[[link:multi-critical|離隔余裕の考え方]]のとおり運転範囲から離すか、減衰を付けて通過させることになり、通過させる場合は制御器がその曲げモードを「見て」減衰を加えなければなりません。

:::field たわみロータの制御——曲げモードが制御の輪に入る
軸が長く、運転範囲の中に曲げの危険速度があるとき、センサと電磁石は節の位置が違う場所に付いています。センサで見た変位と電磁石の力の効き目がモードごとに食い違い、あるモードでは「押し返したつもりが揺らしている」ことが起きます。これが非コロケーション（センサと電磁石の位置が違うこと）の問題で、磁気軸受の制御で最も神経を使う所です。対策は大きく二つの流儀に分かれます。一つは**ゲイン安定化**で、ノッチフィルタや帯域制限でそのモードの周波数には力を出さず、制御の輪から外す（モードに減衰は足さない）。もう一つは**位相安定化**で、モードを制御帯域に含めたまま、その周波数で力の位相が「押し返し」の側に来るよう補償器を組み、積極的に減衰を加える。どちらを選ぶかはモードごとで、ロータの有限要素モデルと制御器を一緒に解析して確かめます。
:::

## 力には上限がある

:::analogy @horseshoe-magnet 磁石に付く鉄の重さには、限りがある
馬蹄磁石で持ち上げられる鉄の重さは、磁石の面積と磁力で決まり、どんなに頑張っても限度があります。電磁石も同じで、電流を増やせば力は増えますが、鉄心が磁気的に「飽和」するとそれ以上は増えません。磁気軸受の力の上限は、磁極の面積とその飽和で決まります。限界：馬蹄磁石は鉄に触れて引きますが、磁気軸受はすきまを保って引きます。同じ磁束密度 $B$ と面積なら力はすきまの長さによらないのですが、すきまが広いほど同じ $B$ を作るのに大きな起磁力（電流×巻数）が要り、漏れ磁束も増えるので、現実に出せる $B$ が下がります。
:::

電磁石がすきまを挟んで鉄を引く力は、磁極の面積 $A$ あたり

$$\frac{F}{A} = \frac{B^2}{2\mu_0}$$

です。言葉にすると、磁気の「圧力」はエアギャップの[[B_gap|磁束密度]]の 2 乗に比例し、真空の透磁率の 2 倍で割ったもの、ということです。磁束密度 1 T（テスラ）なら約 0.4 MPa、鉄心の飽和がだいたい 1.5〜2 T 前後なので、磁極の全面を使って引ける圧力は 1 MPa 前後が物理的な天井です。実際には磁極は円周の一部しか軸に向いておらず、しかも「引く」ことしかできないので向かい合う磁極を対で使い、制御のために飽和の手前に余裕を残します。結果として軸の投影面積あたりの支持力は、油膜のすべり軸受の平均面圧（大型機で 1〜3 MPa 級）より小さいのが普通です。同じ荷重を支えるには軸受を長く太くする必要があり、これが磁気軸受の機械が大きく重くなる理由の一つです。

もう一つの制約は**停電**です。電流が止まれば力は消え、軸は落ちます。だから磁気軸受の機械は必ず**バックアップ軸受**（タッチダウン軸受）を持ち、電源には無停電化や、減速中の電動機を発電機として使って制御電源を賄う仕組みが入ります。

## 不釣り合いへの二つの流儀

磁気軸受は回転に同期した成分（1×）を信号の中で見分けられるので、不釣り合いに対して二通りの振る舞いを選べます。

- **力を減らす**：1× の成分に対しては制御器を「見ないふり」にして、軸を重心を通る慣性主軸のまわりで自由に回らせる。軸受には不釣り合いの力がほとんど伝わらず、ケーシングも静かになる。代わりに軸は偏心のぶんだけ振れるので、すきまに余裕が要る。
- **変位を減らす**：1× の成分に対して逆に硬くし、幾何中心に軸を押さえ込む。軸の変位は小さくなるが、不釣り合いの力はそのまま電磁石が受け持ち、力の上限と発熱で頭打ちになる。

前者は同期成分を抜くノッチフィルタや、回転に同期した補正信号を足して不釣り合いの力を打ち消すフィードフォワードで実現されます。後者も同期成分を取り出して使いますが、目標が「力をゼロに」ではなく「変位をゼロに」なので、補償の設計は別物で、単に符号を変えたものではありません。どちらを選ぶかは機械しだいで、圧縮機のように力の上限が厳しい機械では前者、工作機械の主軸のように刃先の位置が命の機械では後者が選ばれます。いずれにせよ、[[link:balancing|釣り合わせ]]を不要にするものではなく、残留不釣り合いの扱いを柔らかくする道具です。

![慣性主軸で回す流儀と幾何中心に押さえる流儀の比較](data/books/rotordynamics/images/amb-rotordynamics-3.jpg "イメージ図（生成画像・模式）：左は慣性主軸のまわりで自由に回らせて力を減らす流儀、右は幾何中心に押さえ込んで変位を減らす流儀。"){small}

## 安定の余裕を測る——感度関数と ISO 14839

:::analogy @tightrope 綱渡りの「余裕」をどう数字にするか
綱渡りの人が落ちていないことと、どれだけ余裕を持って渡っているかは別です。風が少し吹いたとき、体がどれだけ揺れて戻るかを見れば、余裕の大きさが分かります。制御系の「安定余裕」も同じで、いま安定であることではなく、外乱に対してどれだけ揺れが増幅されるかで測ります。限界：綱渡りの余裕は一つの数字では言えませんが、制御系では「感度関数のピーク」という一つの数字に約束で決めてあります。
:::

磁気軸受の機械は制御系ですから、[[link:stability-chart|油膜の安定性]]とは違う物差しで安定の余裕を測ります。制御の分野で使われるのが**感度関数**で、外乱が閉ループでどれだけ増幅されるかを周波数ごとに表した曲線です。値が 1（0 dB）なら外乱は素通り、2（6 dB）なら 2 倍に増幅、ピークが高いほど不安定に近い、と読みます。下の曲線は、上で作った一方向の磁気軸受に比例・微分制御をかけたときの感度関数で、硬さと減衰の数字を動かすとピークがどう変わるかを見られます。

ISO 14839 シリーズは磁気軸受付き回転機械のための規格群で、-1 が用語（初版 2002 年、その後 2018 年に改訂）、-2 が振動の評価（2004 年）、-3 が安定余裕の評価（2006 年）、-4 が技術ガイドライン（2012 年）です。-3 は、まさにこの感度関数のピークを制御軸ごとに測り、その高さでゾーン A〜D に分けます。ゾーンの境界値は二次資料では約 9.5 dB、12 dB、14 dB とされていますが、規格本文は有料で、ここでは確認できていません。使うときは版と本文を確認してください。-2 は、軸受近くの軸の振動変位をすきまに対する比で評価するのに加えて、コイルや増幅器の**電流と電圧**の余裕も評価の対象にします。[[link:standards-intro|ISO 20816 の速度実効値]]とは物差しが違うわけで、磁気軸受では「どれだけ揺れているか」より「すきまと力の余裕をどれだけ食っているか」が本質だからです。適用範囲は主に定格 15 kW を超える機械で、小型のターボ分子ポンプや工作機械主軸は外れると理解していますが、この範囲と 2018 年改訂の中身は本文未確認です。

石油・ガスの圧縮機では、API 617（遠心圧縮機の規格）が磁気軸受付きの機械の設計・ロータダイナミクス・試験・バックアップ軸受の要求を附属書にまとめている（第 8 版の附属書 E、第 9 版では附属書 D）とされます。一方 API 684（現在は技術報告 TR 684-1）はロータダイナミクスのチュートリアルで、受け入れの可否を決める規格そのものではありません。どちらも本文は未確認で、版によって附属書の番号と中身が変わるので、使うときは必ず当該版を確認してください。

:::history 規格ができるまで
能動磁気軸受の最初の国際シンポジウム（ISMB）は 1988 年 6 月にチューリッヒで、Gerhard Schweitzer の主催で開かれ、以後 2 年ごとに続く研究者と産業界のネットワークになりました。ISO 14839 の第 1 部（用語）が出たのは 2002 年で、評価（2004 年）、安定余裕（2006 年）、技術ガイドライン（2012 年）と続きます。油膜の軸受が Reynolds の 1886 年から規格化まで百年近くかかったのに比べると、磁気軸受は商用化（S2M の 1976 年）から四半世紀で規格を持ったことになります。制御系の「安定余裕」を評価の物差しにした点が、この規格群の特徴です。
:::

## 落ちたときのために——バックアップ軸受

![磁気軸受の断面（磁極・コイル・位置センサ・バックアップ軸受のすきま）](data/books/rotordynamics/images/amb-rotordynamics-2.jpg "イメージ図（生成画像・模式）：電磁石の磁極とコイル、位置センサ、軸に触れずに待機するバックアップ軸受のすきま。"){right}

制御が止まる、電源が切れる、力の上限を超える荷重が来る。どの場合も軸はバックアップ軸受に落ちます。バックアップ軸受はころがり軸受か乾式のすべり軸受で、通常の運転では軸に触れず、エアギャップの半分ほどのすきまを保って待機しています。落ちた瞬間、止まっていたころがり軸受の内輪が一気に加速され、軸はすきまの中で跳ね、[[link:whirl-direction|後ろ向きの振れ回り]]（摩擦で軸がすきまの中を転がる、乾式のホワール）を起こすことがあります。これが**ドロップ**で、仕様で要求される場合には、受け入れ試験で定格回転からの落下を何回か行い、軸受と軸が無傷で減速し切ることを確かめます。実機で落とすか、試験ロータで落とすか、解析で代えるかは規格の版と契約しだいです。何回のドロップに耐えるかは設計仕様の一部で、バックアップ軸受は消耗品として交換周期が決められます。

ここまでの設計の自由と制約が、どの機械でどう効いたか。ターボ分子ポンプ、フライホイール、海底の圧縮機、血液ポンプの顔ぶれは[[link:amb-applications|磁気軸受はどこにいるかの節]]で振り返ります。

## ひとことで

- 磁気軸受の硬さと減衰は制御器の二つの数字で決まる。有効な硬さは比例ゲインから負の剛性を引いた残り。
- 柔らかく支えて剛体モードの危険速度を運転範囲の下に置き、減衰で通過させる設計が取れる。曲げモードは主に軸の剛性で決まり、剛体モードほどは動かせない。
- 力の上限は磁極の飽和（B²/2μ₀、1 T で約 0.4 MPa）で決まり、油膜より小さい。停電すれば落ちるのでバックアップ軸受が要る。
- 不釣り合いには「力を減らす」と「変位を減らす」の二つの流儀があり、機械しだいで選ぶ。
- 安定の余裕は感度関数のピークで測り、ISO 14839-3 がゾーンに分ける。-2 は軸の変位（すきまに対する比）と電流・電圧の余裕を評価する。圧縮機では API 617 の附属書も効く。
- 仕様で要求されれば受け入れ試験で定格からのドロップを行い、バックアップ軸受で無傷に止まることを確かめる。

**模式・出典について**：一方向の運動方程式と感度関数は、質量・負の剛性・比例微分制御だけの最も単純な模型で、実機の位相遅れ・センサと電磁石の位置の違い・曲げモードは含みません。感度関数の部品は式どおりの計算で、ISO 14839-3 のゾーン境界値（約 9.5／12／14 dB）は浙江大学の論文（2020 年）の表に拠る二次情報で、規格本文は未確認です。ISO 14839 各部の題名と発行年、-2 が変位と電流・電圧の両方を測ることは国際磁気軸受学会の規格一覧、-1 の 2018 年改訂・適用範囲 15 kW 超・API 617 の附属書（第 8 版 E／第 9 版 D）と TR 684-1 の位置づけは査読者の指摘に基づく記述で本文は未確認、1988 年 6 月のチューリッヒのシンポジウムは ISMB の公式沿革、S2M の 1976 年、バックアップ軸受が通常必要なこと、磁気は保存力で減衰をほとんど持たないことは Wikipedia「Magnetic bearing」によります。磁気圧力 B²/(2μ₀) は電磁気学の基本式で、1 T で約 0.4 MPa は計算値、鉄心の飽和磁束密度 1.5〜2 T と、すべり軸受の平均面圧 1〜3 MPa 級、エアギャップとバックアップ軸受のすきまの関係は、機械要素の教科書で広く共有されている目安です。たわみロータの非同位置の問題とゲイン安定化・位相安定化、不釣り合いへの二つの流儀、ドロップ試験の扱いは、磁気軸受の実務で一般的な記述です。写真は Wikimedia Commons にある NASA のパブリックドメイン画像で、[[link:amb-control|制御の節]]の冒頭と同じものです。
