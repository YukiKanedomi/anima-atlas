# 前向き？後ろ向き？——振れ回りの向き

回る機械を眺めるとき、私たちはつい「回転の向き」だけを見てしまいます。でも、たわんだロータの運動には向きが**2つ**あります。軸が自分の中心線のまわりをくるくる回る**自転**（回転角速度 [[Omega|Ω]]）と、たわんだ軸の**中心そのもの**が別の輪を描いてまわる**振れ回り**。地球が自転しながら太陽のまわりを公転しているように、この2つは別々の運動です。

[[link:jeffcott-intro|第1章の最初]]から、私たちは揺れの**大きさ**と[[link:phase-lag|**位相**]]を見てきました。この節では、振れ回りそのものの**形と向き**に注目します。

軸の中心が、回転と**同じ向き**に回るのが **前向き振れ回り（forward whirl）**、**逆向き**に回るのが **後ろ向き振れ回り（backward whirl）** です。不釣り合いで揺れるふつうのロータは前向きですが、支持の異方性やジャイロ効果がからむと後ろ向きが現れます。

便利なことに、どんな平面の振れ回りも、**前向きの円**と**後ろ向きの円**の足し合わせで表せます。前向き成分を $F$、後ろ向き成分を $B$ とすると：

$$x(t) = (F+B)\cos\theta,\qquad y(t) = (F-B)\sin\theta$$

この2つの比で、軌道の形と向きが決まります。下のスライダーで $F$ と $B$ を動かして確かめてください。

- $B = 0$（前向きだけ）→ **円**（前向き）
- $F,\ B$ どちらもある → **楕円**（支持が硬軟あるとこうなる）
- $F = B$ → **直線**（往復運動）
- $F < B$ → 楕円のまま**向きが後ろ向き**に反転

## 楕円は「支持のかたより」のサイン

支持（軸受や台）の硬さが縦と横で違うと、前向きと後ろ向きの成分が混ざり、ロータは円ではなく**楕円**を描きます。つまり楕円は「軸受の異方性」が軌道に現れたサインで、現場で軌道（オービット）を見れば支持の素性が読み取れます。その軌道を実際にどう測って描くかは、[[link:orbit-from-waves|次の節]]で見ていきます。

## 後ろ向きは、なぜ危ないのか

振れ回りの向きは、見た目の違いにとどまりません。軸の**材料が受ける応力**の質が変わります。

[[link:rotating-frame|回転座標系の節]]で詳しく見るとおり、回転と**同じ向き・同じ速さ**で回る前向きの振れ回り（同期振れ回り）では、軸といっしょに回る立場から見るとたわみは**止まって**見えます。曲がってはいるけれど動かない——曲げ応力はほぼ一定で、材料はあまり疲れません。

ところが**後ろ向き**では話が逆転します。回転と同じ速さで逆向きに振れ回っている場合、回転系から見るとたわみの向きは**2倍の速さ（2Ω）で逆回り**して見え、軸の表面は1回転のあいだに引っ張り⇄圧縮を**2往復**もします。同じ振幅でも、応力の反転がずっと速い。「後ろ向き振れ回りは見落とすと危険」と言われるのは、この意味です。

## Campbell線図への伏線

$F$ と $B$ に分ける分解には、もう1つ大きなご利益があります。振れ回りを前向き成分と後ろ向き成分に**分けて追跡できる**ことです。実はロータの[[omega_n|固有振動数]]も、回転数が上がると前向きモードと後ろ向きモードで**別々に**動いていきます（ジャイロ効果）。回転数とともにこの2本の枝がどう開いていくかを1枚に描いたのが、後で登場する[[link:campbell|Campbell線図]]です。この節のF/B分解は、その線図を読むための土台になります。

:::deep F/B分解の複素表現
平面の運動を複素数 $z = x + iy$ で書くと、振れ回りは

$$z(t) = F\,e^{i\theta} + B\,e^{-i\theta},\qquad \theta = \omega t$$

と表せます。第1項が反時計回り（前向き）の円、第2項が時計回り（後ろ向き）の円。実部と虚部を取り出すと、本文の $x=(F+B)\cos\theta,\ y=(F-B)\sin\theta$ にそのまま一致します。

- 楕円の長半径は $|F|+|B|$、短半径は $\big|\,|F|-|B|\,\big|$
- 向きは大きい方が勝ち：$|F|>|B|$ なら前向き、$|F|<|B|$ なら後ろ向き、$|F|=|B|$ で直線
- $F,\ B$ を位相つきの複素数にすると楕円が**傾き**ます（主軸の向きは2つの位相で決まる）

どんな楕円軌道も、この形に**ただ一通り**に分解できます。だから現場で測った $x,\ y$ の2つの波形から、計算で $F$ と $B$ を取り出せるのです。
:::

**模式・出典について**：上の図は平面振れ回りの標準的な前向き／後ろ向き分解（$z(t)=F e^{i\omega t}+B e^{-i\omega t}$）をそのまま動かした**模式**です。寸法は見やすさのためのスケールで、形と向きの関係は式どおりです。「後ろ向き同期振れ回りで軸表面の応力が 2Ω で交番する」ことは、回転座標系への変換（$\zeta = z\,e^{-i\Omega t}$）から従う古典的な結果です。
