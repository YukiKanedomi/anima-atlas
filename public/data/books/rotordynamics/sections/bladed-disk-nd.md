# 翼は一枚では揺れない——翼付き円盤と節直径

前の部では、翼を**一枚**取り出して、叩けば決まった高さの音で鳴ること、回せばその音が高くなること、そして誰がどんなリズムで翼を叩くのかを見てきました。ところが、本物のタービンでは翼は一枚では存在しません。何十枚もの翼が、一枚の**円盤**にぐるりと植わっています。ロケットのターボポンプのタービンも同じで、円盤のふちに同じ形の翼が等間隔に並んでいます。

ここで素朴な疑問が出ます。**一枚の翼を叩いたら、隣の翼はどうなるのでしょう？**

翼の根元はすべて同じ円盤につながっています。円盤は硬いとはいえ、ばねの性質を持った金属の板です。ある翼が揺れれば、その根元で円盤が少したわみ、たわみは隣の翼の根元を揺らします。つまり翼たちは、円盤という**共通のばね**を通して手をつないでいるのです。一枚の翼の「音」は、もはや一枚だけの性質ではなく、**翼と円盤の集団としての揺れ方**になります。これを **翼付き円盤（bladed disk）** と呼び、翼振動の本当の主役はこの集団です。

## 砂が教えてくれる「動かない線」

集団の揺れ方を言葉で言う前に、目で見る方法があります。平らな金属板に砂をまき、ふちをバイオリンの弓でこすって鳴らすと、砂が**動かない線**に集まって模様を描きます。18 世紀末にエルンスト・クラドニが本にして広めた実験で、**クラドニ図形**と呼ばれます（砂は振動している場所から弾き飛ばされ、静止している線＝**節線**に落ち着きます）。

円い板で同じことをすると、節線は 2 種類しか現れません。中心を通る**直径**と、中心を囲む**円**です。だから円板の揺れ方は、「動かない直径が何本あるか」と「動かない円が何本あるか」の 2 つの数で**番地付け**できます。前者を **[[ND|節直径]]（nodal diameter）の数 $n$**、後者を**節円（nodal circle）の数**と呼びます。

翼付き円盤では、翼はふちに並んでいるので、翼の揺れ方を決めるのはもっぱら**節直径の数 $n$** です。円周方向に見たとき、翼の変位が

$$a_j = \cos(n\theta_j), \qquad \theta_j = \frac{2\pi j}{N}$$

という形で並ぶ——これが節直径 $n$ のモードです。$N$ は[[N_b|翼の枚数]]、$j$ は翼の番号です。コサインがゼロになる方向が、動かない直径になります。

動かすと、次のことが見えてきます。

- **$n = 0$：アンブレラ。** 全部の翼が同時に同じ向きへ動きます。傘を開いたり閉じたりするような揺れで、動かない直径はありません。
- **$n = 1$：傾き。** 円盤の片側が上がり、反対側が下がる。これは円盤全体が**傾く**動きなので、軸の曲げと連成します。[[link:rigid-rotor-modes|剛体ロータの傾きモード]]や[[link:campbell|ジャイロ効果]]の話が、ここでつながります。
- **$n = 2, 3, \dots$：花びら。** 動かない直径が $n$ 本。翼の変位は円周に沿って $n$ 回うねります。
- **$n = N/2$：交互。** 隣同士の翼がぴったり逆向き。これより細かい「うねり」は、翼の並びでは**表現できません**。

## なぜ n は N/2 までしかないのか

最後の点は、この章の後半を支える大事な性質なので、立ち止まって考えてみます。

翼は $N$ 枚しかありません。連続した円盤なら $\cos(n\theta)$ の $n$ はいくらでも大きくできますが、私たちが見ているのは**翼の位置 $\theta_j$ での値だけ**です。$N$ 個の点で $\cos(n\theta)$ をサンプリングすると、$n$ と $N - n$ は**まったく同じ値の列**を与えます（三角関数の周期性から $\cos((N-n)\theta_j) = \cos(2\pi j - n\theta_j) = \cos(n\theta_j)$）。つまり翼の並びから見ると、$n = N/2$ を超えた「うねり」は、それより少ない $n$ のうねりと**区別がつかない**のです。

これは[[link:aliasing|フーリエの章で見たエイリアシング]]と同じ現象です。あちらは「時間を一定間隔で測ると、速すぎる波は遅い波に化ける」でした。こちらは「円周を一定間隔（翼）で見ると、細かすぎるうねりは粗いうねりに化ける」です。**空間のエイリアシング**と言ってよいでしょう。第III部では、この性質が ZZENF 線図の「ジグザグ」そのものになることを見ます。ここでは「翼が $N$ 枚なら、節直径は $0$ から $N/2$ まで」とだけ覚えておいてください。

## モードを数える：1 族に N 個

では、冒頭の予想「24 枚なら 24 個」はどう数えるのでしょう。

節直径 $n$ のモードには、$\cos(n\theta)$ 型と $\sin(n\theta)$ 型の**2 つ**があります。花びらの向きを少し回しただけの双子で、円盤は回転対称なので**固有振動数は同じ**です（数学では「重根」）。ただし $n = 0$ は $\sin(0) = 0$ で双子がおらず、$n = N/2$ も $\sin$ 型が全翼の位置でゼロになって消えます。数えると

$$1 \;(n=0)\;+\;2 \times \left(\tfrac{N}{2} - 1\right)\;+\;1\;(n = N/2) \;=\; N$$

で、ちょうど翼の枚数と同じ $N$ 個です（$N$ が奇数のときは $n = N/2$ が無い代わりに $1 + 2 \times \frac{N-1}{2} = N$ で、やはり $N$ 個）。

この $N$ 個は、翼の揺れ方としては全部同じ（たとえばすべて根元から曲がる 1F）で、違うのは**翼どうしの位相関係だけ**です。そこでこの $N$ 個をひとまとめにして **1 つのモード族（mode family）** と呼びます。翼の揺れ方が変われば（1F → 1T → 2F …）、族がもう 1 つ増え、やはり $n = 0 \sim N/2$ の $N$ 個を持ちます。実機のタービンでは、族がいくつも積み重なっています。

[[link:mode-shapes|軸の曲げモード]]では「1 次、2 次、3 次……」と**一列**に番号が付きました。円盤では「どの族か（翼の形）」と「節直径 $n$ はいくつか（翼どうしの位相）」の**二重の番地**で揺れ方が決まる——この違いが、翼振動を軸振動より少しややこしく、そして面白くしています。

## 双子が意味するもの

$\cos$ 型と $\sin$ 型が同じ振動数を持つことには、ひとつ重要な帰結があります。同じ振動数で位相だけ 90° ずれた 2 つの定在波を足すと、**走る波**になるのです（[[link:orbit-from-waves|軌道は 2 つの波からできている]]で、横の波と縦の波を足すと円軌道になったのと同じ数学です）。上の図のピルを「前向き進行波」「後ろ向き進行波」に切り替えると、花びらの模様が円盤の上を回っていくのが見えます。動かない直径も、一緒に回ります。

回っている翼付き円盤を揺らす力は、次の節で見るように「走る波」の形をしています。だから円盤の応答も、定在波ではなく**進行波**で考えるのが自然になります。この双子の存在が、その準備をしてくれているわけです。

:::deep 周期対称性がモードを節直径で整理する理由
翼付き円盤は、$N$ 枚の同じ**セクタ**（翼 1 枚＋円盤の $1/N$ 片）を円周に並べたものです。セクタ $j$ の変位ベクトルを $\mathbf{x}_j$ とすると、隣としかつながっていない構造の運動方程式は

$$\mathbf{M}\ddot{\mathbf{x}}_j + \mathbf{K}_0 \mathbf{x}_j + \mathbf{K}_c(\mathbf{x}_{j-1} + \mathbf{x}_{j+1}) = \mathbf{0}$$

の形になります（$\mathbf{K}_0$：セクタ自身の剛性、$\mathbf{K}_c$：隣との結合、添字は $N$ を法として巡回）。この「どのセクタから見ても同じ」という**周期対称性**のおかげで、解を円周方向のフーリエ級数

$$\mathbf{x}_j = \mathbf{u}_n\, e^{\,i\,2\pi n j/N}$$

の形に置くことができます。代入すると隣との項が $e^{\pm i 2\pi n/N}$ の因子になり、

$$\left[\mathbf{K}_0 + 2\mathbf{K}_c\cos\!\left(\frac{2\pi n}{N}\right) - \omega^2 \mathbf{M}\right]\mathbf{u}_n = \mathbf{0}$$

という、**1 セクタ分の大きさ**の固有値問題が節直径 $n$ ごとに独立に得られます。$N$ 枚まとめて解く必要がなく、$n = 0, 1, \dots, N/2$ について小さな問題を解けばよい——これが有限要素ソフトの**周期対称（cyclic symmetry）解析**の原理です。ANSYS ではこの $n$ を **harmonic index（調和指数）** と呼び、モードは harmonic index ごとに出力されます。

$e^{i 2\pi n j/N}$ の実部が $\cos(n\theta_j)$、虚部が $\sin(n\theta_j)$ で、これが本文の「双子」です。また $n \to N - n$ で $e^{i2\pi(N-n)j/N} = e^{-i 2\pi n j/N}$ となり、同じ固有値を与える——「節直径は $N/2$ まで」の式による確認です。結合 $\mathbf{K}_c$ が $\cos(2\pi n/N)$ を通して効くため、$n$ が増えるほど円盤の実効剛性が上がります。次々節のモード族曲線は、この式の 2 自由度版をそのまま描いたものです。
:::

:::history クラドニの砂、ナポレオンの賞金
砂で節線を見る実験そのものは、1680 年にロバート・フックがガラス板と小麦粉で観察したのが先です。それを体系化し、1787 年の著書『Entdeckungen über die Theorie des Klanges（音の理論に関する発見）』で円板・方形板の図形を大量に公表したのがクラドニでした。1808〜09 年にパリで公開実験を行うと、ナポレオンがこれを説明する数学理論に賞金を出し、ラグランジュやラプラス、ポアソンが審査に名を連ねました。唯一正しい方向を示したのがソフィー・ジェルマンで、不備を指摘されながらも板の振動理論の礎を築きます。クラドニ自身は、節直径の数 $m$ と節円の数 $n$ に対して振動数が $(m + 2n)^2$ に比例するという経験則（クラドニの法則）を残し、後にキルヒホッフがそれが高次モードでの漸近則であることを示しました。「動かない線で揺れ方を番地付けする」という本節の発想は、この 200 年来の系譜の上にあります。
:::

:::field 翼付き円盤の節直径は、どう見分けるか
実機の翼付き円盤を静止状態でハンマリングすると、1F 族の $N$ 個のモードは**ごく狭い振動数帯**に密集して現れます。どのピークがどの節直径かは、1 本のセンサでは分かりません。複数の翼にセンサ（ひずみゲージや非接触の変位計）を付け、**翼どうしの位相関係**を見て $\cos(n\theta_j)$ のうねりを当てはめるのが基本です。翼の数が多いほど $n$ の候補も多く、密集も激しくなるので、翼の数が 50 枚を超えるようなロータでは周期対称 FE 解析の結果と照合しながら同定します。後の節で扱う**ミスチューニング**（翼ごとの小さな違い）があると「双子」の振動数が割れ、モード形が純粋な $\cos(n\theta)$ から崩れるため、同定はさらに難しくなります。
:::
