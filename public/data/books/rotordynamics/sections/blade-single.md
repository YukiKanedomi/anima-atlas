# 一枚の板ばねから始める——翼の固有振動数とモード

定規を机の端に押さえて、はみ出した部分をはじいてみてください。「ビーン」と震えて、やがて止まります。はみ出す長さを短くすると音は高くなり、長くすると低くなる——誰でも一度はやったことのある遊びですが、実はこれがタービン翼の振動の、いちばん正直な模型です。

タービンの動翼は、根元を円盤（ディスク）にがっちり固定された**一枚の板ばね**です。流れの力で押され、たわみ、戻る。この「たわんで戻る」速さが翼の**固有振動数**で、翼振動の話はすべてここから始まります。これまでこの本で見てきた[[link:natural-frequency|固有振動数 √(k/m)]]や、[[link:mode-shapes|はりの曲げモード]]は、そのまま翼にも通用します。違うのは支え方だけ——軸は両端を支えられていましたが、翼は**片側だけ固定され、もう片側は自由**（片持ち）です。

## 揺れる「形」には名前がある

![根元を固定された翼の曲げとねじりの模式](data/books/rotordynamics/images/blade-single-1.jpg "イメージ図（生成画像・模式）：円盤に根元を固定された翼。破線は曲げ（しなり）とねじりの揺れ方。"){right}

図のモードを切り替えると、翼の揺れ方が変わります。

- **1F**（曲げ1次）：翼全体が根元を支点に**しなる**、いちばん単純で、いちばん低い振動数の形。振動数が低いぶん低い次数の励起と交わりやすく、実機で問題になることが多いモードです（ただし機種によっては 1T や 2F が主役になることもあります）。
- **2F**（曲げ2次）：途中に1か所、動かない点（**節**）ができて、根元側と先端側が逆向きに揺れます。振動数は 1F の約 **6.27 倍**。
- **3F**（曲げ3次）：節が2か所。振動数は約 **17.5 倍**。
- **1T**（ねじり1次）：翼が根元を軸に**ねじれる**形。曲げとは別系統の揺れで、振動数は翼の断面の形（厚さと幅の比）で大きく変わります。

このほか、翼弦（翼の幅）方向にしなる **1E**（エッジワイズ）や、幅の広い薄い翼で現れる板状の高次モード（ストライプモードと呼ばれることがあります）もあります。F・T・E という記号は「flap（またはflex）・torsion・edgewise」の頭文字で、業界や解析ソフトによって呼び方には揺れがあります。この本では、曲げを F、ねじりを T、幅方向の曲げを E と呼ぶことにします。

:::analogy @guitar ギターの弦の「倍音」と、翼のモード
ギターの弦をはじくと、弦全体が一山で揺れる基音のほかに、真ん中に動かない点を持つ二山の揺れ、三山の揺れ……が同時に鳴っています。これが倍音で、一本の弦に「揺れ方のメニュー」が何種類もあることの、いちばん身近な例です。翼の 1F・2F・3F はこのメニューにあたり、2F の「途中に動かない点（節）がある」のは、弦の二山の揺れと同じ姿です。ただし弦の倍音は 1 : 2 : 3 のきれいな整数比なのに対し、片持ちの板は 1 : 6.27 : 17.5 と、整数比になりません。弦は張力で戻るのに対し、板は曲げの硬さで戻るので、高い揺れ方ほど急に硬くなるからです。限界：弦の倍音は同時に鳴って一つの音色を作りますが、翼のモードはそれぞれ別の励起で別々に立ち、問題になるのはたいてい一つの模様だけです。
:::

大事なのは、**翼には揺れ方の「メニュー」が何種類もあり、それぞれに固有振動数がある**ということです。後の節で出てくる Campbell 線図や ZZENF 線図は、このメニューの一つひとつが励起に当たるかどうかを調べる地図です。

## 叩いて測る

![ハンマリング試験の模式](data/books/rotordynamics/images/blade-single-2.jpg "イメージ図（生成画像・模式）：根元を固定した翼を小さなハンマーで叩き、減衰していく波形を記録する。"){right}

固有振動数を知るいちばん手軽な方法は、**叩くこと**です。翼を小さなハンマーでコツンと叩き、加速度計やレーザーで揺れを拾うと、図の下段のような**減衰していく正弦波**が記録されます。1秒間に何回揺れたかが固有振動数、どれくらい早く消えたかが減衰の大きさです。叩く衝撃は広い振動数の成分を含むので、多くのモードが同時に励起され、記録をFFT（[[link:spectrum|スペクトル]]）にかけると、1F・1T・2F……の山が一度に並びます（ただし、叩く位置や向きによっては力が仕事をしないモードがあり、センサが節に当たっているモードは記録に現れません。叩く場所と測る場所を変えて確かめるのが作法です）。これを**ハンマリング試験**（ping test、打撃試験）と呼びます。

ただし、この方法で測れるのは**止まっている翼**の値です。回り始めると翼の固有振動数は変わります（次の節のテーマです）し、翼を円盤に植えてしまうと、一枚のときとは別の揺れ方も出てきます（第II部のテーマです）。叩いて測った値は出発点であって、答えではありません。

## 短く硬い翼ほど高い——ロケットの翼は kHz の世界

![蒸気タービンのロータに翼を差し込む作業](data/books/rotordynamics/images/blade-single-3.jpg "写真：蒸気タービンのロータに翼を取り付ける作業。奥の段ほど翼が長く、長い翼ほど固有振動数は低い。（Wikimedia Commons, Siemens Pressebild, CC BY-SA 3.0）"){right}

図の L と h のスライダーを動かすと、曲げの振動数の表示が $h/L^2$ に比例して動きます（ねじりは $h/L$。長さを半分にしても 2 倍にしかなりません）。一様な板ばねの固有振動数は

$$f_1 \;\propto\; \frac{h}{L^2}\sqrt{\frac{E}{\rho}}$$

で、**長さの2乗に反比例し、厚さに比例**します。ここで $E$ はヤング率（材料の硬さ）、$\rho$ は密度です。言葉にすると、**短く・厚く・硬く・軽い板ほど高く鳴る**、ということです。だから、長い定規は低く鳴り、短い定規は高く鳴る。

この関係を実機に当てはめてみます。長い翼ほど固有振動数は低く、発電用の大型蒸気タービンの最終段のように長さが 1 m 級に及ぶ翼では、定規の「ビーン」に近い数十〜百 Hz 台になることが多いと言われます（機種によって幅があります）。一方、ロケットエンジンのターボポンプを回すタービンの翼はまるで違う世界にいます。スペースシャトル主エンジン（SSME）の高圧燃料ターボポンプ（HPFTP）の第1段動翼は**長さ約 1 インチ（25 mm）、幅約 0.5 インチ**という小ささで、ポンプは毎分 37,000 回転（1 秒に 600 回転以上）で回り、タービン出力は 85,000 馬力に達します。この翼の固有振動数は、NASA の摩擦ダンパ研究報告によれば、曲げ1次が**約 4,500 Hz**、曲げ2次が**約 18,000 Hz**、ねじり1次が**約 11,000 Hz** でした。定規のビーンが数十 Hz なのに対し、ロケットの翼は**キロヘルツ**——音でいえば高い笛の音域で揺れているわけです。

:::analogy @jump-rope なぜ「小さいから安心」ではないのか——走る人と縄跳び
縄跳びの縄を回す人がいて、あなたはその前で跳んでいるとします。縄がゆっくり回るなら、あなたが速く跳んでも縄には当たりません。縄が速く回るほど、あなたの跳ぶリズムと縄のリズムが「同じくらい」になり、当たる危険が出てきます。翼の固有振動数は「跳ぶ速さ」、ノズルが翼を叩く速さは「縄の速さ」です。大きな翼はゆっくり跳ぶので、速い縄とは別世界にいて当たりにくい。小さな翼は速く跳ぶぶん、1 秒に何万回と回る縄と同じ速さの帯域に入ってしまいます。もちろん本当の共振は「当たる」ではなく「リズムがぴたりと合って揺れが育つ」ことですが、「速さの土俵が重なるかどうか」という点ではこの絵のとおりです。限界：縄は「当たる・当たらない」の二択ですが、共振は近づくほど連続的に大きくなる現象で、山の高さは減衰と励起の強さで決まります。
:::

小さく硬いことは、振動数が高いという以上の意味を持ちます。回転 1 周の間に翼を叩く回数（後で出てくる励起次数）が、翼の 1 回の揺れと同じくらい速くなりうるからです。たとえば 37,000 rpm（617 回転/秒）で、4,500 Hz の 1F を 1 周あたり 7〜8 回の叩きが捉えます。「翼が小さいから振動の心配は少ない」のではなく、「小さいからこそ、励起と同じ土俵に乗ってしまう」——これがロケットターボポンプの翼振動の出発点です。

## 根元の固定度で、固有振動数は変わる

もう一つ、この節で覚えておいてほしいことがあります。図の翼は根元を「完全に固定」していますが、本物の翼の根元はそうではありません。差込み式の翼では、**もみの木（ファーツリー）型**や**ダブテール型**の根を円盤の溝に差し込んで固定するため、根元には必ず少しの柔らかさ（コンプライアンス）があります。一方、翼と円盤を一体で削り出すブリスクでは根元の界面そのものがなく、拘束は強い代わりに摩擦で揺れを食う場所もありません。差込み翼では、根元が柔らかいほど固有振動数は下がり、隣の翼と台座（プラットフォーム）が触れ合えば上がります。

![断面展示されたターボプロップのタービン円盤と翼](data/books/rotordynamics/images/blade-single-4.jpg "写真：断面展示された Rolls-Royce Dart ターボプロップのタービン円盤と翼（一般的な例）。翼は根元で円盤に差し込まれている。（Wikimedia Commons, Olivier Cleynen, CC BY-SA 3.0）"){small}

:::analogy @guitar 弦を押さえる指の強さで、音程が変わる
ギターで弦を押さえるとき、指の力が弱いと音がにごり、音程も少し下がります。しっかり押さえて初めて、フレットで決まった音程が出ます。翼の根元も同じで、「どれだけしっかり固定されているか」で固有振動数が変わります。根元にわずかな遊びがあれば音程（固有振動数）は下がり、台座が隣と触れて動けなくなれば、揺れる部分が短くなったぶん音程は上がります。ギターなら音程のにごり程度ですが、翼では固定のしかたで固有振動数が 2 倍近く動くことがある、というのが下の実例です。限界：ギターでは指の力を自分で選べますが、翼の根元の固定度は遠心力と温度で運転中に勝手に変わり、設計者が直接つまめる量ではありません。
:::

SSME HPFTP の第1段動翼では、この「根元の条件」が実際に問題になりました。前述の NASA 報告によれば、設計時のモード解析で 1F は約 4,500 Hz とされていたのに、回転試験で **8,500 Hz 付近**に説明のつかない共振が見つかりました。これは当初ねじりモードと考えられましたが、のちに「翼の台座が隣と接触して動けなくなった状態で、翼型部分だけがしなる 1F」だと判明します。同じ翼でも根元の拘束条件が変わると固有振動数が 2 倍近く動く——翼振動を扱う人が最初に叩き込まれる教訓です。

:::deep 片持ちはりの固有振動数と振動数比——1 : 6.27 : 17.5 の出どころ
一様な片持ちはり（Euler–Bernoulli はり、長さ $L$、曲げ剛性 $EI$、単位長さ質量 $\rho A$）の曲げ振動の固有関数は

$$\psi_n(\xi) = \cosh(\beta_n L\,\xi) - \cos(\beta_n L\,\xi) - \sigma_n\left[\sinh(\beta_n L\,\xi) - \sin(\beta_n L\,\xi)\right],\qquad \sigma_n = \frac{\cosh\beta_n L + \cos\beta_n L}{\sinh\beta_n L + \sin\beta_n L}$$

言葉にすると、曲がり方の「形」は、根元がぴたりと固定され、先端が自由に揺れる、という条件に合うように 4 本の曲線を混ぜ合わせたもので、混ぜる割合 $\sigma_n$ はその条件だけで決まる、ということです。

で、$\xi = x/L$ は根元を 0、先端を 1 とした位置です。根元で変位と傾きがゼロ、先端で曲げモーメントとせん断力がゼロ、という境界条件から**振動数方程式**

$$\cos(\beta L)\cosh(\beta L) = -1$$

言葉にすると、「根元は動かず、先端には何の力もかからない」という両端の条件を同時に満たせる揺れ方は飛び飛びにしかなく、この式の解がその許された「音の高さ」の一覧表（メニュー）になっている、ということです。

が出ます。この根が $\beta_n L = 1.8751,\ 4.6941,\ 7.8548,\ \dots$ で、固有振動数は

$$f_n = \frac{(\beta_n L)^2}{2\pi L^2}\sqrt{\frac{EI}{\rho A}}$$

言葉にすると、同じはりの $n$ 番目の音は、根 $\beta_n L$ の 2 乗の分だけ 1 番目より高くなり、長さ・厚さ・材料の効き方（長さの 2 乗に反比例、曲げの硬さに比例）は 1 番目と同じ、ということです。

です。$(\beta_n L)^2$ の比をとると $1 : (4.6941/1.8751)^2 : (7.8548/1.8751)^2 = 1 : 6.27 : 17.5$。図の振動数比はこの計算そのものです。なお[[link:mode-shapes|軸のモード形状]]で見た単純支持（1 : 4 : 9）や自由–自由（1 : 2.76 : 5.40）とは比が違います。支え方が違えば、同じはりでもメニューが変わるのです。

矩形断面なら $I = bh^3/12$、$A = bh$ なので $\sqrt{EI/\rho A} = h\sqrt{E/12\rho}$ となり、$f_1 \propto h/L^2$ が出てきます。幅 $b$ は分子分母で消える——翼を幅広にしても曲げの固有振動数は変わりません（質量も剛性も同じ比で増えるため）。
:::

:::history 砂で見るモード——クラドニの図形
「物体が決まった形で振動し、動かない線（節線）を持つ」ことを最初に目に見える形で示したのは、18 世紀末のドイツの物理学者 E. F. F. クラドニです。金属板に砂をまき、縁をバイオリンの弓でこすると、砂は動かない節線に集まって幾何学模様を描きます。これが「クラドニ図形」で、翼や円盤のモード形を語るときの「節」という言葉はここに源流があります。第II部で出てくる円盤の**節直径**も、言ってみれば円盤のクラドニ図形です。
:::

:::field 叩いた値をそのまま使わない
ハンマリング試験の値は「静止・常温・その固定治具」での値です。実機では（1）回転による遠心力で曲げの固有振動数が上がる、（2）高温でヤング率が下がり固有振動数が下がる、（3）根元やシュラウドの接触状態で拘束条件が変わる、（4）円盤に植えると翼どうしが円盤を通じて連成する——という 4 つの理由で値が動きます。設計の現場では、静止試験の値を出発点に、回転試験（スピン試験）や回転中のひずみ計測で「本番の値」を裏取りするのが作法です。それぞれ、この後の節で順に扱います。
:::

## ひとことで

- 翼は根元を固定された板ばね。短く・厚いほど高く鳴り、ロケットの翼は笛のような kHz の高さで鳴る。
- 揺れ方には「しなる・ねじれる・二山でしなる」などのメニューがあり、それぞれに固有振動数がある。
- 叩いて測った値は「止まった翼・その固定具」での値。回ると変わり、根元の固定の強さでも大きく変わる。

**模式・出典について**：図の曲げモードは一様な片持ちはり（Euler–Bernoulli）の固有関数をそのまま描いたもので、形・節の位置・振動数比（1 : 6.27 : 17.5）は式どおりです。ねじり 1T は一様な棒の片持ちねじり 1 次（$\sin(\pi\xi/2)$）を見立てとして描いた模式で、振動数の表示値（1F の 2.6 倍）も模式値です。実際の翼は先細り・ねじれ・翼型断面を持つため、絶対値は有限要素解析や試験で決めます。「叩いた波形」は減衰比 0.02 の減衰正弦波です。
