# 窓とリーケージ——切り取り方の作法

![切り取った波の端を、なめらかに絞る](data/books/rotordynamics/images/leakage-2.jpg "イメージ図（生成画像・模式）：長い波から一区間を四角く切り出したもの（左）と、同じ区間の両端をなめらかにゼロへ絞ったもの（右）。右の釣り鐘形の線が「窓」の形。"){right}

曲のフェードアウトを思い出してください。終わりで音量をすっと絞るのは、演奏を途中でぷつりと切ると耳障りな「プツッ」が鳴るからです。写真でも、はさみでまっすぐ切った端と、ぼかして溶かした端では印象がまるで違います。信号を扱う計測でも、同じ「切り口」の問題がついて回ります。

[[link:dft-probe|「掛けて、平均する」の節]]の最後に、ピークの足元の**にじみ**は「有限の窓の副作用」だと予告しました。その伏線をここで回収します。計測では、無限に続く波を**有限の長さで切り取る**しかありません。この切り取った区間を**窓**と呼びます。そして FFT には、一つ思い込みがあります。**「窓の中身が、窓の外でも延々と繰り返されている」**とみなして計算するのです。この思い込みが、切り方しだいで牙をむきます。

## 段差は「そこにない周波数」のかたまり

スライダーを 8.00 に合わせると、つなぎ目はぴたりと滑らかで、スペクトルは1本にすっと立ちます。8.50 にずらすと、つなぎ目で波が**折れ曲がり**ます（8.5 往復では値はちょうどゼロで合いますが、上りと下りがぶつかって傾きが反転します）。8.3 のような値にすると、値そのものが飛ぶ**段差**になります。どちらも、波形の途中に本来ない角や崖を作ったのと同じです。

角や崖のような急な変化は、[[link:fourier-synthesis|最初の節]]で見たとおり**高い成分をたくさん含みます**（値が飛ぶ波ほど裾が長い、の極端な形）。つまり段差や折れの正体は「そこに実在しない周波数の詰め合わせ」です。それがスペクトルに漏れ出す。これが**リーケージ（漏れ）**です。

たちの悪いことに、実測で回転数が窓にぴったり整数回おさまることは、まずありません。発電機の 3,000 rpm は 50 Hz ちょうどに見えて、実際は負荷で少しずれますし、ファンやポンプの回転数は小数点以下まで揃いません。**リーケージは例外ではなく日常**です。

:::analogy @curtain-window カーテンを勢いよく閉めるか、そっと引くか
窓に差し込む光を、カーテンで一気に遮ると、部屋の明るさは一瞬で「カクン」と落ちます。そっと引けば、明るさはなだらかに下がります。信号の切り取りも同じで、四角い窓（矩形窓）は「カクン」の切り口を作り、その急変が偽の高い周波数を生みます。端をなだらかに絞る窓（Hann 窓など）は「そっと引くカーテン」で、切り口の急変そのものを消してしまいます。限界：カーテンをそっと引くと、そのあいだ部屋の明るさは中途半端になります。信号でも、絞った端の情報は薄まって使われず、そのぶん山の幅が太ります。
:::

## FFT の思い込み——窓の中身が繰り返されている

なぜ「つなぎ目」が問題になるのか、もう一段だけ掘ります。長さ $T$ の記録を FFT にかけると、出てくる周波数は $k/T$（$k = 0, 1, 2, \ldots$）という**とびとびの目盛り**だけです。目盛りがとびとびだということは、FFT が「この記録は周期 $T$ で永遠に繰り返す」と仮定していることと同じです。周期 $T$ の波は $k/T$ の成分しか持てないからです。

$$f_k = \frac{k}{T}, \qquad k = 0, 1, 2, \ldots$$

言葉にすると、FFT の周波数の目盛りは「記録の長さの逆数」を単位に刻まれていて、その目盛りの上に乗る成分しか表せない、ということです。真の周波数が目盛りの上（窓に整数回）に乗っていれば一本で表せますが、目盛りの間（半端な回数）に落ちると、周りの目盛りを総動員して「近い形」を作るしかなく、それが裾として見えます。

:::analogy @radio 隣の放送局の音がかぶる
ラジオで弱い局を聞いていると、隣の強い局の音がかすかにかぶってくることがあります。スペクトルの裾も同じで、強い成分の裾が隣の弱い成分の上にかぶさり、弱い方を覆い隠します。回転機械では 1× の不釣り合いがたいてい一番強いので、その裾が広いと、すぐそばにいる小さなピーク（たとえば [[link:oil-whirl-whip|0.43× のホワール]]の芽）が読めなくなります。限界：ラジオのかぶりは電波の重なりで起きますが、リーケージは計測側の切り取りが作る偽物で、機械の中には存在しません。窓を変えれば遠くの裾は大きく抑えられます（山の幅との引き換えで、ゼロにはなりません）。
:::

## 対策：端をそっと絞る——Hann 窓

![Hann 窓の形と、そのスペクトル](data/books/rotordynamics/images/leakage-3.jpg "図：Hann 窓の形（上）と、その窓だけを FFT したときの周波数応答（下、対数目盛り）。中央の山が「主ローブ」、両側に並ぶ小さな山が「サイドローブ」で、遠ざかるほど急速に低くなる。（Wikimedia Commons, Bob K, CC0）"){small}

切り口の段差が犯人なら、**切り口をなくせばいい**。窓の両端で信号をなめらかにゼロへ絞り込んでから変換します。この絞りの形が**窓関数**で、定番が **Hann 窓**です。形は一周期の余弦を持ち上げただけの、単純な釣り鐘です。

$$w(t) = \frac{1}{2}\left(1 - \cos\frac{2\pi t}{T}\right), \qquad 0 \le t \le T$$

言葉にすると、窓の真ん中で 1、両端でちょうど 0 になる、なめらかな山の形を記録に掛け算してから FFT する、ということです。両端が 0 なので、どんな半端な切り方をしても「つなぎ目」は必ず 0 と 0 の接続になり、値の段差が生まれず、傾きの折れも窓の端で押しつぶされて小さくなります。

ブロックで Hann に切り替えてみてください。つなぎ目の段差が消え、遠くの裾が**激減**します（この例で約 80 分の 1）。ただし**代償**もあります。山の幅が少し太るのです。端の情報を捨てるぶん、周波数の切れ味がわずかに鈍る。にじみと引き換えの、フェアな取引です。

![Julius von Hann の肖像](data/books/rotordynamics/images/leakage-1.jpg "写真：Julius von Hann（1839〜1921）。オーストリアの気象学者で、Hann 窓の名前の由来。（Wikimedia Commons, Josef Löwy, パブリックドメイン）"){small}

:::history 気象学者の名前がついた窓——「ハニング」は誤用
Hann 窓の名は、オーストリアの気象学者 Julius von Hann（1839〜1921）に由来します。Hann は「近代気象学の父」の一人とされ、1877 年にウィーンの中央気象研究所の所長になり、『気候学ハンドブック』（1883 年初版）を著した人物で、信号処理とは縁がありません。彼が気象データを隣の地点と 1/4・1/2・1/4 の重みでならす平滑化を考案し、1958 年に Blackman と Tukey がスペクトル推定の本でその重みを窓として借用し、「hanning（ハンする）」という動詞で呼んだのが始まりです。そこから「ハニング窓」という呼び名が広まりましたが、Harris は 1978 年の窓関数の総説で「正しい名前は Hann である」と注意しています。似た名前の Hamming 窓は別人（Richard Hamming）の考案で、混同しやすいので注意してください。
:::

## 窓の使い分け——幅・裾・振幅の三つどもえ

窓は Hann だけではありません。どの窓も「山の幅」「裾の低さ」「振幅の正確さ」のどれかを犠牲にして、どれかを得ています。Harris の 1978 年の総説が、この取引を一覧表にして示した古典です。

- **矩形窓**（そのまま切る）：山は一番細い（切れ味は最高）。しかし最初のサイドローブは約 −13 dB しか下がらず、裾は 1 オクターブあたり 6 dB という緩い傾きで遠くまで漏れます。
- **Hann 窓**：山の幅は矩形の約 2 倍。最初のサイドローブは約 −31 dB、裾は 1 オクターブあたり 18 dB で急降下します。万能の既定値で、振動診断は基本これです（本書の[[link:spectrum|スペクトル]]ブロックも Hann です）。
- **フラットトップ窓**：山の頂上が平らになるように設計された窓。山はさらに太りますが、ピークの**振幅**を目盛りのずれに関係なく正確に読めます。校正や振幅重視の測定向けです。

:::analogy @ruler 目盛りの太い定規と細い定規
細い目盛りの定規は長さを精密に読めますが、目盛りの線が細すぎると、線の上に乗ったかどうかの判定が難しくなります。太い目盛りの定規は読み取りは楽ですが、精密さは落ちます。窓関数の選択も同じで、矩形窓は「細い目盛り」で周波数を精密に分けられる一方、裾が長く隣を汚します。フラットトップ窓は「太い目盛り」で、振幅を読み間違えない代わりに周波数の分離は甘くなります。限界：定規は長さ一つを測る道具ですが、窓は「周波数の分離」「裾の低さ」「振幅の正確さ」という三つを同時に取引しています。
:::

## ピケットフェンス効果——目盛りの間に落ちた山

![板塀のすき間から見える尖った山](data/books/rotordynamics/images/leakage-4.jpg "イメージ図（生成画像・模式）：板塀（目盛り）のすき間から山を見ると、頂上が板の裏に隠れて、両肩しか見えないことがある。"){right}

リーケージにはもう一つの顔があります。真の周波数が二つの目盛りのちょうど中間に落ちると、スペクトルの山の**頂上**が目盛りの間に隠れ、両側の目盛りに「肩」だけが現れます。板塀（ピケットフェンス）のすき間から景色をのぞくと、ちょうど板の裏にある物が見えないのと同じで、**ピケットフェンス効果**と呼びます。

このとき読み取れる振幅は、真の値より小さくなります。矩形窓では最悪で約 3.9 dB（振幅で約 36 % 減）、Hann 窓では約 1.4 dB（約 15 % 減）です。Hann 窓の山が太いのは、ここでは長所に転じます。太い山は目盛りの間に落ちても肩が高いからです。フラットトップ窓はこの損失をほぼゼロにするために山の頂上を平らにした窓で、「振幅を正確に読む」とはこの効果を消すことを指します。

振動診断で 1× の振幅を規格値（[[link:standards-intro|ISO 20816 のゾーン]]）と比べるときは、この効果だけで判定が変わることがあります。目盛りの間に落ちた 1× を矩形窓で読めば 3 割以上小さく見える、という話ですから、軽視できません。

:::field 現場の窓選び——三つの定番
- **診断の既定値は Hann**：不釣り合い・ミスアライメント・油膜不安定の切り分けなど、「どの周波数にピークがあるか」を見る用途では Hann が標準です。測定器の初期設定もたいてい Hann です。
- **振幅を規格と比べるならフラットトップ**：校正や、1× の振幅を数値として記録する用途では、ピケットフェンス効果を消せるフラットトップに切り替えます。
- **窓に同期できるなら矩形**：記録の長さを回転のちょうど整数回に合わせる回転同期サンプリング（[[link:order-reading|次数の節]]）では、つなぎ目がもともと滑らかなので矩形窓が最強になります。インパクトハンマによる打撃試験（[[link:multi-critical|モード試験]]）では、打撃後に減衰しきる長さの窓を取れば矩形窓で足り、減衰しきらない場合は指数窓で端を絞ります。
どの窓にも「山の幅 × 裾の低さ × 振幅の正確さ」の取引があり、**全部に勝てる窓は存在しません**。
:::

:::deep 裾の正体と、減衰の速さ
矩形窓のスペクトルは $\mathrm{sinc}$ 関数の形の裾を引き、振幅は周波数差に対して $1/\Delta f$ でしか減りません。だから遠くまで漏れます。Hann 窓は端の絞りによって裾の減衰が $1/\Delta f^3$ に速まり、遠方が桁違いに静かになります。そのかわり主ローブ（山の幅）は矩形窓の約 2 倍です。

$$\text{矩形窓の裾} \propto \frac{1}{\Delta f}, \qquad \text{Hann 窓の裾} \propto \frac{1}{\Delta f^{3}}$$

言葉にすると、矩形窓の裾は周波数差が 2 倍になっても半分にしか減らないのに対し、Hann 窓の裾は 8 分の 1 に減る、ということです。これが「1 オクターブあたり 6 dB」と「18 dB」の意味です。一般に、窓の端で何階微分まで連続かが裾の減衰の速さを決めます。矩形窓は値そのものが不連続（0 階）、Hann 窓は値と 1 階微分が連続で 2 階微分が不連続なので、裾の減衰は $1/\Delta f^{3}$ になります。
:::

## ひとことで

- 有限の記録を FFT すると「窓の中身が繰り返す」とみなされ、半端な切り方は**つなぎ目の段差や折れ**を生む。
- つなぎ目の不連続は「そこにない周波数の詰め合わせ」で、スペクトルに裾として漏れる（**リーケージ**）。
- **Hann 窓**は両端をなめらかに絞ってつなぎ目の不連続を消す。裾は激減し（ゼロにはならない）、山の幅は約 2 倍になる。
- 窓の選択は「山の幅・裾の低さ・振幅の正確さ」の取引。診断は Hann、振幅読みはフラットトップ、回転同期なら矩形。
- 真の周波数が目盛りの間に落ちると山の頂上が隠れる（**ピケットフェンス効果**）。矩形窓で最大約 3.9 dB、Hann 窓で約 1.4 dB 低く読む。
- 名前は気象学者 Julius von Hann に由来し、「ハニング」は 1958 年の動詞用法から広まった誤用。

**模式・出典について**：ブロックのスペクトルは本物の FFT（Cooley–Tukey）による計算で、模式ではありません。f=8.5 のとき遠方の裾が矩形窓 0.017 → Hann 0.0002 に沈むこと、整数ちょうどで 1 本に立つことを独立検証済みです。矩形窓と Hann 窓のサイドローブ（約 −13 dB／約 −31 dB）、裾の減衰（6 dB／18 dB 毎オクターブ）、ピケットフェンス効果による最大損失（約 3.9 dB／約 1.4 dB）は Harris（1978 年、Proceedings of the IEEE 66 巻 1 号 51〜83 ページ）の窓の一覧表の値で、本文では概数で示しました。Julius von Hann の経歴（1839〜1921、1877 年中央気象研究所所長、『気候学ハンドブック』1883 年）と 1/4・1/2・1/4 の平滑化、Blackman と Tukey（1958 年）による「hanning」の用法、Harris による「正しい名前は Hann」の注意は Wikipedia「Julius von Hann」「Hann function」によります。Hann 窓の図は Wikimedia Commons（Bob K、CC0）、肖像は Josef Löwy 撮影（パブリックドメイン）。生成画像は「イメージ図」と明記し、事実は担わせていません。
