# ねじり振動——軸のもう一つの揺れ方

ここまでに見てきた揺れは、振れ回りも曲げモードも、ぜんぶ**横方向**——軸が中心線から外れる動きでした。でも軸には、もう一つばねが隠れています。**回転方向のばね**です。

ペットボトルのふたを閉めるとき、最後にぐっとねじる手応えがありますね。細長い軸も同じで、両端を逆向きにねじると、元に戻ろうとするばねとして働きます。そして実機の軸の両端には、**モータ**と**負荷**（ポンプや圧縮機の羽根車）という2つの重い回転体が付いています。この2つが軸をねじり合って震える——それが**ねじり振動**です。

このとき、軸のどこかに**まったくねじれない断面**が1つ現れます。曲げモードの「節」の、ねじり版です。

大事なのは、この揺れが**回転そのものの速度むら**だということです。軸の中心線はまったく動きません。外から見れば、軸はただ静かに回っているだけ。その回転の速さが、1回転の中でわずかに速くなったり遅くなったりを繰り返している——それがねじり振動の正体です。

## なぜ怖いのか——静かに育つ揺れ

ねじり振動が厄介なのは、**気づきにくく、育ちやすい**からです。

1. **外にほとんど漏れない。** 横の揺れなら軸受を通して振動がケーシングに伝わり、音も出ます。ところがねじり振動は回転方向の揺れなので、**軸受にはほとんど力を伝えません**。いつもの振動計を当てても静かなまま——見張り番の目をすり抜けるのです。
2. **減衰がとても小さい。** 横の揺れでは[[link:whirl-instability|軸受の油膜]]が優秀なダンパとして働きますが、回転方向には油膜がほぼ効きません。摩擦の少ないねじりの世界では、一度励起された揺れが**なかなか消えず、育ちやすい**のです。
3. **励起源がそこら中にある。** 電動機の電気トルクの脈動、往復圧縮機やエンジンのトルク変動、インバータ（VFD）駆動の高調波、歯車のかみ合い——どれも回転方向を直接叩く力です。これらの周波数がねじりの[[omega_n|固有振動数 ωn]]と重なると、静かに共振が始まります。

そして気づいたときには、**軸継手のゴム要素がちぎれていたり、歯車の歯面が傷んでいたり、軸にねじりの疲労亀裂**が入っていたりします。壊れて初めて存在に気づく——ねじり振動の事故報告に繰り返し出てくるパターンです。

## どうやって測るのか

横の揺れと違って、ねじり振動の計測はひと手間かかります。代表的なのは、軸に貼った**ひずみゲージ**でねじりのひずみを直接測る方法（回転体からの信号取り出しにテレメトリが要ります）と、**エンコーダや歯車のパルスから回転の速度むら**を読み取る方法です。「回転が速い・遅いを細かく繰り返していないか」を見るわけで、発想としては[[link:order-reading|回転同期の計測]]の親戚です。

:::deep 2慣性モデルの式とモード
モータの慣性を $I_1$、負荷の慣性を $I_2$、軸のねじり剛性を $k_t$ とし、それぞれのねじれ角を $\theta_1,\ \theta_2$ とすると、

$$I_1\ddot\theta_1 = -k_t(\theta_1-\theta_2),\qquad I_2\ddot\theta_2 = -k_t(\theta_2-\theta_1)$$

固有値問題を解くと、モードは2つ。1つは $\omega=0$ の「全体が一緒に回る」剛体回転（ねじれなし）。もう1つが本題のねじりモードで、

$$\omega_n=\sqrt{k_t\left(\frac{1}{I_1}+\frac{1}{I_2}\right)},\qquad \frac{\theta_1}{\theta_2}=-\frac{I_2}{I_1}$$

つまり2つの円板は**必ず逆向き**にねじれ、振幅の比は慣性の逆比。ねじれ角がゼロになる節は、モータ端から $x/L = I_2/(I_1+I_2)$——**慣性の大きい側に寄る**ことが式からも読めます。慣性が3つ以上並ぶ実機のねじり系も、[[link:rigid-rotor-modes|剛体2モードの節]]でやったのと同じ流儀で、質量行列と剛性行列を立てて固有値を解くだけです。
:::

## 曲げの地図と、ねじりの地図

流れとしては[[link:rigid-rotor-modes|剛体の2モード]]と同じ「モードと節」の話ですが、揺れる方向がちがう別世界——固有振動数も励起源も、曲げとは**別の地図**になります。だからねじりにも、[[link:campbell|Campbell線図]]とそっくりの図があります。横軸に回転数、横に走るねじり固有振動数の線、そこへ電気脈動や歯車かみ合いなどの**励起次数の斜め線**を重ねて、交点＝共振点を運転範囲から外す。回転機械の設計では、曲げの危険速度と並んで、この**ねじりの共振チェック**が必ずセットで行われます。

**模式・出典について**：図は両端に慣性をもつ一様軸の標準的な**2慣性ねじりモデル**の模式です。固有振動数・モード形・節の位置はいずれも上の式のとおりで、ねじれ角の大きさだけ見やすさのため誇張しています。ねじり振動の評価・計測の実務は API 684（ロータダイナミクスのチュートリアル）や各機種規格に整理されています。
