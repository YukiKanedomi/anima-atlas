# N枚の翼が空間でサンプリングする——励起次数の折り返し

[[link:family-curves|前の節]]で、翼付き円盤のモードが「節直径 [[ND|n]]」という番号で整理できること、そして各モードの周波数が n ごとに決まることを見ました。この節は、もう一方の主役——**揺らす側**——を同じ言葉で整理します。ノズルの後流や部分噴射が作る圧力の波は、翼の列からはどんな「節直径」に見えるのか。答えは意外なほど単純で、しかも[[link:aliasing|フーリエの目の章で見たエイリアシング]]と**まったく同じ構造**をしています。

## 扇風機のストロボ、翼のストロボ

扇風機の羽根を蛍光灯の下で見ると、ゆっくり逆回りに見えることがあります。羽根は速く回っているのに、光が1秒に100回しか点かないので、目は「飛び飛びの瞬間」しか見ていない。その飛び飛びの瞬間をつなぐと、本当の回転とは違う、遅い（あるいは逆向きの）回転が見える——フーリエの章で扱った**ワゴンホイール効果**です。

翼付き円盤にも、これとそっくりなことが起きます。ただし、飛び飛びなのは**時間**ではなく**場所**です。円盤の周りには [[N_b|N]] 枚の翼が等間隔に並んでいて、流れの圧力を「感じる」のはその N か所だけ。翼と翼の間の空間に、どんなに細かい圧力の山や谷があっても、翼はそこにいないので感じません。つまり翼の列は、円周上の圧力パターンを **N 点で標本化（サンプリング）する装置**なのです。

[[link:blade-excitation|第I部]]で、励起は「回転1周あたり何回叩かれるか」という次数 [[EO|k]] で整理できることを見ました。たとえばノズルが Ns 枚あれば、翼は1周に Ns 回叩かれるので k = Ns。円周方向に見ると、これは $\cos(k\theta)$ という**山が k 個ある圧力パターン**です。問いはこうです。山が k 個のパターンを、N 枚の翼が標本化すると、翼の列には**山がいくつのパターン**に見えるのでしょうか。

## 折り返しの規則

上の図で k をゆっくり増やしてみてください。k が 0 から N/2 までは、見える節直径 n は k と同じです（細線と太線が重なったまま）。ところが k が N/2 を超えると、**太線の山の数が減り始めます**。k = N で太線は山ひとつもない平らな線（全翼が同じ向きに押される＝節直径 0）、k = N + 1 でまた山 1 個——つまり k が N を超えると、**k = 1 の場合と区別がつかない**のです。

規則を式で書くとこうなります。

$$n \;=\; \min\!\big(\,k \bmod N,\; N - (k \bmod N)\,\big)$$

k を N で割った余りを取り、それが N/2 を超えていたら N から引く。結果は必ず $0 \le n \le N/2$ の範囲に収まります。これが「k 次の励起は、N 枚の翼には節直径 n のパターンに見える」という**折り返し（fold）の規則**です。

なぜこうなるかは、三角関数の等式ひとつで確かめられます。翼 j の位置は $\theta_j = 2\pi j/N$ です。k を $k = mN + n$（m は整数）と書けるとき、

$$\cos(k\theta_j) = \cos\!\Big(2\pi m j + \frac{2\pi n j}{N}\Big) = \cos(n\theta_j)$$

となります。$2\pi m j$ はちょうど整数回転なので消えるのです。$k = mN - n$ のときも、$\cos$ が偶関数なので同じ結果になります。**翼の位置では k 次と n 次のパターンは値がまったく同じ**——だから翼には区別がつかない、というわけです。

## エイリアシングと同じ構造

[[link:aliasing|フーリエの章]]で見た規則を思い出してください。標本化周波数 [[fs|fs]] で f の波を測ると、$f' = |f - m f_s|$ の見かけの周波数に化け、結果は $0 \le f' \le f_s/2$（ナイキスト周波数）に折り返されました。

ここでの規則は、$f \to k$、$f_s \to N$ と読み替えただけです。

- 時間のエイリアシング：標本化周波数 fs、折り返しの境界は fs/2。
- 空間のエイリアシング：標本化の「周波数」は翼の枚数 N、折り返しの境界は **N/2**。

節直径が N/2 までしか存在しないことは[[link:bladed-disk-nd|第II部]]でも触れましたが、その理由はまさにこれです。N 点でしか測れないものに、N/2 より細かい山を「見る」ことはできない。NASA の翼振動の報告書は、この対応表を文字どおり「空間エイリアシング表（spatial aliasing chart）」と呼び、ノズル枚数の整数倍と翼枚数の整数倍の差から励起される節直径を求めています。

## ジグザグの正体

下の散布図は、横軸に励起次数 k、縦軸に見える節直径 n を取ったものです。k を 0 から増やすと、n は 0 → N/2 まで上がり、そこで折り返して 0 まで下がり、また上がる——**ジグザグ**になります。

この絵を、頭の片隅に焼き付けておいてください。次の節で登場する ZZENF 線図は、縦軸を「節直径」から「周波数」に替え、各 k の点を励起周波数 $k\Omega$ の高さに置き直しただけのものです。ジグザグの形はそのまま受け継がれ、線図の名前（Zig-Zag shaped Excitation line）にもなっています。

いくつかの k は特別な意味を持ちます。

- **k が N の倍数**（k = N, 2N, …）：n = 0。全部の翼が**同時に同じ向き**に押されます。円盤が傘のように開閉するアンブレラモード（節直径 0）を揺らす励起です。
- **k = N/2**（N が偶数のとき）：n = N/2。**隣り合う翼が逆向き**に押されます。これは翼の列が持てる最も細かいパターンです。
- **k = N ± 1**：n = 1。円盤が**傾く**ように揺れるモード（節直径 1）を揺らします。節直径 1 のモードは軸の曲げと連成するので、設計では特に気にする組合せです（[[link:zzenf-design|設計の節]]で扱います）。

## 「回転1周に N 回」と「翼の枚数 N」が同じ数なのは偶然ではない

励起次数 k は[[link:blade-excitation|「回転1周あたりに叩かれる回数」]]として導入しました。一方、折り返しの N は翼の枚数です。この二つが同じ土俵で引き算される（k − mN）のは、どちらも「円周を何等分するか」という**同じ量**だからです。

ノズル列は固定されていて、翼列が回ります。回転系から見れば、Ns 枚のノズルの後流は「1周に Ns 回やってくる叩き」であると同時に、「円周上に Ns 個の山が並んだ圧力パターン」でもあります。時間と空間が、回転によって結びついているのです。[[link:traveling-waves|立つ波と走る波の節]]で見た「静止系の固定パターンが回転系では進行波になる」が、まさにこの結びつきでした。

:::deep 標本化定理との対応——なぜ N/2 で止まるのか
翼の列の変位を $u_j$（j = 0, …, N−1）とします。これは N 個の数の並びなので、離散フーリエ変換（[[link:dft-probe|DFT]]）で

$$u_j = \sum_{n=0}^{N-1} U_n\, e^{\,i\,2\pi n j/N}$$

と書けます。この和の n は N 個しかなく、しかも $n$ と $N - n$ は互いに複素共役の組（実数の変位では $U_{N-n} = \overline{U_n}$）なので、独立な「形」は $n = 0, 1, \dots, \lfloor N/2 \rfloor$ の $\lfloor N/2 \rfloor + 1$ 通りだけです。これが「節直径は 0 から N/2 まで」の数学的な意味です。

励起側も同じです。翼 j が受ける力 $F_j = F_0 \cos(k\theta_j - \omega t)$ を同じ DFT で分解すると、成分は $n \equiv \pm k \pmod N$ の一か所にしか立ちません。**力が持つ「形」は節直径 fold(k, N) ただ一つ**——だから、その節直径を持たないモードには（線形理論の範囲では）仕事をまったくしません。これが次の節の「共振の二重条件」の根拠になります。

Tyler と Sofrin が 1961 年に圧縮機の騒音の研究でこの「動翼枚数と静翼枚数の整数倍の差」の規則を示して以来、回転機械の翼列の相互作用は**Tyler–Sofrin モード**の名で呼ばれています。翼振動でも音響でも、根っこは同じ空間エイリアシングです。
:::

:::field 実機の数字で折り返してみる
スペースシャトル主エンジン（SSME）の高圧燃料ターボポンプのタービンは、初段が静翼 41 枚・動翼 63 枚、2段目が静翼 39 枚・動翼 59 枚です（Biggs の開発史より）。この数字を折り返しの規則に入れてみましょう。

- 初段：k = 41 → n = 63 − 41 = **22**。2倍の k = 82 → 82 − 63 = **19**。3倍の k = 123 → |123 − 126| = **3**。
- 2段目：k = 39 → n = **20**。k = 78 → 78 − 59 = **19**。k = 117 → |117 − 118| = **1**。

3倍高調波で初段は節直径 3、2段目は節直径 **1**（軸の曲げと連成する番号）に落ちることが分かります。ノズル通過の基本波（k = Ns）だけ見ていると見落とす組合せです。なお Dominic の摩擦ダンパ研究によれば、この初段では 13 本の軸受支持ストラットが 13 枚のノズルと**不等間隔**に整列しており、ノズル後流の圧力パルスは一様ではありません。つまり実際の励起は「k = 41 の純音」ではなく多くの次数を含み、折り返し表の**多くの行が同時に生きる**ことになります。

J-2X エンジン（NASA の上段用エンジン）の燃料ターボポンプタービンでは、動翼 69 枚に対して上流ノズル 37 枚・下流静翼 57 枚で、NASA の解析報告は「下流静翼が節直径 12 を励起する」と空間エイリアシング表で示しています。折り返しの規則で確かめると 57 → 69 − 57 = 12 で一致します（上流は 37 → 32、2倍の 74 → 5）。
:::
