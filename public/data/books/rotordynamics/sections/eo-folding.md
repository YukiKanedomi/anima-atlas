# N枚の翼が空間でサンプリングする——励起次数の折り返し

[[link:family-curves|前の節]]で、翼付き円盤のモードが「節直径 [[ND|n]]」という番号で整理できること、そして各モードの周波数が n ごとに決まることを見ました。この節は、もう一方の主役——**揺らす側**——を同じ言葉で整理します。ノズルの後流や部分噴射が作る圧力の波は、翼の列からはどんな「節直径」に見えるのか。答えは意外なほど単純で、しかも[[link:aliasing|フーリエの目の章で見たエイリアシング]]と**まったく同じ構造**をしています。

## 扇風機のストロボ、翼のストロボ

![1920年ごろの電気扇風機](data/books/rotordynamics/images/eo-folding-1.jpg "写真：1920 年ごろの GE 製扇風機（フランクリン研究所所蔵）。蛍光灯やストロボの下で回る羽根が止まって見えたり逆回りに見えたりするのが、この節の入口。（Wikimedia Commons, Daderot, パブリックドメイン）"){right}

扇風機の羽根を蛍光灯の下で見ると、ゆっくり逆回りに見えることがあります。羽根は速く回っているのに、光が1秒に100回しか点かないので、目は「飛び飛びの瞬間」しか見ていない。その飛び飛びの瞬間をつなぐと、本当の回転とは違う、遅い（あるいは逆向きの）回転が見える——フーリエの章で扱った**ワゴンホイール効果**です。

翼付き円盤にも、これとそっくりなことが起きます。ただし、飛び飛びなのは**時間**ではなく**場所**です。円盤の周りには [[N_b|N]] 枚の翼が等間隔に並んでいて、流れの圧力を「感じる」のはその N か所だけ。翼と翼の間の空間に、どんなに細かい圧力の山や谷があっても、翼はそこにいないので感じません。つまり翼の列は、円周上の圧力パターンを **N 点で標本化（サンプリング）する装置**なのです。

[[link:blade-excitation|第I部]]で、励起は「回転1周あたり何回叩かれるか」という次数 [[EO|k]] で整理できることを見ました。たとえばノズルが Ns 枚あれば、翼は1周に Ns 回叩かれるので k = Ns。円周方向に見ると、これは $\cos(k\theta)$ という**山が k 個ある圧力パターン**です。問いはこうです。山が k 個のパターンを、N 枚の翼が標本化すると、翼の列には**山がいくつのパターン**に見えるのでしょうか。

![レコードプレーヤのストロボ円板](data/books/rotordynamics/images/eo-folding-2.jpg "写真：レコードプレーヤの回転数を合わせるストロボ円板。点滅する光の下では、模様が止まって見える回転数がある。飛び飛びに「見る」と本当の動きとは別の動きが見える、身近な例。（Wikimedia Commons, P.Sasonoff, CC BY-SA 4.0）"){small}

## 折り返しの規則

![翼が圧力の波を飛び飛びに見る模式図](data/books/rotordynamics/images/eo-folding-3.jpg "イメージ図（生成画像・模式）：円周に沿って走る本当の圧力の波（臙脂）を、翼は翼の位置（紺の点）でしか「見る」ことができない。点をつなぐと、本物よりずっとゆるい波（破線）に見える。"){right}

上の図で k をゆっくり増やしてみてください。k が 0 から N/2 までは、見える節直径 n は k と同じです（細線と太線が重なったまま）。ところが k が N/2 を超えると、**太線の山の数が減り始めます**。k = N で太線は山ひとつもない平らな線（全翼が同じ向きに押される＝節直径 0）、k = N + 1 でまた山 1 個——つまり k が N を超えると、**k = 1 の場合と区別がつかない**のです。

規則を式で書くとこうなります。

$$n \;=\; \min\!\big(\,k \bmod N,\; N - (k \bmod N)\,\big)$$

言葉にすると、翼は N 枚しかないので、N 周期ぶんの山は数えられず「余り」の分だけが模様として残り、その余りが半周を超えるときは逆向きに数えたほうが近い、ということです。

k を N で割った余りを取り、それが N/2 を超えていたら N から引く。結果は必ず $0 \le n \le N/2$ の範囲に収まります。これが「k 次の励起は、N 枚の翼には節直径 n のパターンに見える」という**折り返し（fold）の規則**です。

符号まで含めるなら、[[link:traveling-waves|第II部]]で定義した**符号付きの折り返し次数** [[q_signed|q]]（k を N で割った余りを $-N/2 < q \le N/2$ に巻き戻した値）を使います。$n = |q|$ で、$q$ の符号が進行波の向きです。fold の式は、この $q$ の絶対値を取ったものにほかなりません。

:::analogy @clock 時計の文字盤で「何分前」と数える
時計の長針が 50 分を指しているとき、私たちは「50 分」とも「10 分前」とも言います。文字盤は 60 分で一周するので、50 分進むことと 10 分戻ることは**同じ位置**だからです。しかも「10 分前」の方が近い言い方です。折り返しの規則はこれと同じで、翼の列は N 枚で「一周」し、k 次の模様は「k を N で割った余り」の位置にあり、その余りが半分を超えていれば「逆から数えた方（N から引いた数）」の方が近い——その近い方が、翼の列に見える節直径 n です。時計では文字盤の目盛りが 60 個、翼では翼が N 枚、という違いだけです。ただし見落としがちな点が一つあります。「50 分」と「10 分前」は**位置は同じでも、針が進んできた向きは逆**です。折り返しも同じで、$k = 20$ と $k = 4$（$N = 24$）は翼の列に同じ山の数を見せますが、波の走る向きは逆——その向きを覚えているのが符号付きの $q$（この例では $q = -4$）です。
:::

なぜこうなるかは、三角関数の等式ひとつで確かめられます。翼 j の位置は $\theta_j = 2\pi j/N$ です。k を $k = mN + n$（m は整数）と書けるとき、

$$\cos(k\theta_j) = \cos\!\Big(2\pi m j + \frac{2\pi n j}{N}\Big) = \cos(n\theta_j)$$

言葉にすると、翼のある場所だけで値を読む限り、1 周に k 個の山を持つ波と n 個の山を持つ波はまったく同じ高さを示す——翼には山を数えそこなった波と本物の波の区別がつかない、ということです。

となります。$2\pi m j$ はちょうど整数回転なので消えるのです。$k = mN - n$ のときも、$\cos$ が偶関数なので同じ結果になります。**翼の位置では k 次と n 次のパターンは値がまったく同じ**——だから翼には区別がつかない、というわけです。ただし $k = mN - n$ のときは、時間まで含めた進行波 $\cos(k\theta_j + k\Omega t)$ が $\cos(n\theta_j - k\Omega t)$ になり、山の数は同じでも**走る向きが反転**します。それを教えてくれるのが $q$ の符号（この場合は負）です。

## エイリアシングと同じ構造

[[link:aliasing|フーリエの章]]で見た規則を思い出してください。標本化周波数 [[fs|fs]] で f の波を測ると、$f' = |f - m f_s|$ の見かけの周波数に化け、結果は $0 \le f' \le f_s/2$（ナイキスト周波数）に折り返されました。

ここでの規則は、$f \to k$、$f_s \to N$ と読み替えただけです。

- 時間のエイリアシング：標本化周波数 fs、折り返しの境界は fs/2。
- 空間のエイリアシング：標本化の「周波数」は翼の枚数 N、折り返しの境界は **N/2**。

節直径が N/2 までしか存在しないことは[[link:bladed-disk-nd|第II部]]でも触れましたが、その理由はまさにこれです。N 点でしか測れないものに、N/2 より細かい山を「見る」ことはできない。NASA の翼振動の報告書は、この対応表を文字どおり「空間エイリアシング表（spatial aliasing chart）」と呼び、ノズル枚数の整数倍と翼枚数の整数倍の差から励起される節直径を求めています。

## ジグザグの正体

下の散布図は、横軸に励起次数 k、縦軸に見える節直径 n を取ったものです。k を 0 から増やすと、n は 0 → N/2 まで上がり、そこで折り返して 0 まで下がり、また上がる——**ジグザグ**になります。

:::analogy @ball-walls 二枚の壁のあいだを往復するボール
床（n = 0）と天井（n = N/2）のあいだで、ボールをまっすぐ上に投げ続けるところを思い浮かべてください。k が増えるにつれてボールは上がり、天井に当たると跳ね返って下がり、床に当たるとまた上がります。「見える節直径」はこのボールの高さで、k を増やし続けると、高さは床と天井のあいだを**往復**するしかありません。これがジグザグの正体です。本物のボールは速さを失ってやがて止まりますが、この往復は k がいくら大きくなっても同じ形で続きます。
:::

この絵を、頭の片隅に焼き付けておいてください。次の節で登場する ZZENF 線図は、縦軸を「節直径」から「周波数」に替え、各 k の点を励起周波数 $k\Omega$ の高さに置き直しただけのものです。ジグザグの形はそのまま受け継がれ、線図の名前（Zig-Zag shaped Excitation line）にもなっています。

いくつかの k は特別な意味を持ちます。

- **k が N の倍数**（k = N, 2N, …）：n = 0。全部の翼が**同時に同じ向き**に押されます。円盤が傘のように開閉するアンブレラモード（節直径 0）を揺らす励起です。スタンドのウェーブで、隣との遅れがちょうど「1 回立って座る時間」だったら、全員が同時に立ち座りして波が**消えて**見える——それと同じです。
- **k = N/2**（N が偶数のとき）：n = N/2。**隣り合う翼が逆向き**に押されます。これは翼の列が持てる最も細かいパターンです。
- **k = N ± 1**：n = 1。円盤が**傾く**ように揺れるモード（節直径 1）を揺らします。節直径 1 のモードは、軸の横変位や傾きと同じ円周対称性を持つため、ハブが十分に動き周波数が近い場合には軸の曲げと連成しうるので、設計では特に気にする組合せです（[[link:zzenf-design|設計の節]]で扱います）。

## 「回転1周に N 回」と「翼の枚数 N」が同じ数なのは偶然ではない

励起次数 k は[[link:blade-excitation|「回転1周あたりに叩かれる回数」]]として導入しました。一方、折り返しの N は翼の枚数です。この二つが同じ土俵で引き算される（k − mN）のは、どちらも「円周を何等分するか」という**同じ量**だからです。

ノズル列は固定されていて、翼列が回ります。回転系から見れば、Ns 枚のノズルの後流は「1周に Ns 回やってくる叩き」であると同時に、「円周上に Ns 個の山が並んだ圧力パターン」でもあります。時間と空間が、回転によって結びついているのです。言葉にすると、回っている翼にとって「1 周のあいだに何回叩かれるか」と「円周に山がいくつ並んでいるか」は同じ数を別の言い方で言っているだけ、ということです。[[link:traveling-waves|立つ波と走る波の節]]で見た「静止系の固定パターンが回転系では進行波になる」が、まさにこの結びつきでした。

:::deep 標本化定理との対応——なぜ N/2 で止まるのか
翼の列の変位を $u_j$（j = 0, …, N−1）とします。これは N 個の数の並びなので、離散フーリエ変換（[[link:dft-probe|DFT]]）で

$$u_j = \sum_{n=0}^{N-1} U_n\, e^{\,i\,2\pi n j/N}$$

言葉にすると、N 枚の翼の変位の並びは、どんな形であっても、節直径 0 から N/2 までの模様をそれぞれの重みで足し合わせたものとして必ず書ける、ということです。

と書けます。この和の n は N 個しかなく、しかも $n$ と $N - n$ は互いに複素共役の組（実数の変位では $U_{N-n} = \overline{U_n}$）なので、**異なる節直径の値**は $n = 0, 1, \dots, \lfloor N/2 \rfloor$ の $\lfloor N/2 \rfloor + 1$ 種類だけです。これが「節直径は 0 から N/2 まで」の数学的な意味です。ただし独立な「形」（自由度）の数は、$0 < n < N/2$ の各 $n$ に $\cos$ 型と $\sin$ 型の 2 つがあるので、[[link:bladed-disk-nd|第II部]]で数えたとおり合計 $N$ 個です。「節直径の値の種類」と「独立なモードの数」は別の数え方だ、という点に注意してください。

励起側も同じです。翼 j が受ける力 $F_j = F_0 \cos(k\theta_j + k\Omega t)$ を同じ DFT で分解すると、成分は $n \equiv \pm k \pmod N$ の一か所にしか立ちません。**力が持つ「形」は節直径 fold(k, N) ただ一つ**——だから、翼がすべて同じ（tuned）で線形な周期対称系では、直交性により、その節直径を持たないモードには仕事をまったくしません。これが次の節の「共振の二重条件」の根拠になります。この選択則は、ミスチューニング（翼ごとのばらつき）、接触部の非線形、1 周で繰り返さない荷重があると崩れます（[[link:mistuning|第IV部]]で扱います）。

Tyler と Sofrin が 1961 年に圧縮機の騒音の研究でこの「動翼枚数と静翼枚数の整数倍の差」の規則を示して以来、回転機械の翼列の相互作用は**Tyler–Sofrin モード**の名で呼ばれています。翼振動でも音響でも、根っこは同じ空間エイリアシングです。
:::

:::field 実機の数字で折り返してみる
スペースシャトル主エンジン（SSME）の高圧燃料ターボポンプのタービンは、初段が静翼 41 枚・動翼 63 枚、2段目が静翼 39 枚・動翼 59 枚です（Biggs の開発史より）。この数字を折り返しの規則に入れてみましょう。

- 初段：k = 41 → n = 63 − 41 = **22**。2倍の k = 82 → 82 − 63 = **19**。3倍の k = 123 → |123 − 126| = **3**。
- 2段目：k = 39 → n = **20**。k = 78 → 78 − 59 = **19**。k = 117 → |117 − 118| = **1**。

3倍高調波で初段は節直径 3、2段目は節直径 **1**（軸の曲げと連成する番号）に落ちることが分かります。ノズル通過の基本波（k = Ns）だけ見ていると見落とす組合せです。なお Dominic の摩擦ダンパ研究によれば、この初段では 13 本の軸受支持ストラットが 13 枚のノズルと**不等間隔**に整列しており、ノズル後流の圧力パルスは一様ではありません。つまり実際の励起は「k = 41 の純音」ではなく多くの次数を含み、折り返し表の**多くの行が同時に生きる**ことになります。

J-2X エンジン（NASA の上段用エンジン）の燃料ターボポンプタービンでは、動翼 69 枚に対して上流ノズル 37 枚・下流静翼 57 枚で、NASA の解析報告は「下流静翼が節直径 12 を励起する」と空間エイリアシング表で示しています。折り返しの規則で確かめると 57 → 69 − 57 = 12 で一致します（上流は 37 → 32、2倍の 74 → 5）。
:::

## ひとことで

- 翼の列は、円周の圧力の模様を「翼のある場所だけ」で見ている。だから細かすぎる模様は、粗い模様と区別がつかない。
- 「1 周に k 回叩く」励起は、翼には「うねり $n = \mathrm{fold}(k, N)$ 回」の模様に見える。$n$ は 0 と $N/2$ のあいだを**往復**する（符号付きの $q$ を使えば、波の走る向きも分かる）。
- この往復がジグザグ線。次の節の ZZENF 線図は、ジグザグの高さを周波数に置き換えただけ。

**模式・出典について**：図の上段の圧力パターンと翼の標本点は三角関数の等式どおりで、翼の列に見える節直径は本文の fold の式で計算しています。リング表示の翼の長さは圧力の正負を見せる模式です。下段のジグザグは定義そのものです。折り返しの規則の根拠は Tyler, J.M. and Sofrin, T.G., "Axial Flow Compressor Noise Studies," SAE Transactions, Vol. 70, 1961, pp. 309–332。NASA の空間エイリアシング表と J-2X の数値は Brown, A.M. and Schmauch, P., "Characterization of Deficiencies in the Frequency Domain Forced Response Analysis Technique for Supersonic Turbine Bladed Disks," JANNAF 2011（NASA NTRS 20120002973、https://ntrs.nasa.gov/api/citations/20120002973/downloads/20120002973.pdf ）。SSME HPFTP の翼・静翼枚数は Biggs, R.E., "Space Shuttle Main Engine: The First Ten Years," Part 6（AAS History Series Vol. 13, 1992、https://mail.enginehistory.org/Rockets/SSME/SSME6.pdf ）、ストラットとノズルの整列は Dominic, R.J., "Turbine Blade Friction Damping Study," NASA CR, 1985（NTRS 19850018575、https://ntrs.nasa.gov/api/citations/19850018575/downloads/19850018575.pdf ）。SSME の 3倍高調波の節直径は本文で計算した値であり、出典に記載されたものではありません。
