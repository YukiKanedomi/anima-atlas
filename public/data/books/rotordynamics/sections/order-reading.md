# 回転機械ならではの読み方——次数と回転同期平均

フーリエの道具箱がそろいました。仕上げに、この道具を**回転機械用に研ぎ直します**。鍵は「Hz ではなく**回転**を物差しにする」という発想の転換です。

## 周波数ではなく「次数」で読む

回転機械のスペクトルでは、横軸を Hz でなく**次数（回転数の何倍か）**で読みます。1×＝回転そのもの、2×＝1回転に2回起きること、0.43×＝回転の43%の速さ。

理由は単純で、**振動の原因の多くが回転に紐づいている**からです。不釣り合いは1回転に1回、ミスアライメントは2回、歯数 Z の歯車のかみ合いは Z 回。回転数が変われば Hz の住所は全部動きますが、**次数の住所は動きません**。[[link:waterfall|ウォーターフォール]]で斜めの尾根に見えた次数成分が、次数軸で描けば**まっすぐ縦に立つ**——それが[[link:aliasing|エイリアシングの節]]で触れた次数トラッキング（回転同期サンプリング）の狙いでした。

## キーフェイザ——回転の「ページ番号」

この平均を可能にしているのが**キーフェイザ**です。軸に付けた切り欠きや反射マークを検出して、**1回転に1回、正確なパルス**を出す——いわば回転の**ページ番号**。これがあると、

- 波形を「1回転ぶん」で正確に切り出せる（回転同期平均の土台）
- 振動の**位相**を回転基準で測れる——[[link:balancing|バランシング]]で使った「振動ベクトル $V_0$ の角度」は、キーフェイザを0°とした角度です
- 回転数そのものの計測にもなる

つまり、この章の道具（FFT・窓・平均）と第7章の現場作業（釣り合わせ）は、キーフェイザという1本のパルスでつながっています。

## 章のまとめ——フーリエの目

- 波は正弦波の足し算でできている（**合成**）。レシピ＝スペクトル。
- 分解は「**掛けて、平均する**」。直交性が混線を防ぐ。
- 点で測るなら **fs > 2f**。破れば偽物（エイリアス）が現れ、後からは見抜けない。
- 有限の窓は**にじむ**。端を絞って（Hann）行儀よく切る。
- **細かさは T、静けさは M**——どちらも時間で買う。
- 回転機械では**次数**で読み、回転同期平均で「回転の声」だけを取り出す。

これで[[link:spectrum|スペクトル]]も[[link:waterfall|ウォーターフォール]]も、「なぜそう描けるのか」から読めるはずです。フーリエの目は、回転機械の聴診器です。

**模式・出典について**：回転同期平均は式どおりの計算です（非同期成分の残留が $1/\sqrt{M}$ で減ること、1×振幅が保存されることを独立検証済み。M=1で残留RMS 0.43 → M=16で0.006）。測定ノイズは再現性のため乱数の種を固定しています。標本化定理・窓関数・同期平均はいずれも振動計測の標準的手法です。
