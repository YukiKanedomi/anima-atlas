# 慣性が三つ以上並ぶと——Holzer 法と固有モード

![電動機・減速機・圧縮機の列と、その上に描いたモード形](data/books/rotordynamics/images/torsional-modes-1.jpg "イメージ図（生成画像・模式）：電動機、減速機、圧縮機を二本の軸でつないだ列。上の曲線は各機械のねじれ角をつないだモード形で、点は符号の変わる位置（節）。"){right}

実機の軸系は、電動機と負荷の二つだけで終わりません。電動機、継手、減速機、継手、圧縮機。ディーゼル機関なら、気筒の数だけクランクが並び、その先にはずみ車と発電機。慣性が三つ、五つ、十個と並ぶと、[[link:torsional-intro|前の節]]の 2 慣性の式では足りなくなります。

けれども考え方は変わりません。慣性が $n$ 個あれば、全体が一緒に回る剛体回転を除いて $n-1$ 個のねじりモードがあり、それぞれに固有振動数とモード形（どの慣性がどちら向きにどれだけ振れるか）があります。この節では、その固有振動数とモード形を**手で追える手順**、Holzer 法で求めます。1921 年に設計室の標準になった手順で、いまも計算機の中で同じことが行われています。

## 試しの ω で軸を渡り、右端に残るトルクを見る

Holzer 法の発想はこうです。固有振動数は「外からトルクをかけなくても、その振動数で揺れ続けられる速さ」です。そこで、**仮に** 角振動数 $\omega$ で揺れているとして、左端の慣性のねじれ角を 1 と置き、順に右へ渡っていきます。各慣性は $\omega$ で揺れるために $I\omega^2\theta$ のトルクを要求するので、それを軸が運ばなければなりません。軸はトルクを運ぶぶんだけねじれる。こうして右端まで来たとき、**右端の外には何もない**のに、まだトルクが残っていたら、仮定した $\omega$ では揺れ続けられません。残ったトルク（残留トルク）がちょうどゼロになる $\omega$ だけが、本物の固有振動数です。

:::analogy @train 連結された貨車を、先頭から順に押していく
連結器でつないだ貨車の列を思い浮かべてください。先頭の貨車を揺らすと、連結器を通じて次の貨車が揺れ、また次へ。最後尾の貨車の後ろには何もつながっていないので、列全体で「各貨車を揺らすのに要る力」が互いに打ち消し合い、最後尾を外から押す力がゼロで済む揺れ方しか続きません。Holzer 法は、先頭から順にその力を足していき、最後尾に力が余らない揺れ方だけを合格にする手順です。限界：貨車は直線に並んで引き合いますが、軸系では「力」がトルク、「ずれ」がねじれ角になるだけで、計算の形は同じです。
:::

ゼロ交差の数を数えてください。3 慣性なら 2 つ、4 慣性なら 3 つ。モードのボタンを 1 次、2 次と切り替えると、下段の折れ線がゼロ線をまたぐ回数（節の数）が 1、2 と増えます。1 次モードは軸系全体が「両端が逆向き」に大きくうねる形で、節は一つ。固有振動数がいちばん低く、励起と重なりやすいので、設計で最初に調べるのはこのモードです。

![はずみ車の大きなたわみ軸継手](data/books/rotordynamics/images/torsional-modes-2.jpg "写真：駆動列に取り付けられた大型の高弾性継手（VULKAN RATO R）。ゴムの要素が周方向に並び、軸系の中でもっとも柔らかいばねになる。節がどこにできるかは、この継手の硬さと両側の慣性で決まる。（Wikimedia Commons, Ricdeaamouse, CC BY-SA 4.0）"){right}

手順を式にすると、慣性 $I_i$ のねじれ角を $\theta_i$、$i$ 番目と $i+1$ 番目をつなぐ軸のねじり剛性を $k_i$ として、

$$T_i = T_{i-1} + I_i\,\omega^2\theta_i,\qquad \theta_{i+1} = \theta_i - \frac{T_i}{k_i}$$

です。言葉にすると、「$i$ 番目の慣性を通り過ぎたあと軸が運ぶトルクは、それまでのトルクに、この慣性が $\omega$ で揺れるために要るトルク $I_i\omega^2\theta_i$ を足したもの。次の慣性のねじれ角は、そのトルクで軸がねじれるぶんだけ減る」ということです。$\theta_1 = 1$、$T_0 = 0$ から始めて右端まで進み、最後の $T_n$ が残留トルクです。

$$T_n(\omega) = \sum_{i=1}^{n} I_i\,\omega^2\theta_i(\omega) = 0$$

言葉にすると、「固有振動数では、すべての慣性が要求するトルクの合計がゼロになる。つまり、ある慣性が『速く回りたい』向きのトルクを、別の慣性の『遅く回りたい』向きのトルクがちょうど打ち消している」ということです。各慣性の角運動量の変化が全体で釣り合っている、と言っても同じです。

:::analogy @torsion-pendulum 糸で吊った円板は、糸をねじって揺れる
ガラスのドームに入った置き時計（アニバーサリークロック）は、細い帯で吊った円板がゆっくり回っては戻る、ねじり振り子で時を刻みます。1 往復に 12〜20 秒もかかる、とても遅い振動です。糸のねじり剛性が小さく、円板の慣性が大きいからで、$\omega=\sqrt{k_t/I}$ の最も単純な形です。Holzer 法は、この「1 個の円板」を何個も数珠つなぎにして、互いが互いの支えになる揺れ方を探す手順だと思えます。限界：時計の帯は上端が固定されていますが、回転機械の軸系は両端が自由です。だから「全部が一緒に回る」剛体回転が一つ余計に出て、ねじりモードは慣性の数より一つ少なくなります。
:::

## 歯車がはさまると——速さの違う軸をそろえる

減速機をはさんだ軸系では、電動機側と圧縮機側で回転数が違います。ねじれ角も速さも違う二つの軸を、そのまま一列には並べられません。そこで**どちらか一方の軸の速さに換算**します。基準の軸に対して回転数が $r$ 倍（たとえば増速なら $r>1$）の側にある慣性 $I$ と剛性 $k$ は、

$$I_{eq} = r^{2} I,\qquad k_{eq} = r^{2} k$$

として基準軸上に置き直せます。言葉にすると、「速く回る側の部品は、速さの 2 乗だけ重く・硬く見える」ということです。運動エネルギー $\tfrac{1}{2}I(r\dot\theta)^2$ と、ひずみエネルギー $\tfrac{1}{2}k(r\theta)^2$ を基準軸のねじれ角 $\theta$ で書き直すと、$r^2$ が前に出てきます。増速比 5 の圧縮機側に置いた慣性は、電動機軸から見ると 25 倍の重さに見えるわけです。かみ合う二つの歯車の慣性は、換算してから一つにまとめます。

:::analogy @gears 自転車のギアを軽くすると、車輪が重く感じなくなる
自転車で重いギア（ペダル 1 回転で車輪がたくさん回る）にすると、同じ車輪なのに漕ぎ出しが重く感じます。ペダルから見た車輪の慣性が、変速比の 2 乗で大きく見えるからです。軽いギアにすると車輪は「軽く」なります。ねじり振動の計算で歯車の向こう側の慣性を $r^2$ 倍するのは、まったく同じ理屈です。限界：自転車では「重い・軽い」は漕ぐ人の感覚ですが、軸系の計算では換算の向きを間違えると固有振動数が何倍もずれるので、どの軸を基準にしたかを必ず書き留めます。
:::

![往復機関のクランク軸の断面図](data/books/rotordynamics/images/torsional-modes-4.jpg "図：船用蒸気機関のクランク軸（1904 年の教本の図版）。ねじり振動の計算では、クランク一つ一つをその軸位置の慣性に置き換え、クランク間の軸を等価なねじり剛性に置き換えて、慣性の列にする。（Wikimedia Commons, New Catechism of the Steam Engine, 1904, パブリックドメイン）"){right}

往復機関のクランク軸も同じ流儀で慣性の列にします。クランク一つ（クランクピン、クランクアーム、連接棒の回転側、ピストンの往復質量の寄与）をその位置の等価慣性に、クランクのあいだの曲がりくねった軸を等価なねじり剛性に置き換えます。ピストンの往復質量は回転角で見かけの慣性が変わるので、平均値で代表させるのが昔からの近似です。こうして「気筒の数＋はずみ車＋発電機」の慣性列ができれば、あとは Holzer 法の出番です。

:::history 設計室の表計算から、伝達マトリクスへ
Holzer の方法が広まった理由は、**手計算で追える**ことでした。表の左の列に慣性、次の列に $I\omega^2$、その隣にねじれ角、その隣にトルクの累計、という具合に横へ埋めていけば、1 行に 1 慣性、最後の行の右端に残留トルクが出ます。$\omega$ を変えて何枚か表を作り、残留トルクの符号が変わるところを内挿する。ディーゼル機関の設計室では、この表を何十枚も作るのが若い技師の仕事でした。

同じ「端から順に渡る」考え方は、1940 年代に Myklestad（1944 年）と Prohl（1945 年）によって**曲げ振動**に拡張され、翼や軸の[[link:mode-shapes|曲げモード]]を求める方法になりました。さらに各要素の受け渡しを行列で書いたものが**伝達マトリクス法**で、計算機の時代の初期まで回転機械の固有値計算の主力でした。いまは有限要素法が主流ですが、「左端の状態を仮定して右端の境界条件が満たされる振動数を探す」という骨格は、Holzer の表のままです。
:::

## 何次まで見ればよいか——実務の目安

:::field 1 次と 2 次を、励起の線から外す
軸系のねじり固有振動数は、剛体回転を除けば慣性の数より一つ少ないだけあります。何個まで見るかは決め打ちせず、**対象とする励起の周波数範囲にかかるモードをすべて**対象にします。電動機駆動の圧縮機なら電源周波数の 2 倍まで、歯車やインバータの高調波があればそこまでで、規格によっては最高速度の 2 倍程度までの固有振動数とモード形の報告を求めるものもあります。低いモードが励起と重なりやすいのは事実ですが、高いモードも歯車のかみ合いやインバータの高調波で励起され、どれだけ応答するかはモード形（どの慣性がどれだけ動くか）で決まります。設計の手順はおおむね次のとおりです。

- （1）軸系を慣性と剛性の列にする（歯車の向こうは $r^2$ で換算、クランクは等価慣性に）。
- （2）Holzer 法か固有値計算で、励起の周波数範囲にかかる固有振動数とモード形を出す。
- （3）[[link:torsional-excitation|励起源]]の次数（電動機の 1×・2×、電源周波数の 1 倍・2 倍、往復機関の 0.5× 刻みの次数、歯車のかみ合い）を斜線にして、ねじりの Campbell 線図に重ねる。
- （4）運転範囲の中で交点ができるなら、固有振動数を動かす（継手の硬さ、はずみ車の慣性）か、交点での応力を計算して疲労強度と比べる。各機種の規格（API 610 や 617 など）は、関連する励起との交点から余裕（離隔余裕）をとることを求め、解説文書の API 684 がその考え方を整理しています。
- （5）動かせない交点（起動時に必ず通る低いモードなど）は、通過の速さと応力の大きさを評価する。

モード形は、どこにひずみゲージを貼れば振動がよく見えるか（節のそば、ねじれ角の勾配が大きい所）、どこに減衰を入れれば効くか（ねじれの大きい所）を教えてくれます。固有振動数だけでなく、形を必ず見ておくのはそのためです。
:::

:::deep 行列で書くと——固有値問題としての Holzer
慣性を対角に並べた行列を $\boldsymbol{M}=\mathrm{diag}(I_1,\dots,I_n)$、三重対角の剛性行列を $\boldsymbol{K}$（対角は $k_{i-1}+k_i$、隣は $-k_i$）とすると、自由振動は

$$\boldsymbol{M}\ddot{\boldsymbol{\theta}} + \boldsymbol{K}\boldsymbol{\theta} = \boldsymbol{0},\qquad \left(\boldsymbol{K}-\omega^{2}\boldsymbol{M}\right)\boldsymbol{\phi}=\boldsymbol{0}$$

言葉にすると、「各慣性の加速度に慣性を掛けたものと、隣との角度差に軸の硬さを掛けたものが釣り合う。これを満たす $\omega$ とねじれ角の列 $\boldsymbol{\phi}$ の組が固有値と固有ベクトル」ということです。$\boldsymbol{K}$ の行をすべて足すとゼロになる（両端が自由で、全体を回しても復元力がない）ので、$\omega=0$ が必ず一つの固有値になり、残りの $n-1$ 個がねじりモードです。Holzer 法は、この三重対角の固有値問題を「上から順に消去する」手順そのもので、残留トルク $T_n(\omega)$ は $\det(\boldsymbol{K}-\omega^2\boldsymbol{M})$ に比例します。部品の上段の曲線は、その行列式を $\omega$ の関数として描いたものと言えます。
:::

## ひとことで

- 慣性が $n$ 個なら、ねじりモードは $n-1$ 個。剛体回転の分だけ一つ少ない。
- Holzer 法は「試しの $\omega$ で左端から渡り、右端に残るトルクがゼロになる $\omega$ を探す」手順。残留トルクのゼロ交差が固有振動数、そのときのねじれ角の列がモード形。
- 歯車の向こう側の慣性と剛性は、速さの比の 2 乗で換算して一列にする。クランク軸は等価慣性と等価剛性の列にする。
- 見るモードは励起の周波数範囲で決める（低いモードだけとは限らない）。モード形は、応答の大きさ、測る場所、減衰を入れる場所を教えてくれる。
- 同じ考え方が曲げ振動（Myklestad・Prohl）と伝達マトリクス法へ広がった。

**模式・出典について**：部品は $n$ 個の慣性を $n-1$ 本の軸でつないだ直列系の Holzer 法をそのまま計算しており、残留トルクのゼロ交差を二分法で詰めています。上段の縦軸は見やすさのため圧縮して描き、ゼロ交差の位置だけが意味を持ちます。既定の慣性・剛性の値は電動機・減速機・圧縮機の列を模した相対値で、実機の値ではありません。歯車の換算 $r^2$ はエネルギーの等価から導かれる標準的な関係です。生成画像は「イメージ図」と明記し、事実は担わせていません。Holzer の 1921 年の著書は Springer 社の書誌、ねじり振り子時計の 1 往復 12〜20 秒と発明の経緯（Aaron Crane 1841 年、Anton Harder 1879〜80 年）は Wikipedia「Torsion pendulum clock」、Myklestad（1944 年、翼と梁の曲げ振動）と Prohl（1945 年、たわみロータの危険速度、Journal of Applied Mechanics 12 巻 3 号 A142〜A148、DOI 10.1115/1.4009455）による曲げへの拡張と、のちに伝達マトリクス法として書き直されたことは Wikipedia「Nils Otto Myklestad」の記述、離隔余裕の考え方は API 684（解説文書）と API 610・617 の一般的な記述によります。
