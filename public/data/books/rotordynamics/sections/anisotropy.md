# 楕円の軌道——支持のかたよりと、間で起きる逆回り

実際の機械でロータの軌道を測ると、これまで見てきたようなきれいな**円**には、まずなりません。たいていは**楕円**です。なぜでしょうか。答えは、ロータを支える側にあります。軸受や台の硬さが、**横方向と縦方向で違う**からです。床に据えた機械なら、縦は基礎ががっちり受け止める一方、横は構造がしなって柔らかい——支持に「かたより」（**異方性**）があるのが、実機ではむしろ普通なのです。

[[link:whirl-direction|振れ回りの向きの節]]で「楕円は支持のかたよりのサイン」と予告しました。この節で、その伏線を回収します。

支持の硬さが方向で違うと、何が起きるか。まず、[[link:natural-frequency|危険速度]]が**2つに割れます**。横方向は硬さ $k_x$ で決まる固有振動数 $\omega_x$、縦方向は $k_y$ で決まる $\omega_y$ を、それぞれ**別々に**持つからです。回転数 [[Omega|Ω]] を上げていくと、まず柔らかい方向の山を、次に硬い方向の山を通過する——共振の山が2つあるのです。

では、その**2つの危険速度のあいだ**では、軌道はどうなっているでしょう。

## なぜ「あいだ」だけ逆回りするのか

種明かしには、これまでの2つの道具がそのまま使えます。[[link:orbit-from-waves|前の節]]で見たとおり、軌道は横の波 $x(t)$ と縦の波 $y(t)$ の合成で、向きは**どちらの波が先を行くか**の追い越し関係で決まるのでした。そして[[link:phase-lag|位相の節]]で見たとおり、危険速度を超えると応答の位相は **180° 反転**します。

異方性があると、この位相反転が**方向ごとに別のタイミング**で起きます。$\Omega$ が $\omega_x$ を超えた瞬間、**横の波だけが先に反転**する。縦の波はまだ反転していない。すると2つの波の追い越し関係が入れ替わって——軌道は後ろ向きに回りだします。さらに $\Omega$ が $\omega_y$ も超えると、今度は縦の波も反転して関係が元に戻り、軌道はまた前向きに。**2つの山のあいだだけが逆回りの帯**になるのは、このためです。

[[link:orbit-from-waves|F/B分解]]の言葉で言えば、帯の中では後ろ向き成分 $|B|$ が前向き成分 $|F|$ を上回っている、ということです。上のブロックの帯は、この $|B|>|F|$ の範囲をそのまま塗ったものです。

## 実機での意味

**楕円のつぶれ具合は、支持の診断書です。** オービットを見れば、支持の硬さのかたよりが読み取れます。円に近ければ支持はほぼ等方、強くつぶれていれば異方性が大きい——軌道の形そのものが、軸受や基礎の素性を語ってくれます。

もうひとつは帯の通過です。昇速でこの帯を横切るあいだ、ロータは後ろ向きに振れ回ります。[[link:whirl-direction|前々節]]で見たとおり、後ろ向き振れ回りでは軸の表面の応力がずっと速く交番します（回転系から見て $2\Omega$ の引っ張り⇄圧縮）。昇速中に短時間で通り抜けるぶんには大きな問題になりにくいのですが、**知らずに帯の中で連続運転する**のは避けたい。危険速度の山だけでなく「山のあいだ」にも目を配る理由が、ここにあります。

:::deep 式で見る後ろ向きの帯
横・縦は独立の1自由度として扱えます。$\omega_x = 1$（横の危険速度）で無次元化し、$\omega_y = \sqrt{k_y/k_x}$、[[zeta|減衰比]] $\zeta$ として、不釣り合い応答は

$$A_x = \frac{\Omega^2}{\sqrt{(\omega_x^2-\Omega^2)^2 + (2\zeta\omega_x\Omega)^2}},\qquad \varphi_x = \operatorname{atan2}\!\left(2\zeta\omega_x\Omega,\ \omega_x^2-\Omega^2\right)$$

（$y$ も同様）。軌道は $x(t)=A_x\cos(\Omega t-\varphi_x),\ y(t)=A_y\sin(\Omega t-\varphi_y)$ で、複素表示 $z=x+iy=F\,e^{i\Omega t}+B\,e^{-i\Omega t}$ に分解すると

$$F = \tfrac{1}{2}\left(A_x e^{-i\varphi_x} + A_y e^{-i\varphi_y}\right),\qquad B = \tfrac{1}{2}\left(A_x e^{+i\varphi_x} - A_y e^{+i\varphi_y}\right)$$

- 等方（$\omega_x=\omega_y$）では $A_x=A_y,\ \varphi_x=\varphi_y$ となり $B=0$——**真円（前向き）**
- 異方では $B\neq 0$——**楕円**。そして $|B|>|F|$ の範囲が**後ろ向きの帯**
- $\zeta=0.08,\ k_y/k_x=1.5$ のとき、帯は $\Omega = 1.040 \sim 1.178$。2つの危険速度（$1.000$ と $\sqrt{1.5}\approx 1.225$）の**内側**に、減衰のぶんだけ少し狭く収まります。$\zeta \to 0$ の極限では、帯は2つの危険速度いっぱいまで広がります
:::

**模式・出典について**：上のブロックは異方支持 Jeffcott ロータの標準的な不釣り合い応答（各方向独立の1自由度）と F/B 分解を**式のまま**動かした模式で、寸法は見やすさのためのスケールです。数値検証として、等方（$k_y/k_x=1$）で $|B|=0$（真円）、$\zeta=0.08,\ k_y/k_x=1.5$ で振幅の山が $\Omega \approx 1.006$ と $1.232$ の2つに割れ、$\Omega = 1.040\sim1.178$ で $|B|>|F|$ となること、その範囲で軌道の回転向き（面積法）が実際に逆転することを確認しています。「2つの危険速度の間で後ろ向き振れ回りが生じる」ことは、異方支持ロータの古典的な結果です。
