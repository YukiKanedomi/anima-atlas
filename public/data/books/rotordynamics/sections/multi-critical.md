# 危険速度はいくつもある——実機のモードと離隔余裕

![危険速度と運転範囲の模式図](data/books/rotordynamics/images/multi-critical-1.jpg "イメージ図（生成画像・模式）：回転数軸に並ぶ 2 つの共振の山と、その間に置いた運転範囲（斜線）。両側の矢印が離隔の幅。"){right}

ここまでの 2 節で、ロータの危険速度が「剛体モード 2 つ」と「曲げモード 1 次、2 次、3 次……」と、回転数の軸にずらりと並ぶことが分かりました（この分け方は軸受が柔らかい側で見やすい近似で、軸受が硬くなると両者は連続的につながります。後述の危険速度マップ）。設計者の仕事は、この並びの中に**運転回転数の範囲をどう置くか**です。

一本の山道を思い浮かべてください。峠（危険速度）がいくつもあり、車（ロータ）はある区間を毎日走ります。峠の上に駐車場を作ってはいけないのは当然として、峠のすぐ下に作るのも危険です。少し荷物が増えたり道がぬれたりするだけで、車は峠に乗り上げてしまうからです。駐車場（運転範囲）は峠から十分離し、しかも「どれくらい離せば十分か」は峠の険しさ、つまりその共振の鋭さで決める。これが本節の主題である**離隔余裕（セパレーションマージン）**の考え方です。

## 危険速度の階段

![Aurel Stodola の肖像](data/books/rotordynamics/images/multi-critical-4.jpg "写真：Aurel Stodola（1859〜1942）。チューリヒ工科大学で蒸気タービンの理論を築き、段付き軸の危険速度の計算法を示した。（Wikimedia Commons, Fr. Schmelhaus / ETH Zürich, CC BY-SA 3.0）"){right}

ロータを下から回していくと、順に次の危険速度に出会います。

1. **剛体の並進モード**と**傾きモード**。軸受と支持のばねで決まり、軸受が柔らかいほど低い。どちらが先かはロータの形次第（[[link:rigid-rotor-modes|前々節]]）。
2. **曲げの 1 次モード**。軸が弓なりになる。軸の太さ、長さ、円板の重さで決まる。
3. **曲げの 2 次、3 次……**。波の細かさの 2 乗で上がる（[[link:mode-shapes|前節]]）。

この「剛体 2 つ＋曲げ」という数え方は、軸受が軸に比べて十分柔らかいときに成り立つ見方です。軸受が硬くなるにつれて、剛体モードだった枝は軸のしなりを含む曲げモードへ連続的に移り変わり、独立した段ではなくなります。

ここで大事なのは、この階段が**固定されていない**ことです。軸受の硬さが変わると剛体モードは大きく動き、曲げモードは少しだけ動きます。回転数が上がるとジャイロ効果で傾きモードや曲げモードが前向き・後ろ向きに分かれて動きます（[[link:gyro-split|第 3 章]]）。すべり軸受の油膜は回転数と荷重で硬さが変わるので、同じロータでも暖機中と定格では階段の段の高さが違います。

設計の最初の一枚は、この動きを一望する**危険速度マップ**です。横軸に軸受（支持）の硬さ、縦軸に危険速度をとり、1 次、2 次、3 次の曲線を描きます。軸受が柔らかい左側では曲線は「剛体モード」として硬さとともに上がり、軸受が硬い右側では「曲げモード」として頭打ちになります。そこに実際の軸受の硬さの曲線を重ねれば、交点が「この機械の危険速度」です。API の解説書は、この図で機械の性格を素早くつかめる一方、減衰を含まないので危険速度や離隔余裕の最終判定には使ってはならない、と念を押しています。

:::analogy @ball-hill 峠の険しさで、駐車場の距離を決める
なだらかな峠なら、少し近くに停めても転がり落ちることはありません。鋭く切り立った峠なら、わずかに近づいただけで谷底まで持っていかれます。危険速度も同じで、減衰の大きい「なだらかな」共振は運転範囲の近くにあっても振幅が育たず、減衰の小さい「鋭い」共振は遠くに置かなければなりません。だから離隔余裕の規定は「何パーセント離せ」ではなく「山の鋭さに応じて何パーセント離せ」という形をしています。限界：山の鋭さ（増幅係数）は計算でも試験でも誤差を持つので、規格の式はその誤差も見込んだ保守的な線です。
:::

## 山の鋭さを数字にする：増幅係数 AF

山の鋭さは、[[link:bode-polar|ボード線図]]の共振の山の「幅」で測ります。山の頂点の振幅を 1 として、振幅が $1/\sqrt{2} \approx 0.707$ に下がる両側の回転数を $N_1$、$N_2$ とすると、**増幅係数（Amplification Factor, AF）** は

$$\mathrm{AF} = \frac{N_{c}}{N_2 - N_1}$$

言葉にすると、「山の両側で高さが 7 割まで下がる 2 点の間隔が、頂点の回転数の何分の一か」で、幅が狭いほど AF は大きく、山は鋭い、ということです。この測り方は半値幅（ハーフパワー）法と呼ばれ、1 自由度の減衰振動では減衰比 [[zeta|ζ]] と

$$\mathrm{AF} \approx \frac{1}{2\zeta}$$

の関係があります。言葉にすると、増幅係数は[[link:blade-damping|翼振動章]]で使った Q 値と同じもので、減衰比が小さいほど山は鋭く、たとえば ζ = 0.05 なら AF は約 10 ということです。

下のブロックで ζ を変えて、山の幅がどう変わるか見てください。上の段が振幅、下の段が位相です。

:::bode
{
  "title": "減衰比を変えると、山の幅（増幅係数）が変わる",
  "zetaDefault": 0.1,
  "rMax": 2.0,
  "caption": "ζ = 0.1 なら頂点の 0.707 倍まで下がる幅は r でおよそ 0.2、AF ≈ 5。ζ を 0.05 にすると幅は半分、AF は約 10 になります。位相が 90° を横切る点が固有振動数との一致点です。"
}
:::

API の標準条文は、この AF で「危険速度かどうか」そのものを定義しています。計算または試験のボード線図で山の頂点の回転数を危険速度と呼び、そのうち **AF が 2.5 を超える**ものだけを「減衰が足りない共振」として扱い、それ以下の山は**臨界減衰されている**とみなして危険速度に数えません。鋭くない山は、通っても大きく揺れないからです。ここでいう「臨界減衰」は API の便宜的な分類語で、物理でいう臨界減衰（$\zeta = 1$）ではありません。1 自由度の近似 $\mathrm{AF} \approx 1/(2\zeta)$ で言えば AF = 2.5 は $\zeta \approx 0.2$ にあたります。なお定義は「2.5 を超える」ですが、後述の離隔余裕の判定式では「2.5 以上」を境にする版もあり、境界ちょうどの扱いは採用する規格の版に従います。

## 離隔余裕：どれだけ離せば十分か

離隔余裕（separation margin, SM）は、運転範囲の端から危険速度までの距離を、運転回転数のパーセントで表したものです。運転範囲の**下**にある危険速度は最低運転回転数から、**上**にある危険速度は最高連続回転数から測ります。

![モード試験用のインパクトハンマ](data/books/rotordynamics/images/multi-critical-3.jpg "写真：モード試験に使うインパクトハンマ。ヘッドの中に力変換器を備え、先端のチップは硬さの違うものに交換できる。叩いた力の大きさと時間波形を記録する。（Wikimedia Commons, Austin Downey, CC BY-SA 4.0）"){right}

圧縮機の規格 API 617 の **第 7 版（2002 年）** に引かれる判定は、AF に応じて要求する余裕を変える形で、解説書や業界の資料ではおおむね次のように紹介されています。

- AF が 2.5 未満：臨界減衰とみなし、離隔余裕は要求しない。
- AF が 2.5 以上で、危険速度が運転範囲の下にあるとき：最低運転回転数から $17\left(1 - \frac{1}{\mathrm{AF} - 1.5}\right)$ パーセント以上離す（上限は 16 パーセント）。
- AF が 2.5 以上で、危険速度が運転範囲の上にあるとき：最高連続回転数から $10 + 17\left(1 - \frac{1}{\mathrm{AF} - 1.5}\right)$ パーセント以上離す（上限は 26 パーセント）。

言葉にすると、山が鋭いほど遠くへ、ただし上限あり、そして運転範囲の上側の危険速度は下側より 10 パーセントぶん余計に離す、ということです。上側が厳しいのは、調速機の不調や負荷の急変で回転数が上に飛び出す余地を見たものと解釈できますが、規格本文にその理由までは書かれていません。数値を入れると、下側・上側の順に、AF = 2.5 で 0 パーセント・10 パーセント、AF = 5 で約 12 パーセント・約 22 パーセント、AF = 10 で 15 パーセント・25 パーセントです。

この式と上限値は第 7 版のもので、**第 8 版（2014 年）以降では数値と式の扱いが改められています**（解説資料では上限が 17 パーセント・27 パーセントになった、などと紹介されます）。離隔余裕は契約で指定された版に従う事項なので、実務では必ず該当する版の条文を参照してください。本書では規格の原文を直接確認できていません。

:::analogy @car-wall 壁ぎりぎりに停めない、の正体
翼振動章では「運転範囲の端ぎりぎりに共振を置かない」と繰り返しました。何パーセント離せばよいかの答えがここにあります。計算の固有振動数は、軸受の硬さの推定誤差や温度で数パーセント動き、運転回転数も負荷で数パーセント動きます。両方の誤差を足しても当たらない距離が「余裕」で、鋭い共振ほど「当たったときの被害」が大きいので余裕も大きくとる。翼振動章の Campbell 線図に書いた「交点のまわりの感度」と、この節の離隔余裕は同じ考えを別の機械に当てたものです。限界：翼の固有振動数は遠心力で大きく動く（[[link:blade-stiffening|回ると硬くなる]]）ので、翼の離隔余裕は運転中の値で評価しなければならず、ロータの軸の場合より話が込み入ります。
:::

## 剛性ロータか、柔軟ロータか

運転範囲をどこに置くかで、機械の性格が決まります。

- **剛性ロータ（stiff shaft）**：運転回転数が曲げの 1 次危険速度より十分下。多くのポンプ、ファン、小型の電動機。釣り合わせは低速で行えばよい（[[link:standards-intro|ISO の釣り合い等級]]の世界）。
- **柔軟ロータ（flexible shaft）**：運転回転数が曲げの 1 次（ときに 2 次）危険速度より上。大型の発電機、蒸気タービン、多段の遠心圧縮機、ジェットエンジンの低圧軸。昇速のたびに危険速度を通過し（[[link:runup-transient|第 1 章]]）、釣り合わせもモード形を考えて複数の面で行います（[[link:two-plane-balancing|多面バランシング]]）。
- **超臨界ロータ**：第一危険速度より上で運転するロータの総称で、柔軟ロータはこれに含まれます。複数の危険速度を通過して運転する設計は、軽く速く作れる代わりに、通過する危険速度のすべてで減衰と余裕を確保しなければなりません。

どの選択にも理由があります。剛性ロータは単純で頑丈ですが、太く重くなります。柔軟ロータは軽く高速ですが、設計と運転の作法が増えます。翼振動章のターボポンプのタービンが「短く硬い軸」だったのは、軽さよりも、危険速度を運転範囲の上に追い出す確実さを選んだ結果でした。

## 測って確かめる：モード試験

計算した危険速度と増幅係数は、必ず実機で確かめます。方法は大きく 2 つです。

**止まっているロータを叩く**。ロータに小さな加速度センサを貼り、力センサ付きのインパクトハンマで軸を軽く叩きます。叩いた力の波形と応答の波形の比（周波数応答関数）から、固有振動数、減衰比、モード形が読めます。叩く場所と測る場所を軸に沿って変えていけば、前節のモード形が実測の点として浮かび上がります。ただし止まっている状態なので、油膜の硬さやジャイロ効果は入りません。回転中の値は、ここから計算で補正するか、次の方法で直接測ります。

![インパクトハンマによるモード試験の模式図](data/books/rotordynamics/images/multi-critical-2.jpg "イメージ図（生成画像・模式）：軸受台に載せたロータをインパクトハンマで叩き、加速度センサの信号を解析器で見る絵。"){small}

**回しながら測る**。昇速または降速のあいだ、軸受近くの変位センサで振幅と位相を記録し、[[link:bode-polar|ボード線図とポーラ線図]]を描きます。山の頂点が危険速度、山の幅が AF、位相が 90° を横切る点が固有振動数との一致点です。API の標準条文は、工場試験でこのボード線図を取り、計算と比べて、違いが大きければ解析モデルを直すことを求めています。「計算と試験が合うまでモデルを直す」という手順そのものが、受け入れ基準の一部になっているのです。

:::field 工場試験で危険速度が「計算より低く出た」とき
よくある原因は、支持構造です。解析では軸受の油膜の硬さだけを入れていたのに、実機では軸受箱と台座が直列のばねとして入り、全体が柔らかくなって剛体モードが下がる。もう一つは、試験時の軸受温度と油の粘度が設計点と違うこと。油の粘度が変わると油膜の硬さと減衰が変わり、危険速度は暖機の前後で動きます。どちら向きに動くかは軸受の形式、荷重、偏心率などの条件で決まり、「冷たければ必ず硬い」と単純には言えません。どちらも「軸受の硬さは軸受だけでは決まらない」「油膜の硬さは運転条件で変わる」の実例で、解析モデルの支持ばねを実測に合わせ直すのが定石です。
:::

:::history 「危険速度を避ける」から「山の鋭さで判断する」へ
初期の設計規則は「運転回転数は 1 次危険速度の何割以下、あるいは何割以上」という、距離だけの規定でした。ところが減衰の大きいすべり軸受に乗ったロータでは、計算上の危険速度を通っても振幅がほとんど育たないことがあり、距離だけの規定は保守的すぎたり、逆に鋭い 2 次モードを見逃したりしました。API の標準条文が、減衰を含む不釣り合い応答解析のボード線図から危険速度を定義し、増幅係数 2.5 を境に「臨界減衰」という分類を認め、AF に応じて離隔余裕を変える形に整ったのは、こうした経験の積み重ねです。1996 年に初版が出た解説書 API Publication 684 は、この考え方と計算手順を一冊にまとめ、2002 年の API 617 第 7 版で離隔余裕の式が改められ、その後の版でも見直しが続いています。
:::

## ひとことで

- 危険速度は剛体 2 つと曲げ 1 次、2 次……と階段をなし、軸受の硬さや回転数で段の高さが動く。危険速度マップでその動きを一望する。
- 避けるべきかどうかは山の鋭さ（増幅係数 AF）で決める。AF が 2.5 を超えなければ API 上の「臨界減衰」、超えれば AF に応じた離隔余裕を運転範囲の両側にとる（式と数値は規格の版で異なる）。上側は下側より厳しい。
- 計算した危険速度と AF は、止めて叩くモード試験と、回しながら取るボード線図で確かめ、合わなければ支持のばねを直す。

**模式・出典について**：増幅係数の定義（半値幅法、$\mathrm{AF} = N_c/(N_2 - N_1)$）、危険速度の定義（減衰を含む不釣り合い応答のボード線図の山の頂点、AF が 2.5 を超えるもの）、「AF が 2.5 以下は臨界減衰」という便宜的分類、危険速度マップの用途と限界、工場試験とモデル修正の手順は、API Publication 684（Tutorial on the API Standard Paragraphs Covering Rotor Dynamics and Balancing、1996 年初版）の本文によります。離隔余裕の式 $17(1 - 1/(\mathrm{AF}-1.5))$ と $10 + 17(1 - 1/(\mathrm{AF}-1.5))$、上限 16・26 パーセントは、API 617 第 7 版（2002 年）の規定として複数の解説資料（API 617 を購入仕様として用いる解説、磁気軸受圧縮機への API 617 第 8 版の適用に関する論文など）に引かれているものを転記しました。第 8 版以降で数値と式が改められていることも同じ資料によります。規格原文は本書では未確認で、上側を厳しくする理由は本書の解釈です。$\mathrm{AF} \approx 1/(2\zeta)$ は 1 自由度の半値幅の関係式で、ブロックの数値は式どおりです。剛性ロータ・柔軟ロータの区分は一般的な設計解説に基づく性格づけで、個別機の値ではありません。生成画像は「イメージ図」と明記し、事実は担わせていません。
