# 翼振動の歩き方——板ばね一枚からZZENF線図まで

スペースシャトルのメインエンジンには、液体水素を燃焼室へ押し込む**高圧燃料ターボポンプ**が付いていました。NASA の設計指針書によれば、このポンプは 85,000 馬力を出しながら毎分 37,000 回転、つまり**1秒間に 600 回以上**回ります。ポンプを回すのは同じ軸に付いた小さなタービンで、その初段の翼車には **63 枚の翼**が並び、**41 枚のノズル**から噴き出す高温の水素リッチガスを受け止めています。

ここで一つ、算数をしてみてください。翼は1回転ごとに 41 個のノズルの前を通り、通るたびにノズルの後ろの「風の影」（後流）で叩かれます。1秒に 617 回転なら、1枚の翼は**毎秒およそ 25,000 回**叩かれる計算です。10 秒で 25 万回、1回の飛行（約 8 分半）で 1,000 万回を超えます。金属は、小さな力でも何百万回と繰り返されると割れることがあります。針金を同じ場所で何度も曲げ伸ばししていると、手で引きちぎれないはずの針金がある瞬間ポキリと折れる——あの現象です。これが**高サイクル疲労**（HCF）で、実際にこのターボポンプでは開発初期に初段翼が壊れる事故が繰り返し起き（1977 年の 2 件を含め、NASA の報告書は計 3 件と記しています）、原因は「翼の過大な振動による高サイクル疲労」と結論されました。量産後も翼には髪の毛ほどのひび（hairline crack）が見つかり続け、定期的に分解して検査する運用が続いたと指針書は記しています。

![ロケットエンジンのターボポンプの断面（イメージ図）](data/books/rotordynamics/images/turbopump-hero.jpg "ターボポンプの断面のイメージ図（生成画像・模式）。左がポンプ、右が小さなタービン。ノズル（臙脂）が円周の一部にしか並んでいない「部分噴射」タービンの一般的な模式で、直前に述べた SSME HPFTP の初段（こちらはノズルが全周に並ぶ全周噴射）そのものではありません。翼車の翼が、ノズルの後ろの「風の影」を毎回くぐる。")

**翼はなぜ揺れるのか。いつ共振するのか。どうすれば避けられ、避けられないときはどう耐えるのか。**　この章はその問いに、板ばね一枚の話から始めて、最後は専門家が設計審査で使う **ZZENF線図**を自分で読み、使えるところまで登ります。ZZENF は Zig-Zag shaped Excitation line in Nodal diameter versus Frequency（節直径 対 周波数の図に描いたジグザグ形の励起線）の頭文字で、提案者 Murari Singh の名を取って **SAFE線図**（Singh's Advanced Frequency Evaluation）とも呼ばれます。名前の意味は第 III 部で一つずつほどきます。

## この章が「特別ページ」である理由

これまでの章は、ロータ（軸）がどう振れ回るかを 1〜6 節で扱ってきました。翼振動はそれとは別の、しかし地続きの世界です。軸が「1本の棒」なら、翼車は「何十枚もの同じ板ばねが円盤でつながったもの」で、同じ板ばねが円周に並ぶという**対称性**が、軸にはない独特の現象を生みます。

- 翼は一枚では揺れません。隣とつながっているので、翼車全体の「模様」（節直径）として揺れます。
- 叩く側（ノズル）は静止していて、叩かれる側（翼）は回っています。回る側から見ると、固定された風の影が「走る波」に見えます。
- N 枚の翼は、円周上の連続な波を N 点でしか「見る」ことができません。ここに FFT 章で学んだ**エイリアシング**がそのまま現れます。

:::analogy @trampoline 丸いトランポリンの輪を、まわりを走りながら押す
大きな丸いトランポリンの膜の上に、子どもたちが輪になって等間隔に立ち、それぞれ膝でリズムよくはねているとします。一人がはねれば膜がたわんで隣もつられて上下するので、この輪は「ばらばらの子ども」ではなく、膜ごと一つの模様で波打ちます。ここであなたが輪の外側を走りながら、通りすぎる子どもを順番に押していくとしましょう。押すリズムがはねるリズムに合っていなければ、どの子も大きくははねません——これが周波数の一致です。ところが、もう一つ条件があります。膜が「隣どうし交互に上・下」の模様で波打ちたがっているのに、あなたの押し方が「全員いっせいに下へ」になっていれば、押して足した分と逆らって削った分が打ち消し合い、模様は育ちません。押す順番と向きの「模様」が、輪が波打ちたがる模様と合っていなければならない——これが節直径の一致です。翼車の翼が子ども、円盤が膜、ノズルの後流が走りながら押す手です。限界：本物の円盤は膜よりはるかに硬く、たわみは目に見えないほど小さいのですが、「隣と一枚の板でつながっている」ことの効き方は同じです。
:::
この3つが組み合わさると、「周波数が合っても、模様が合わなければ共振しない」という**二重条件**が出てきます。これを1枚の図にしたのが ZZENF線図で、Campbell線図だけでは数えすぎてしまう「見かけの共振」をふるいにかけてくれます。ここまで来るには段階が要るので、この章は 5 つの部・全 17 節と、これまでで最も長い構成にしました。

## 登る道筋（5つの部）

**第I部　翼はなぜ揺れるか**（やさしい）。翼を一枚の板ばねとして眺め、固有振動数とモード（曲げ・ねじり）を知ります。回ると遠心力で硬くなること、ノズルの後流がどんな「手」で翼を叩くか、そして翼のCampbell線図。ここで「交点が多すぎて避けきれない」という壁にぶつかります。
[[link:blade-single|一枚の板ばねから始める]] → [[link:blade-stiffening|回ると硬くなる]] → [[link:blade-excitation|翼を叩く手は誰か]] → [[link:blade-campbell|翼のCampbell線図]]

**第II部　一枚から円盤へ**（標準）。翼車全体の揺れ方＝節直径、静止系の固定パターンが回転系では走る波になること、節直径ごとに固有振動数が並ぶ「モード族の曲線」。ZZENF線図の縦軸と横軸の材料をそろえます。
[[link:bladed-disk-nd|翼付き円盤と節直径]] → [[link:traveling-waves|立つ波と走る波]] → [[link:family-curves|周波数 vs 節直径]]

**第III部　ZZENF線図**（この章の核心）。N 枚の翼による空間のサンプリングから、ジグザグの励起線が生まれる理由を導き、ZZENF線図の読み方と、ノズル数・翼数を選ぶ設計への使い方まで。
[[link:eo-folding|励起次数の折り返し]] → [[link:zzenf-reading|ZZENF線図を読む]] → [[link:zzenf-design|ZZENF線図で設計する]]

**第IV部　実機の翼**（専門）。同じ翼は二枚とないこと（ミスチューニング）、減衰とダンパ、高サイクル疲労とGoodman線図。発展節としてフラッタと、翼振動の計測（ブレードチップタイミング）。
[[link:mistuning|ミスチューニング]] → [[link:blade-damping|減衰とダンパ]] → [[link:blade-hcf|高サイクル疲労]] →（発展）[[link:flutter|フラッタ]] / [[link:tip-timing|翼の振動をどう測るか]]

**第V部　通し演習**。ロケットターボポンプのタービンを題材に、翼数・ノズル数・回転数域を与えられた設計者になって、Campbell→ZZENF→減衰→疲労まで一本の流れで判断します。
[[link:turbopump-exercise|ロケットターボポンプのタービンを設計する]]

## 題材：ロケットエンジンのターボポンプのタービン

![展示用に整備されるスペースシャトル主エンジン](data/books/rotordynamics/images/blade-intro-1.jpg "写真：展示のために整備中のスペースシャトル主エンジン（SSME）。ノズルの脇に付く二つのターボポンプが、燃料と酸化剤を燃焼室へ押し込む。（NASA Stennis Space Center、パブリックドメイン）"){right}

この章の例題はずっと、**ロケットエンジンのターボポンプを回すタービン**です。航空用のジェットエンジンや発電用の蒸気タービンではなく、なぜこれを選んだのか。翼振動の難しさが、最も凝縮された形で現れるからです。

- **小さくて速い**。ターボポンプは手で抱えられるほどの大きさで、数万 rpm で回ります。翼は短く硬く、固有振動数は数 kHz 以上。冒頭の算数のとおり、25 kHz のノズル通過成分なら約 8 分半の運転で 1,000 万回（10 の 7 乗）を超え、開発試験や複数回の運転を累積すればさらに大きな繰り返し数になります。
- **叩く手が強い**。燃焼ガスは高温・高圧で、翼 1 枚あたりの負荷が大きく、小型・高速という条件が重なるため、ノズル後流や部分噴射による励起が設計上の主要な課題になりえます。
- **部分噴射**。小型のタービンでは、円周の一部にだけノズルを並べる「部分噴射」がよく使われます（翼を長くして漏れ損失を減らせるため）。ところが部分噴射では翼が「ガスのある区間」と「ない区間」を毎回出入りするので、「ノズル枚数の倍数だけ」という縛りが消え、低い次数から広い範囲の励起が同時に立ちます。日本の LE-5B-2 エンジンでは、この部分噴射に起因する高サイクル疲労で燃料ターボポンプのタービン翼と円盤に亀裂が入り、後継の LE-5B-3 では全周噴射に設計変更されました（EUCASS 2017 の JAXA/IHI の論文）。
- **軽く作りたい**。翼と円盤を一体で削り出すブリスク（blisk）構造では、翼の根元に摩擦で揺れを食う界面がないため、差込み翼に比べて構造減衰が小さくなる場合があります。

![翼と円盤を一体で削り出した圧縮機ブリスク](data/books/rotordynamics/images/blade-intro-2.jpg "写真：翼と円盤を一体で削り出した圧縮機のブリスク（航空エンジンの展示品。ロケット用ではない一般的な例）。差込み翼と違い、根元に摩擦で揺れを食う界面がない。（Wikimedia Commons, Olivier Cleynen, CC BY-SA 3.0）"){small}

2020 年には H3 ロケットの第 1 段エンジン LE-9 で、液体水素ターボポンプのタービン第 2 段動翼 76 枚のうち 2 枚に疲労破面が見つかりました。JAXA の報告によれば原因は「当初有意な影響があると評価したモード以外の共振」で、励振源は翼列の後流、つまり本節でいう「風の影」でした。全翼を設計変更して共振を追い出すと、今度は初段のディスク部にフラッタが現れ、減衰の強化と剛性の向上で対処しています（経緯は[[link:blade-summary|総括]]の歴史の囲みに資料つきでまとめました）。翼振動は過去の話ではなく、いま現役の設計課題です。

## 読み方のコツ

- **やさしい言葉から入り、節の後半で専門の言葉と式に上がります**。最初の数段落で「言いたいこと」はつかめるようにしてあるので、難しくなったら次の節へ進んで、あとで戻ってきて構いません。
- **「予想してみよう」はまず自分で選んでください**。当たっても外れても、その後に触るブロックの見え方が変わります。
- **動く図は必ず触ってください**。スライダーを端から端まで動かして「壊れる」瞬間を自分で見つけるのが、この本の読み方です。
- 「深掘り」は導出や式、「歴史」は人物や事故の話、「実務」は現場の勘所を畳んであります。全部開かなくても本筋は通ります。
- 記号は点線の語に触れると定義が出ます。章末の[[link:appendix-symbols|記号一覧]]にもまとめてあります。

## 先に知っておくと楽なこと

この章は単独でも読めますが、次の節を先に読んでおくと、たとえ話を「前に見た」として受け取れます。

- [[link:natural-frequency|固有振動数は硬さと重さで決まる]]——翼を板ばねに見立てる土台。
- [[link:campbell|ロータのCampbell線図]]——「固有振動数の線と励起線の交点」という読み方。翼では線の本数が桁違いに増えます。
- [[link:aliasing|サンプリングの罠]]——N 枚の翼が波を数えそこなう理由は、これと同じです。
- [[link:rotating-frame|回転座標系で見る]]——静止系の一定の力が、回る側では交番の力になる話。
- [[link:whirl-instability|自励振動]]——フラッタは「減衰が負になる」という同じ構図です。
- [[link:transmissibility|伝達率と減衰]]——共振の鋭さ（Q 値）の感覚。

## ひとことで

- 翼は「円盤に植わった何十枚もの板ばね」で、ノズルの風の影に 1 秒に何万回も叩かれる。回数が積もると金属は疲れて割れる。
- 共振には「叩くリズムが合う」だけでなく「叩く模様が、翼車の揺れたい模様と合う」ことが要る。その二重条件を 1 枚にしたのが ZZENF 線図。
- 板ばね 1 枚→円盤→模様→ZZENF→実機、の順に登る。難しくなったら、各節の「たとえ話」の囲みと「ひとことで」に戻ればよい。

それでは、一枚の板ばねから始めましょう。
