# 翼振動の歩き方——板ばね一枚からZZENF線図まで

スペースシャトルのメインエンジンには、液体水素を燃焼室へ押し込む**高圧燃料ターボポンプ**が付いていました。NASA の設計指針書によれば、このポンプは 85,000 馬力を出しながら毎分 37,000 回転、つまり**1秒間に 600 回以上**回ります。ポンプを回すのは同じ軸に付いた小さなタービンで、その初段の翼車には **63 枚の翼**が並び、**41 枚のノズル**から噴き出す高温の水素リッチガスを受け止めています。

ここで一つ、算数をしてみてください。翼は1回転ごとに 41 個のノズルの前を通り、通るたびにノズルの後ろの「風の影」（後流）で叩かれます。1秒に 617 回転なら、1枚の翼は**毎秒およそ 25,000 回**叩かれる計算です。10 秒で 25 万回、1回の飛行（約 8 分半）で 1,000 万回を超えます。金属は、小さな力でも何百万回と繰り返されると割れることがあります。これが**高サイクル疲労**（HCF）で、実際にこのターボポンプでは開発初期に初段翼が壊れる事故が繰り返し起き（1977 年の 2 件を含め、NASA の報告書は計 3 件と記しています）、原因は「翼の過大な振動による高サイクル疲労」と結論されました。量産後も翼には髪の毛ほどのひび（hairline crack）が見つかり続け、定期的に分解して検査する運用が続いたと指針書は記しています。

![ロケットエンジンのターボポンプの断面（イメージ図）](data/books/rotordynamics/images/turbopump-hero.jpg "ターボポンプの断面のイメージ図（生成画像・模式）。左がポンプ、右が小さなタービン。タービンのノズル（臙脂）は円周の一部にしか並んでいない＝部分噴射。翼車の翼が、ノズルの後ろの「風の影」を毎回くぐる。")

**翼はなぜ揺れるのか。いつ共振するのか。どうすれば避けられ、避けられないときはどう耐えるのか。**　この章はその問いに、板ばね一枚の話から始めて、最後は専門家が設計審査で使う **ZZENF線図**（SAFE線図）を自分で読み、使えるところまで登ります。

## この章が「特別ページ」である理由

これまでの章は、ロータ（軸）がどう振れ回るかを 1〜6 節で扱ってきました。翼振動はそれとは別の、しかし地続きの世界です。軸が「1本の棒」なら、翼車は「何十枚もの同じ板ばねが円盤でつながったもの」で、同じ板ばねが円周に並ぶという**対称性**が、軸にはない独特の現象を生みます。

- 翼は一枚では揺れません。隣とつながっているので、翼車全体の「模様」（節直径）として揺れます。
- 叩く側（ノズル）は静止していて、叩かれる側（翼）は回っています。回る側から見ると、固定された風の影が「走る波」に見えます。
- N 枚の翼は、円周上の連続な波を N 点でしか「見る」ことができません。ここに FFT 章で学んだ**エイリアシング**がそのまま現れます。

この3つが組み合わさると、「周波数が合っても、模様が合わなければ共振しない」という**二重条件**が出てきます。これを1枚の図にしたのが ZZENF線図で、Campbell線図だけでは数えすぎてしまう「見かけの共振」をふるいにかけてくれます。ここまで来るには段階が要るので、この章は 5 つの部・全 17 節と、これまでで最も長い構成にしました。

## 登る道筋（5つの部）

**第I部　翼はなぜ揺れるか**（やさしい）。翼を一枚の板ばねとして眺め、固有振動数とモード（曲げ・ねじり）を知ります。回ると遠心力で硬くなること、ノズルの後流がどんな「手」で翼を叩くか、そして翼のCampbell線図。ここで「交点が多すぎて避けきれない」という壁にぶつかります。
[[link:blade-single|一枚の板ばねから始める]] → [[link:blade-stiffening|回ると硬くなる]] → [[link:blade-excitation|翼を叩く手は誰か]] → [[link:blade-campbell|翼のCampbell線図]]

**第II部　一枚から円盤へ**（標準）。翼車全体の揺れ方＝節直径、静止系の固定パターンが回転系では走る波になること、節直径ごとに固有振動数が並ぶ「モード族の曲線」。ZZENF線図の縦軸と横軸の材料をそろえます。
[[link:bladed-disk-nd|翼付き円盤と節直径]] → [[link:traveling-waves|立つ波と走る波]] → [[link:family-curves|周波数 vs 節直径]]

**第III部　ZZENF線図**（この章の核心）。N 枚の翼による空間のサンプリングから、ジグザグの励起線が生まれる理由を導き、ZZENF線図の読み方と、ノズル数・翼数を選ぶ設計への使い方まで。
[[link:eo-folding|励起次数の折り返し]] → [[link:zzenf-reading|ZZENF線図を読む]] → [[link:zzenf-design|ZZENF線図で設計する]]

**第IV部　実機の翼**（専門）。同じ翼は二枚とないこと（ミスチューニング）、減衰とダンパ、高サイクル疲労とGoodman線図。発展節としてフラッタと、翼振動の計測（ブレードチップタイミング）。
[[link:mistuning|ミスチューニング]] → [[link:blade-damping|減衰とダンパ]] → [[link:blade-hcf|高サイクル疲労]] →（発展）[[link:flutter|フラッタ]] / [[link:tip-timing|翼の振動をどう測るか]]

**第V部　通し演習**。ロケットターボポンプのタービンを題材に、翼数・ノズル数・回転数域を与えられた設計者になって、Campbell→ZZENF→減衰→疲労まで一本の流れで判断します。

## 題材：ロケットエンジンのターボポンプのタービン

この章の例題はずっと、**ロケットエンジンのターボポンプを回すタービン**です。航空用のジェットエンジンや発電用の蒸気タービンではなく、なぜこれを選んだのか。翼振動の難しさが、最も凝縮された形で現れるからです。

- **小さくて速い**。ターボポンプは手で抱えられるほどの大きさで、数万 rpm で回ります。翼は短く硬く、固有振動数は数 kHz 以上。1回の運転が数分でも、繰り返し回数はすぐに 10 の 8 乗、9 乗に達します。
- **叩く手が強い**。燃焼ガスは高温・高圧で、ノズルの後流は航空用の圧縮機よりずっと強い圧力の脈動を作ります。
- **部分噴射**。小型のタービンでは、円周の一部にだけノズルを並べる「部分噴射」がよく使われます（翼を長くして漏れ損失を減らせるため）。ところが部分噴射では翼が「ガスのある区間」と「ない区間」を毎回出入りするので、あらゆる次数の励起が同時に立ちます。日本の LE-5B-2 エンジンでは、この部分噴射に起因する高サイクル疲労で燃料ターボポンプのタービン翼と円盤に亀裂が入り、後継の LE-5B-3 では全周噴射に設計変更されました（EUCASS 2017 の JAXA/IHI の論文）。
- **軽く作りたい**。翼と円盤を一体で削り出すブリスク（blisk）構造では、翼の根元に摩擦で揺れを食う界面がなく、減衰がきわめて小さくなります。

2020 年に H3 ロケットの LE-9 エンジンで見つかったターボポンプのタービン翼の疲労亀裂も、報道によれば JAXA は「共振」が原因と説明し、運転範囲内で共振しうる固有値をすべて除くようタービンを再設計して翼の振動試験で確認する、と述べています。翼振動は過去の話ではなく、いま現役の設計課題です。

## 読み方のコツ

- **やさしい言葉から入り、節の後半で専門の言葉と式に上がります**。最初の数段落で「言いたいこと」はつかめるようにしてあるので、難しくなったら次の節へ進んで、あとで戻ってきて構いません。
- **「予想してみよう」はまず自分で選んでください**。当たっても外れても、その後に触るブロックの見え方が変わります。
- **動く図は必ず触ってください**。スライダーを端から端まで動かして「壊れる」瞬間を自分で見つけるのが、この本の読み方です。
- 「深掘り」は導出や式、「歴史」は人物や事故の話、「実務」は現場の勘所を畳んであります。全部開かなくても本筋は通ります。
- 記号は点線の語に触れると定義が出ます。章末の[[link:appendix-symbols|記号一覧]]にもまとめてあります。

## 先に知っておくと楽なこと

この章は単独でも読めますが、次の節を先に読んでおくと、たとえ話を「前に見た」として受け取れます。

- [[link:natural-frequency|固有振動数は硬さと重さで決まる]]——翼を板ばねに見立てる土台。
- [[link:campbell|ロータのCampbell線図]]——「固有振動数の線と励起線の交点」という読み方。翼では線の本数が桁違いに増えます。
- [[link:aliasing|サンプリングの罠]]——N 枚の翼が波を数えそこなう理由は、これと同じです。
- [[link:rotating-frame|回転座標系で見る]]——静止系の一定の力が、回る側では交番の力になる話。
- [[link:whirl-instability|自励振動]]——フラッタは「減衰が負になる」という同じ構図です。
- [[link:transmissibility|伝達率と減衰]]——共振の鋭さ（Q 値）の感覚。

それでは、一枚の板ばねから始めましょう。
