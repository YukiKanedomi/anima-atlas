# 前向きと後ろ向きで固有振動数が分かれる

![傾きながら振れ回る円板](data/books/rotordynamics/images/gyro-split-1.jpg "イメージ図（生成画像・模式）：軸の上で傾いた円板。傾きの向きが回っていく様子を破線の円錐で示した。"){right}

[[link:gyro-intuition|前の節]]で、回っている物は傾けられると直角に返事をする、と覚えました。この節では、その返事がロータの固有振動数をどう動かすかを見ます。結論を先に言うと、固有振動数は**一つではなくなり、二つに分かれます**。振れ回りの向きが回転と同じ（前向き）か逆（後ろ向き）かで、ジャイロの返事の向きが変わるからです。

軸がたわむと、軸に付いた円板はたわみの向きに少し傾きます。[[link:whirl-direction|振れ回り]]では、たわみの向きがぐるりと回っていくので、円板の傾きの向きも回っていきます。横から見ると、円板のふちが円錐をなぞるように見えるので、この揺れ方を**円錐振れ回り**（傾きモード）と呼びます。[[link:rigid-rotor-modes|剛体ロータの 2 つのモード]]のうち、傾きのほうです。

## 傾きの向きが回るとき、ジャイロはどちらに返事するか

コマの規則は「傾けられると、傾きと直角の向きに動こうとする」でした。振れ回る円板では、傾きの向きそのものが回っています。傾きの向きが回転と**同じ向き**に回る（前向き）とき、ジャイロの返事は傾きを**起こす**向き、つまり軸を押し返すばねのように働きます。軸が実際より硬くなったように見えるので、固有振動数は**上がります**。傾きの向きが回転と**逆向き**に回る（後ろ向き）とき、返事は傾きを**倒す**向きに働き、軸が柔らかくなったように見えて、固有振動数は**下がります**。

どちらの効き目も回転数 $\Omega$ に比例するので、止まっているときは一本だった固有振動数の線が、回転数を上げるほど二本に開いていきます。これが[[link:campbell|次の節の Campbell 線図]]で見る「枝分かれ」の正体です。

:::analogy @top ぐらつくコマは、回転と同じ向きにぐらつく
回っているコマを軽く弾くと、軸がふらふらとぐらつきます（章動）。よく見ると、そのぐらつきの向きは、コマの回転と**同じ向き**に回っています。ぐらつきが速いのも特徴で、回転が速いほどぐらつきは速くなります。これがロータでいう「前向きの傾きモード」で、回転数とともに固有振動数が上がる枝です。逆向きにゆっくり回る揺れ方（後ろ向きの枝）は、コマでは重力の歳差に隠れて見えにくいのですが、軸で支えられたロータでは同じ資格で存在します。限界：コマの章動は支点が固定された剛体の話で、ロータでは軸のばねも一緒に効くため、式は少し違います（深掘り参照）。
:::

## 式で確かめる：二つの根

円板の傾きを複素数 $\psi$ で表し、傾きに対する軸のばねを $k_t$ とすると、[[link:gyro-intuition|前の節の深掘り]]の式にばねの項を足して

$$I_d\,\ddot\psi \;-\; i\,I_p\,\Omega\,\dot\psi \;+\; k_t\,\psi = 0$$

言葉にすると、傾きを加速させる慣性、回転に比例して 90° 回った向きに働くジャイロのモーメント、傾きを戻す軸のばね、この三つの釣り合いで円板の傾きが決まる、ということです。ここに「傾きの向きが角振動数 $\omega$ で回る」という解 $\psi = \Psi e^{i\omega t}$ を入れると（$\omega > 0$ が前向き、$\omega < 0$ が後ろ向き）

$$-I_d\,\omega^2 \;+\; I_p\,\Omega\,\omega \;+\; k_t = 0$$

言葉にすると、ジャイロの項が「$I_p\Omega\omega$ だけ軸を硬くする（$\omega > 0$ のとき）か柔らかくする（$\omega < 0$ のとき）」ばねの追加分として現れ、前向きと後ろ向きで実効的な硬さが違う、ということです。この 2 次方程式の二つの根が、前向きの枝と後ろ向きの枝です。$\gamma = I_p/I_d$、$\omega_0 = \sqrt{k_t/I_d}$ で無次元化すると

$$\frac{\omega_{f,b}}{\omega_0} = \pm\frac{\gamma}{2}\frac{\Omega}{\omega_0} + \sqrt{\left(\frac{\gamma}{2}\frac{\Omega}{\omega_0}\right)^2 + 1}$$

言葉にすると、止まっているとき（$\Omega = 0$）はどちらも $\omega_0$ で一致し、回転数を上げると前向きは $\gamma\Omega/2$ ぶん持ち上がり、後ろ向きは同じだけ引き下げられる（根号の中も少し増える）、ということです。回転数が十分高いと、前向きの枝は $\gamma\Omega$ に近づき（コマの章動そのもの）、後ろ向きの枝はゼロに近づきます。

下の図は、この二つの根を回転数に対して描いたものです。[[gamma|γ]] を大きくすると、枝の開きが大きくなるのを確かめてください。

## γ は円板の「平たさ」

枝の開き方を決めるのは $\gamma = I_p/I_d$、回転軸まわりの慣性モーメントと、傾き方向の慣性モーメントの比です。

![薄い円板と長いドラム](data/books/rotordynamics/images/gyro-split-2.jpg "イメージ図（生成画像・模式）：同じ質量の薄い円板と長いドラムを軸に載せた比較。寸法線は直径と長さを示す。"){right}

一様な円柱（半径 $r$、長さ $L$）なら $I_p = mr^2/2$、$I_d = m(3r^2 + L^2)/12$ なので

$$\gamma = \frac{6r^2}{3r^2 + L^2}$$

言葉にすると、ぺたんこの円板（$L \to 0$）で $\gamma = 2$ と最大、長さが半径の $\sqrt{3}$ 倍で $\gamma = 1$、それより長いドラムでは 1 を下回り、細長い棒ではほぼゼロになる、ということです。つまり**平たい円板ほどジャイロ効果が強く、長いドラムではほとんど効かない**。タービンの段ごとの円板や、ジェットエンジンの前端のファンは「平たい側」、発電機のロータのような長い円筒は「ドラム側」です。$\gamma$ が 1 を超えるかどうかが、次の節で「前向きの危険速度が消える」境目になります。

:::analogy @ice-skater 腕を広げたスケーターと、腕を縮めたスケーター
回転軸まわりの慣性モーメント $I_p$ は、質量が回転軸から遠くにあるほど大きくなります。フィギュアスケートの選手が腕を広げると回転が遅くなり、縮めると速くなるのは、この $I_p$ が変わるからです。平たい円板は「腕を広げた」状態に近く、質量が回転軸から半径方向に広がって分布し、軸方向にはほとんど伸びていないので、$I_p$ が傾き方向の慣性 $I_d$ より大きくなります（一様な中実円板でも質量がふちに集まっているわけではなく、分布の「向き」の違いです）。一方、$I_d$ は質量が軸方向に長く伸びているほど大きくなります。長いドラムは $I_d$ が大きく、$\gamma$ は小さい。限界：スケーターのたとえは $I_p$ の側だけで、$\gamma$ はもう一つの慣性 $I_d$ との比なので、「平たいか長いか」の両方を見る必要があります。
:::

## 実機では：片持ちのファンと、両持ちの円板

![ジェットエンジンの断面模型](data/books/rotordynamics/images/gyro-split-3.jpg "写真：Pratt & Whitney JT9D ターボファンエンジンの断面展示。前端の大きなファンは軸受の外側に張り出している。（Wikimedia Commons, Cliff, CC BY 2.0）"){right}

ジャイロ効果がどれだけ効くかは、$\gamma$ だけでなく、円板が**どこに付いているか**でも変わります。軸受と軸受のちょうど真ん中に付いた円板は、軸がたわんでもほとんど傾きません（たわみの頂点では軸は水平なままです）。だから単純な[[link:jeffcott-intro|ジェフコットロータ]]ではジャイロ効果を無視できました。一方、軸受の外側に張り出した**片持ち**の円板は、たわむと大きく傾くので、ジャイロ効果が強く効きます。ジェットエンジンのファンはその典型で、巨大で平たい（$\gamma$ が大きい）うえに前端に張り出しているため、Campbell 線図の枝は大きく開きます。

:::field 設計で γ とジャイロ効果をどう扱うか
実機の計算では、円板ごとに $I_p$ と $I_d$ を入れた多自由度のモデル（有限要素や伝達マトリクス）で固有値を解き、回転数ごとに前向き・後ろ向きの固有振動数を求めて Campbell 線図を描きます。ジャイロの項は回転数に比例するので、固有値を回転数の関数として何度も解く必要があり、これが「回転機械の固有値計算は回転数の数だけ要る」と言われる理由です。設計の勘所は二つ。平たく重い円板が軸受の外に張り出す配置は、前向き枝を大きく持ち上げる反面、後ろ向き枝を大きく下げるので、後ろ向きの枝が運転範囲の励起と交わらないかを必ず確認すること。もう一つは、$\gamma \ge 1$ に近い平たい円板では前向きの危険速度が運転範囲から逃げることがあり、それを設計に使う場合は、[[link:anisotropy|支持の異方性]]などで後ろ向きが励起される可能性を別に見ておくことです。
:::

:::deep 傾きの向きが回る、ということの意味
$\psi = \Psi e^{i\omega t}$ は、傾きの大きさ $|\Psi|$ を保ったまま、傾きの向きが角速度 $\omega$ で回る解です。$\omega > 0$ は回転 $\Omega$ と同じ向き（前向き）、$\omega < 0$ は逆向き（後ろ向き）。このとき傾きの変化率は $\dot\psi = i\omega\psi$、ジャイロの項は $-iI_p\Omega\dot\psi = I_p\Omega\omega\,\psi$ となって、**傾きそのものに比例する**、つまりばねと同じ形になります。係数 $I_p\Omega\omega$ は前向きで正（硬くする）、後ろ向きで負（柔らかくする）。これが「返事の向きが振れ回りの向きで変わる」ことの数式での姿で、[[link:traveling-waves|翼振動章の進行波]]で前向きと後ろ向きを分けたのと同じ、$e^{i\omega t}$ の符号の話です。なお[[link:rotating-frame|回転座標系]]に乗って見ると、ジャイロの項はコリオリの力として現れます。
:::

## ひとことで

- 傾きながら振れ回る円板は、傾きの向きが回転と同じ向きに回る（前向き）か逆向きか（後ろ向き）で、ジャイロの返事が「起こす」か「倒す」かに分かれる。
- だから固有振動数は二本に分かれ、前向きは回転数とともに上がり、後ろ向きは下がる。開き方は γ = Ip/Id（円板の平たさ）で決まり、平たいほど大きい。
- 軸受の真ん中の円板はほとんど傾かず、片持ちの円板は大きく傾く。ジェットエンジンのファンはジャイロ効果が強く効く典型。

**模式・出典について**：枝の式は単一円板ロータの傾きモードの標準モデル（運動方程式と無次元化は本文のとおり）で、Campbell 部品はこの式をそのまま描いています。一様円柱の $\gamma$ の式は $I_p = mr^2/2$、$I_d = m(3r^2 + L^2)/12$ からの計算です。生成画像は「イメージ図」と明記し、事実は担わせていません。
