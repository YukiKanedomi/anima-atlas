# 翼の振動をどう測るか——ひずみゲージとブレードチップタイミング

ここまで、翼の固有振動数や応答を「計算で」扱ってきました。けれど設計の最後には、必ずこう問われます。**本当にそう揺れているのか**。計算は仮定の上に立っています。根元の固定条件、減衰、ミスチューニング、励起の強さ——どれも数字どおりとは限りません。だから翼は、回しながら測ります。

ところが相手は、毎秒数百回転で回り、数百度のガスに包まれ、1枚が1インチしかない翼です。止まっている軸なら[[link:bode-polar|変位センサ]]を当てれば済みますが、回っている翼にどうやって耳を当てるのか。この節では、その二つの代表的な方法と、後者に潜む「[[link:aliasing|サンプリングの罠]]」を見ていきます。

## 方法1：翼にひずみゲージを貼る

![金属面に貼られたひずみゲージ](data/books/rotordynamics/images/tip-timing-1.jpg "写真：金属表面に貼られたひずみゲージ。薄い箔のジグザグ配線が伸び縮みすると電気抵抗が変わる。（Wikimedia Commons, Cristian V., CC BY 4.0）"){right}

最も直接的なのは、翼の表面に**ひずみゲージ**（伸び縮みで抵抗が変わる薄い箔）を貼り、振動によるひずみをそのまま電気信号にする方法です。信号は波形そのものなので、[[link:spectrum|スペクトル]]を取れば周波数も振幅も分かり、ゲージを応力集中部の近くに貼れば疲労評価に直結します。

問題は、信号を**回る側から止まっている側へ運ぶ**ことです。

:::analogy @train 走る列車から外へ手紙を出す
回っている翼にゲージを貼るのは、走っている列車の中で観察日記を書くようなものです。書くのは簡単でも、それを駅のホーム（止まっている側）に届ける手段が要ります。スリップリングは、列車の屋根の集電装置が架線に擦れながら電気を受け取るのと逆向きに、擦れ合う接点で信号を外へ渡す方法。テレメトリは、列車から無線で送る方法です。擦れる接点は速く回るほど摩耗と雑音に悩まされ、無線は送信機と電源を列車に積まなければならない——どちらも「運ぶ」部分が一番の難所です。
:::

- **スリップリング**：軸に付けた金属環に、固定側のブラシを接触させて配線をつなぐ。構造は単純ですが、高速で回る軸では接触部の摩耗やノイズが問題になり、高温のタービンでは「ほとんど役に立たない」と評した特許文献もあります。
- **テレメトリ**：ロータに小さな送信機を載せ、無線で飛ばす。接触はなくなりますが、回転体に電子機器と電源を載せる重さ・遠心力・温度の制約があり、翼の枚数ぶんのゲージをまかなうには装置が大きく複雑になります。

さらに本質的な制約が2つあります。**チャンネル数**と**寿命**です。NASA の1980年の報告は、ひずみゲージ法は「翼の多い構造では必要なゲージの数と、スリップリングやテレメトリの限られたチャンネル数のために制約される」こと、そしてゲージの寿命と耐久性が常に悩みの種であることを率直に書いています。何十枚もの翼のうち、ゲージを貼れるのはせいぜい数枚。高温ガスの中でゲージは剥がれ、配線は切れ、試験のたびに貼り直す。それでも、根元の応力に直結する計測として、ひずみゲージは今も欠かせない役割を持っています。SSME の翼問題のときも、Rocketdyne は Whirligig と呼ぶ回転試験機でタービン翼車を 38,000 rpm まで回し、翼のひずみをゲージで測って減衰設計を詰めました。

![発電機のスリップリング](data/books/rotordynamics/images/tip-timing-2.jpg "写真：水力発電機のスリップリング。回転する環にばねで押し付けたブラシが滑って、回る側と止まった側のあいだで電気を受け渡す。翼のひずみ信号も同じ仕組みで外へ出せるが、接触は摩耗し、チャンネル数も限られる。（Wikimedia Commons, Wtshymanski, CC BY-SA 3.0）"){small}

## 方法2：翼の「通過時刻」を測る——ブレードチップタイミング

![ケーシングの光学プローブの模式図](data/books/rotordynamics/images/tip-timing-3.jpg "イメージ図（生成画像・模式）：ケーシングに取り付けた光学プローブが、回る翼の先端が通過する瞬間を検出する。回る側には何も載せない。"){right}

もう一つの方法は、発想を逆転させます。回る側には何も載せず、**ケーシング側にセンサ（プローブ）を固定して、翼の先端が目の前を通った瞬間の時刻**だけを記録するのです。これを**ブレードチップタイミング**（BTT）、あるいは非接触応力測定と呼びます。

理屈はこうです。翼が振動していなければ、各翼はきっちり等間隔の時刻にプローブの前を通ります。翼が振動していると、前縁が進行方向に少し進んだり遅れたりした瞬間に通過するので、通過時刻が期待値から $\Delta t$ だけずれる。回転の周速を $U$ とすれば、先端の周方向の変位は、小さな変位の範囲で $x \simeq U\,\Delta t$ です（符号は「遅れ」をどちら向きに取るかの定義によります。実際にはプローブが感じる方向への投影や、翼先端の形の補正も要ります）。周速が 400 m/s なら、1 µs のずれが 0.4 mm の変位に相当します。時刻を数十 ns の精度で測れば、翼先端の変位をサブミリで読める、というわけです。

:::analogy @timetable 駅の時刻表で、電車の揺れを知る
毎日同じ時刻に目の前を通るはずの電車（翼）が、ある日は 3 秒早く、翌日は 2 秒遅く来たとします。ホームに立って到着時刻を記録しているだけで、電車そのものに触れずに「電車が前後に揺れている」ことが分かります。BTT がやっているのはこれで、「来るはずの時刻からのずれ」を「翼先端の前後の変位」に読み替えています。違いは、電車は一日に一本ですが翼は一回転に一回通ること。そのため次に述べる「一回転一点」の罠が生まれます。
:::

**全部の翼を、一度に、回る側に何も載せずに**測れる。これが BTT の決定的な長所です。光学式・渦電流式・静電容量式のプローブがケーシングに数本あれば済みます。NASA ルイス研究センターは1980年の時点で、ケーシングに固定した光学プローブと計算機で「全翼先端の変位を同時にディジタル化する」概念を発表しています。

## 1回転1点——サンプリングの罠がそのまま現れる

ここに落とし穴があります。1本のプローブが翼を見るのは**1回転に1回**。つまり BTT は、振動を回転周波数 $\Omega$ で標本化しているのと同じです。[[link:aliasing|FFT 章]]で見たとおり、標本化周波数の半分（この場合 $\Omega/2$）より高い振動は、折り返して別の周波数に化けます。翼の固有振動数は回転周波数の何倍、何十倍もありますから、**BTT の標本は、ほぼ常にエイリアシングしている**のです。

:::analogy @pendulum-clock 毎朝同じ時刻に見る、振り子時計
振り子時計を、一日に一度、毎朝 7 時にだけ見るとします。振り子の周期がちょうど一日を整数で割った長さなら、毎朝まったく同じ位置に見え、止まっているのと区別がつきません。これが同期振動です。周期がそこから少しずれていれば、毎朝少しずつ違う位置に見え、「何日もかけてゆっくり揺れている」ように感じられます。これが見かけの周波数で、[[link:aliasing|扇風機のストロボ]]と同じ仕組みです。振り子と違うのは、翼の場合「止まって見える位置」が本来の位置からずれた所になる、という点で、そのずれ自体が振幅の手がかりになります。
:::

読み方のポイントを整理します。

- **同期振動（$f/\Omega$ が整数＝[[EO|励起次数]] $k$ の共振）**：各プローブの点は一定値。振動の情報は「平均位置からのずれ」という直流成分に化けます。実機で最も知りたいノズル通過による共振がまさにこれなので、BTT の処理法の多くはこの問題への答えです。
- **非同期振動（$f/\Omega$ が非整数：[[link:flutter|フラッタ]]や回転失速など）**：1本のプローブには見かけの周波数 $|f - k\Omega|$（$k$ は最も近い整数）で揺れて見えます。元の周波数そのものは1本では決まりませんが、「揺れている」ことは見えます。
- **プローブを増やす**：1回転の中で違う位相の点が増えるので、1回転あたりの標本が増え、同期振動でも各プローブの値の違いから振幅と位相を推定できます。不等間隔に配置すると、複数のモードを見分けやすくなります。

## 同期振動を、それでも測る

同期振動が「一定値」にしか見えないなら、どうやって共振を見つけるのか。実務で使われる考え方は2つです。

**回転数を掃引する**。共振は固有振動数と $k\Omega$ が一致する特定の回転数で起きます。回転数を上げていくと、共振の手前で翼の応答の位相が変わり始め、共振点で90°、通り過ぎると180°回ります（[[link:phase-lag|位相の話]]で見た、あの振る舞いです）。位相が回れば、プローブが見る「一定値」も回転数とともに変わります。つまり、回転数に対して各プローブの直流オフセットを追うと、共振のまわりで山と谷が現れる。つまり「止まって見える絵」を、回転数を少しずつ変えながら何枚も撮ると、共振の前後で絵が裏返る——その裏返りを捕まえるわけです。これが1本〜2本のプローブで同期共振を検出する原理で、Heath と Imregun の1998年の総説が整理した古典的な手法群の根っこです。

**複数のプローブで正弦波を当てはめる**。プローブが $P$ 本あれば、1回転の中で $P$ 個の位相の点が得られます。励起次数 $k$ を仮定し、$j$ 番目のプローブの角度を $\theta_j$ として、変位を

$$x_j = S_1 \sin(k\theta_j) + S_2 \cos(k\theta_j) + c$$

と置けば、未知数は $S_1, S_2, c$ の3つ。言葉にすると「振幅・位相・ずれの基準」という 3 つの分からないものがあるので、違う角度から見た 3 人以上の目撃者（プローブ）がいれば決められる、ということです。プローブが3本以上あれば最小二乗で解けて、振幅 $\sqrt{S_1^2+S_2^2}$ と位相が決まります。ここで $c$ は定常の曲がりなど全プローブに共通のずれです。プローブの取り付け誤差はプローブごとに違う値 $c_j$ になるので、校正していない場合は、静止時や低速時の通過時刻、回転数掃引などの別のデータで各 $c_j$ を先に求めておく必要があります。この直流成分を別に扱わないと当てはめが崩れることが、特許文献でも繰り返し注意されています。候補の $k$ を変えて残差が最小になるものを選べば、どの次数の共振かも推定できます（直接法と呼ばれる方法群は4本以上のプローブを前提にすることが多く、2本で済ませる「2パラメータプロット法」もあります）。

:::field 現場の作法：ゲージと BTT は競合ではなく相棒
BTT は全翼を一度に見られますが、見ているのは**翼先端の変位**であって、疲労に効く**根元の応力**ではありません。先端変位から応力への換算にはモード形（有限要素の計算）が要り、その換算の確かさを担保するのがひずみゲージです。ロールス・ロイスの特許には「1枚の翼に1枚のゲージを貼り、1〜2本のチップタイミングプローブを校正して全翼に展開する」という構成が書かれています。少数のゲージで校正し、BTT で全数を監視する——これが現在の標準的な組み合わせです。

もう一つ、BTT は全翼を測るので、[[link:bladed-disk-nd|節直径]]の推定にも使えます。ただし各翼はプローブの前を**違う時刻**に通るので、励起次数か振動周波数を仮定して各通過時刻を共通の時刻に位相補正したうえで、翼 $j$ の位相が $2\pi n j/N$ で並んでいるか（節直径 $n$ の進行波）、翼ごとにばらばらか（[[link:mistuning|ミスチューニング]]で局在した振動）を見ます。ひずみゲージだけでこれをやるには、周方向に何枚もゲージを貼って位相を比べる必要があり、チャンネル数の壁にすぐぶつかります。
:::

## ターボポンプの翼では

ロケットエンジンのターボポンプは、航空エンジンと比べて試験の機会がずっと少なく、1回の燃焼試験が貴重です。しかも翼は小さく（1インチ級）、ゲージを貼る面積も配線の通り道も乏しい。だからこそ、SSME の翼問題では Whirligig のような専用の回転試験機でゲージ計測と減衰評価を重ね、翼を1枚ずつ叩いて固有振動数を測るような地道な計測が設計を支えました。タービン側のケーシングにプローブを置くには、高温・高圧の水素リッチガス、狭い設置空間、光学窓や配線の耐久性という制約があり（極低温なのはポンプ側や冷却流路です）、航空エンジンほど自由には使えません。それでも、非接触で全翼を見られる利点は同じです。

計算で予測し、測って確かめ、ずれていれば予測の仮定を直す。翼振動の章はここで、設計から現場へとつながります。

## ひとことで

- 回っている翼を測るには、翼に貼ったゲージの信号を外へ運ぶか（走る列車から手紙を出す）、外から翼の通過時刻を測るか（駅で到着時刻を記録する）のどちらか。
- 通過時刻を測る方法は全翼を一度に見られるが、一回転に一点しか見ないので、回転の整数倍で揺れる振動は「止まって」見える。毎朝同じ時刻に見る振り子と同じ。
- だから回転数を変えながら見るか、プローブを増やして違う角度から見る。少数のゲージで校正し、全翼を通過時刻で監視するのが現場の組み合わせ。

**模式・出典について**：図の BTT は「翼の通過時刻に真の振動波形を1点標本化する」という原理を、翼の変位を誇張して描いた模式です。周波数・回転数・標本の関係は式どおりで、見かけの周波数 $|f - k\Omega|$ は FFT 章のエイリアシングの式と同じものです。
