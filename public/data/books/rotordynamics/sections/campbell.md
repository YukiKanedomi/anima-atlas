# 回転数で危険速度が変わる——Campbell線図

[[link:gyro-split|前の節]]で、円板の傾きモードの固有振動数は回転数とともに二本に分かれる、と分かりました。すると困ったことが起きます。[[link:natural-frequency|第 1 章]]では「固有振動数は一つの数で、回転数がそこに一致するところが危険速度」でした。固有振動数のほうが回転数で動くなら、危険速度はどこにあるのでしょう。

答えを一枚の図にしたのが **Campbell 線図**です。横軸に回転数、縦軸に振動数をとり、固有振動数が回転数とともにどう動くか（枝）と、回転数に比例して上がっていく励起の振動数（斜めの線）を同じ図に描く。二つが**交わる点**が危険速度です。固有振動数が動いても、交点を探せばよい。回転機械の設計で最もよく使われる図で、[[link:blade-campbell|翼振動章]]では励起線が何十本も走る版が出てきます。ここではその原型を、円板一枚のロータで読みます。

## 線図の作り方：枝と、斜めの線

まず**枝**。[[link:gyro-split|前の節]]の式のとおり、止まっているときの固有振動数 $\omega_0$ から出発して、前向きの枝は回転数とともに上がり、後ろ向きの枝は下がります。開き方は[[gamma|γ]]（円板の平たさ）で決まります。

次に**励起の線**。不釣り合いは円板と一緒に回っているので、ロータを「回転数と同じ振動数」で揺らします。横軸の回転数 $\Omega$ に対して縦軸の振動数が $\omega = \Omega$、つまり原点から伸びる対角線です（両軸の目盛りが等しければ 45°）。これを **[[order_1x|1×]] 励起線**と呼びます。回転数の 2 倍で揺らす原因（[[link:anisotropy|軸の異方性]]や[[link:rotating-frame|呼吸する亀裂]]）があれば 2× の線、翼が静翼の後流に叩かれるなら静翼枚数倍の線、というように、原因ごとに斜めの線が増えます。

そして

$$\text{危険速度} \;=\; \text{励起線と、固有振動数の枝が交わる点}$$

言葉にすると、「その回転数で揺らされる振動数」と「その回転数でロータが揺れたがる振動数」が一致する回転数が危険速度で、固有振動数が回転数で動くぶんは、枝を描いておけば交点が自動的に教えてくれる、ということです。

:::analogy @train 線路と踏切
Campbell 線図は、道路地図に似ています。固有振動数の枝は、起伏に沿って走る線路。励起の線は、まっすぐ伸びる道路。危険速度は、線路と道路が交わる**踏切**です。線路（固有振動数）が回転数で上下に動いても、踏切の場所は地図を見れば分かる。道路が何本もあれば（励起の原因が複数あれば）踏切も増え、線路が何本もあれば（モードが複数あれば）さらに増えます。設計とは、運転する区間に踏切を置かないように、線路か道路を動かすことです。限界：踏切は「そこを通ると必ず当たる」場所ではなく、「当たりうる」場所です。本当に大きく揺れるかどうかは、減衰と、揺らす力がそのモードを押せる形をしているか（翼振動章の[[link:zzenf-reading|二重条件]]）で決まります。
:::

## 交点の読み方

動かすと、いくつか大事なことが見えてきます。

- $\gamma = 0$（ジャイロなし）では枝は分かれず水平です。危険速度は一つで、$\Omega = \omega_0$ のところ。これは第 1 章で見た単純なロータです。
- $\gamma$ を上げると前向きの枝が立ち上がり、**前向きの危険速度が右へ逃げて**いきます。同じ機械でも、ジャイロ効果が強いほど危険速度は高回転側へずれる、ということです。
- $\gamma \ge 1$（薄い円板）になると、前向きの枝が 1× 線と**もう交わりません**。このモデルでは、有限の回転数に前向きの同期（1×）危険速度が**存在しなくなる**のです。

後ろ向きの枝も 1× 線と交わりますが、この図ではそこに印を付けていません。不釣り合いは前向きの力なので、支持が等方で理想的なら後ろ向きのモードを押せないからです。ただし[[link:anisotropy|支持に異方性がある]]と後ろ向きも励起されるので、実機の線図では後ろ向きの交点にも必ず目を配ります。

## 追い越せない前向きの枝——γ ≥ 1 の意味

危険速度が「消える」とは、どういうことでしょう。前向きの枝は、回転数が高いところでは $\gamma\Omega$ に近づいて立ち上がります。$\gamma > 1$ なら、枝の立ち上がる勢いが 1× 線の傾き（1）を上回り、どんなに回転を上げても 1× 線は枝に追いつけません。自分より速く逃げる相手を追いかけるようなものです。ちょうど $\gamma = 1$ では枝の傾きは 1× 線と同じ 1 に近づきますが、枝は常に 1× 線の上側にあって（$\omega_0$ ぶん先に出発し、差は縮まっても消えません）、やはり交わりません。どちらの場合も交点が存在しないので、この単一円板・等方支持の線形モデルでは、不釣り合い（1×）による前向きの共振は起きないことになります。ただしこれは「同期の前向き励起に限った話」で、他の次数の励起、他のモード、[[link:anisotropy|支持の異方性]]や非線形による共振まで無いと言っているわけではありません。

:::analogy @car-wall 交点が無くても、近づきすぎれば当たる
踏切が無い区間でも、線路と道路がすれすれに並んで走っていれば、少し線路がずれただけで当たります。$\gamma$ が 1 に近いと、前向きの枝と 1× 線はなかなか交わらないまま、長い区間ほとんど平行に並びます。固有振動数は温度や製造ばらつきで数パーセント動くので、「交点が無い」ことと「十分離れている」ことは別です。[[link:runup-transient|第 1 章]]で壁ぎりぎりに車を停めなかったのと同じで、運転範囲の中では枝と励起線のあいだに距離（離隔余裕）を取ります。限界：どれだけ離せば十分かは機種と規格によります（下の実務の囲み）。
:::

## 線が増えるとき

ここまでの図は、円板一枚、モード一つ、励起線一本でした。実機の Campbell 線図は、三つの理由でにぎやかになります。

**モードが増える。** 軸は[[link:mode-shapes|いくつもの形で曲がる]]ので、曲げの 1 次、2 次、3 次とモードの数だけ枝の組が増えます。それぞれが前向きと後ろ向きに分かれるので、枝は 2 倍。[[link:multi-critical|危険速度がいくつもある]]のはこのためです。

**励起線が増える。** 1× のほかに、2×（異方性、ミスアライメント）、翼の枚数倍（静翼の後流）、歯車の歯数倍、電動機なら極数に関係する次数、といった線が加わります。[[link:blade-campbell|翼振動章の Campbell 線図]]では、励起線が扇のように何十本も走ります。

**枝が水平でなくなる。** ジャイロ効果だけでなく、[[link:blade-stiffening|遠心力による硬化]]（翼では大きい）や、油膜軸受の硬さが回転数で変わること（[[link:journal-bearing|第 4 章]]）でも枝は曲がります。

読み方は変わりません。運転する回転数の範囲を縦の帯で塗り、その帯の中にある交点を一つずつ拾って、本当に危険か（減衰は、力の形は合うか）を判定していく。これが設計審査で Campbell 線図を見るときの手順です。

:::field 離隔余裕と規格
石油・ガス産業向けのターボ機械の規格 API 617 と、その解説にあたる API 684 は、危険速度を運転範囲からどれだけ離すか（離隔余裕、separation margin）を、共振の鋭さ（増幅率）に応じて定めています。増幅率が大きい（減衰が小さい）ほど大きな余裕を求め、増幅率が十分小さければ運転範囲の中に危険速度があっても許容される、という考え方です。具体的な数値は規格の版によって異なるので、設計では該当する版の本文を確認してください。考え方の芯は二つです。一つ、交点の位置だけでなく、その共振がどれだけ鋭いかをセットで見る。二つ、計算上の交点は数パーセント動くものとして、余裕を距離で持つ。実測で危険速度を確かめる方法は[[link:bode-polar|計測の章]]で扱います。
:::

:::history Campbell と Stodola
Campbell 線図の名は、米国 General Electric の技師 Wilfred Campbell（1884〜1924）に由来します。1910 年代後半から 1920 年代初めにかけて、蒸気タービンの円板（ディスク）が軸方向に振動して疲労破壊する事故が問題になり、Campbell は回転する円板の振動を実測して、円板の固有振動数と回転数の整数倍が一致する条件を一枚の図にまとめました。1924 年に GE から出た報告「Protection of Steam Turbine Disk Wheels from Axial Vibration」がそれで、彼は同じ年に 40 歳前後で亡くなっています。線図はもともと翼車の円板のためのものでしたが、「回転数で動く固有振動数と、回転数に比例する励起を同じ図に描く」という発想は軸の振れ回りにもそのまま使え、今では回転機械全般の共通語になりました。

同じ時代、チューリッヒ工科大学の Aurel Stodola（1859〜1942）は蒸気タービンの大著（初版 1903 年、第 6 版 1924 年、英訳 1927 年）で、たわむ軸と円板の振動、危険速度の計算法、釣り合わせまでを体系化し、Rankine が「危険速度は超えられない」とした誤りを、円板の運動を正しく扱うことで解いた一人とされています。
:::

Campbell 線図が読めると、「この回転数で運転して大丈夫か」「危険速度をどちらへ逃がすか」が一目で分かります。危険速度、[[link:whirl-direction|前向きと後ろ向きの振れ回り]]、ジャイロ効果。これまで見てきた話が、すべてこの一枚に集約されます。

:::deep 固有値問題の形——枝分かれの出どころ
円板の傾きを複素角 $\psi$ で表すと（$I_d$：傾き方向の慣性、$I_p$：回転軸まわりの慣性、$k_t$：傾きに対するばね）、運動方程式は

$$I_d\,\ddot\psi \;-\; i\,I_p\,\Omega\,\dot\psi \;+\; k_t\,\psi = 0$$

言葉にすると、慣性とばねの釣り合いに、回転数に比例して 90° 回った向きに働くジャイロのモーメントが一項加わる、ということです。第 2 項がジャイロモーメントで、$i$ が付いている＝**傾きと直角の向き**に働くのがコマの首振りの数学的な姿です。$\psi = \Psi e^{i\omega t}$ を入れると

$$I_d\,\omega^2 - I_p\,\Omega\,\omega - k_t = 0$$

言葉にすると、ジャイロの項が振れ回りの向き（$\omega$ の符号）によって硬さを足したり引いたりする、ということです。この $\omega$ の 2 次方程式の**2 つの根**が前向き枝と後ろ向き枝です。$\gamma = I_p/I_d$、$\omega_0 = \sqrt{k_t/I_d}$ で無次元化すると、下の「模式・出典」の式に一致します。

さらに $\omega = \Omega$（1× 線との交点）を代入すると $(I_d - I_p)\,\Omega^2 = k_t$。左辺が正でないと解がない、つまり交点が存在するのは $I_p < I_d$（$\gamma < 1$）のときだけ。これが「$\gamma \ge 1$ で前向きの同期危険速度が消える」ことの、式からの確かめです（$\gamma = 1$ では左辺がゼロで、$k_t > 0$ である限り解がありません）。
:::

## ひとことで

- Campbell 線図は、横軸に回転数、縦軸に振動数をとり、回転数で動く固有振動数（枝）と回転数に比例する励起（斜線）を重ねた図。交点が危険速度。
- ジャイロ効果で枝は前向き（上がる）と後ろ向き（下がる）に分かれ、γ ≥ 1 の平たい円板では（このモデルの範囲で）前向きの同期危険速度が消える。
- 実機ではモードの数と励起の原因の数だけ線が増える。読み方は同じで、運転範囲の中の交点を拾い、鋭さと離隔余裕で判定する。

**模式・出典について**：図は単一円板ロータのジャイロ効果の標準モデル（前向き $\omega_f=\frac{\gamma}{2}u+\sqrt{(\frac{\gamma u}{2})^2+1}$、後ろ向き $\omega_b=-\frac{\gamma}{2}u+\sqrt{(\frac{\gamma u}{2})^2+1}$、$u=\Omega/\omega_0$）をそのまま描いたものです。軸は静止固有振動数 $\omega_0$ で規格化した無次元で、形と交点は式どおりです。後ろ向き枝は等方支持の不釣り合いでは励起されないため、危険速度として印は付けていません。Wilfred Campbell の生没年と 1924 年の GE 報告の書誌はテキサス A&M 大学と IISc の図書館目録、当時の円板破損との関係は 1920 年代の英国の論評（IMarEST 所蔵）、Stodola の経歴と著書は Wikipedia「Aurel Stodola」と NPTEL のロータダイナミクス史講義によります。API 617/684 の離隔余裕は「増幅率に応じて定める」という考え方のみを記し、数値は規格本文に委ねました。
