# 回転数で危険速度が変わる——Campbell線図

回っているコマは、押しても素直に倒れません。押した向きにではなく、**横へ**首を振ってかわします（歳差運動）。「回転体は、傾けようとすると横に逃げる」——これが**ジャイロ効果**です。ロータに付いた円板も高速で回るコマそのものなので、軸がたわんで円板が傾くたびに、ジャイロ効果が口を出してきます。

これまで[[omega_n|固有振動数 ωn]]は、[[link:natural-frequency|軸の硬さと円板の重さ]]で決まる**一定の値**として扱ってきました。ところが回転体では、**回る速さそのものが固有振動数を変えます**。

## コマの首振りと同じ理屈

なぜ2本に分かれるのでしょうか。円板が傾いたまま振れ回ると、ジャイロ効果のモーメントが働きます。[[link:whirl-direction|前向き]]の振れ回りでは、このモーメントが傾きを**起こす向き**に働き、軸が実際より**硬く**なったように見える——だから固有振動数が上がる。**後ろ向き**では逆に傾きを**倒す向き**に働き、**柔らかく**見える——だから下がる。しかもこの効き目は回転数に比例するので、回せば回すほど2本の枝は大きく開いていきます。

この「**回転数 vs 固有振動数**」の枝分かれを1枚にまとめたのが **Campbell線図** です。ここに、もう1本だけ線を足します。不釣り合いは「回転数と同じ振動数」でロータを揺らすので、$\omega = \Omega$ の斜めの線（**[[order_1x|1×]]励起線**）を引きます。そして——

$$\text{危険速度} \;=\; 1\times\text{励起線と、固有振動数の枝が交わる点}$$

下の図で、**ジャイロの強さ [[gamma|γ]]**（円板の扁平さ）と**運転回転数**を動かしてみてください。

## 交点の読み方

動かすと、いくつか大事なことが見えてきます。

- $\gamma = 0$（ジャイロなし）→ 枝は分かれず水平。危険速度は1つで、$\Omega = \omega_0$ のところ。これは第1章で見た単純なロータです。
- $\gamma$ を上げる → 前向き枝が立ち上がり、**前向きの危険速度が右へ逃げて**いきます。同じ機械でも、ジャイロ効果が強いほど危険速度は高回転側へずれる、ということです。
- $\gamma \ge 1$（薄い円板）→ 前向き枝が1×線と**もう交わらない**＝前向きの危険速度が**消える**。

## 追い越せない前向き枝——γ ≥ 1 の意味

最後の項目は不思議に見えます。危険速度が「消える」とは？

[[gamma|γ]] は円板の扁平さ（回転軸まわりの慣性と、傾き方向の慣性の比）で、薄く平たい円板ほど大きくなります。$\gamma \ge 1$ になると、前向き枝が立ち上がる勢いが1×線の傾きを上回り、どんなに回転を上げても**1×励起は前向きモードに追いつけません**。ちょうど、自分より速く逃げる相手を追いかけるようなもの——交点が存在しないので、前向きの共振は起きないのです。薄い円板を持つ高速ロータで意識的に使われる、大事な性質です。

Campbell線図が読めると、「この回転数で運転して大丈夫か」「危険速度をどちらへ逃がすか」が一目で分かります。危険速度・[[link:whirl-direction|前向き/後ろ向き振れ回り]]・ジャイロ効果——これまで見てきた話が、すべてこの1枚に集約されます。実物のロータでは軸の曲げの[[link:mode-shapes|モードの数だけ枝が増え]]、線図はもっとにぎやかになりますが、読み方はここで覚えたとおりです。

:::deep 固有値問題の形——枝分かれの出どころ
円板の傾きを複素角 $\psi$ で表すと（$I_d$：傾き方向の慣性、$I_p$：回転軸まわりの慣性、$k_t$：傾きに対するばね）、運動方程式は

$$I_d\,\ddot\psi \;-\; i\,I_p\,\Omega\,\dot\psi \;+\; k_t\,\psi = 0$$

第2項がジャイロモーメントです。回転数 $\Omega$ に比例し、$i$ が付いている＝**傾きと直角の向き**に働くのがコマの首振りの数学的な姿。$\psi = \Psi e^{i\omega t}$ を入れると

$$I_d\,\omega^2 - I_p\,\Omega\,\omega - k_t = 0$$

という $\omega$ の2次方程式になり、**2つの根**が前向き枝と後ろ向き枝です。$\gamma = I_p/I_d$、$\omega_0 = \sqrt{k_t/I_d}$ で無次元化すると、下の「模式・出典」の式に一致します。

さらに $\omega = \Omega$（1×線との交点）を代入すると $(I_d - I_p)\,\Omega^2 = k_t$。左辺が正でないと解がない——つまり交点が存在するのは $I_p < I_d$（$\gamma < 1$）のときだけ。これが「$\gamma \ge 1$ で前向き危険速度が消える」ことの、式からの確かめです。
:::

**模式・出典について**：図は単一円板ロータのジャイロ効果の標準モデル（前向き $\omega_f=\frac{\gamma}{2}u+\sqrt{(\frac{\gamma u}{2})^2+1}$、後ろ向き $\omega_b=-\frac{\gamma}{2}u+\sqrt{(\frac{\gamma u}{2})^2+1}$、$u=\Omega/\omega_0$）をそのまま描いたものです。軸は静止固有振動数 $\omega_0$ で規格化した無次元で、形と交点は式どおりです。なお後ろ向き枝は通常の不釣り合い（前向き）では励起されないため、危険速度として印は付けていません。
