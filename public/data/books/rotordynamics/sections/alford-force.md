# 翼先のすきまが生む力——アルフォード力

![シュラウド付きタービン翼と翼先すきまの模式図](data/books/rotordynamics/images/alford-force-1.jpg "イメージ図（生成画像・模式）：ケーシングの下に並ぶタービン翼の列と、翼先をつなぐ環（シュラウド）、その上のすきまを漏れる流れを描いた絵。"){right}

1960 年代、General Electric のジェットエンジンで、油膜でもシールでも説明のつかない振れ回りが起きていました。原因を突き止めた J. S. Alford は 1965 年の論文で、犯人が圧縮機やタービンの**翼の先端**にあることを示します。ロータがわずかに偏ると、翼先とケーシングのすきまが片側で狭く、反対側で広くなる。すきまの狭い側の翼はガスをよく掴んで強く回し、広い側は漏れが多くて弱い。この**力の偏り**が、ロータを横へ押す力になっていたのです。同じ力は 7 年前の 1958 年、ドイツの H. J. Thomas が蒸気タービンで指摘していました。

[[link:whirl-instability|自励振動の節]]で、「犯人は違っても数学は同じ」と言いました。油膜・シール・翼端すきま——どれも[[q|クロスカップリング q]] を生み、[[c|減衰 c]] に勝てば前向きに発散する。この節では、その犯人の一人の**顔をちゃんと見て**おきます。タービンや圧縮機の翼の先っぽで生まれる、アルフォード力（蒸気タービンではトーマス力）です。油膜の力は油を替えれば変わり、シールの力は旋回を止めれば弱まりますが、この力は**仕事をしている限り、油の対策では消えません**。

舞台は、ケーシングの中で回る**動翼つきのロータの断面**。設計どおりなら、翼先とケーシングのすきまは全周で均一です。でもロータがわずかに横へずれたら？

## からくり：漏れの差が、力の差になる

![翼先を漏れる流れの模式図](data/books/rotordynamics/images/alford-force-2.jpg "イメージ図（生成画像・模式）：一枚の翼の先端とケーシングのあいだのすきまを、圧力面から負圧面へ漏れ抜ける流れ（臙脂）と、翼にそって流れる主流（紺）を描いた絵。"){right}

翼先のすきまは、仕事をせずに素通りする**漏れ道**です。すきまが狭い側の翼は漏れが少なく、ガスをしっかり掴んで**大きな接線力**（ロータを回す力）を出します。広い側は漏れが多く、力が小さい。

接線力そのものはロータを「回す」だけの力です。でも**左右で大きさが違う**と、全周の合計が打ち消しきれず、**変位と直角の正味の力**が残ります（上のブロックで実際に足し算しています）。右へずれたロータは上へ押され、上へずれたら左へ押され……と、力はいつも**変位の90°先**を押し続ける。これは[[link:whirl-instability|自励振動の節]]で見た「回転と同じ向きに押し続ける力」そのもの——**前向き振れ回りにエネルギーを注ぐ**構図です。ただしこれは、すきまの狭い側がよく働く（係数 β が正）タービンの典型で、圧縮機では運転点によって β が負になり、横押しが逆向き（前向き振れ回りを抑える側）になる報告もあります。

翼先のすきまは、[[link:blade-excitation|翼振動章]]では「翼を叩く手」の一つとして登場しました。同じすきまが、翼を叩くだけでなくロータ全体を横へ押しもする。翼の設計者とロータの設計者が同じ寸法を別の理由で気にしている、という場面です。

## トルクに比例する——高出力ほど危ない

Alford がこの力を整理した式は、驚くほどシンプルです。

$$q = \frac{\beta\,T}{D\,H}$$

言葉にすると、「横へ押す力の係数は、段のトルクに比例し、翼のピッチ円直径と翼の高さに反比例する。つまり同じ出力なら、小さくて翼の短い段ほど強く押される」ということです。$T$ は段のトルク（＝どれだけ仕事をしているか）、$D$ は翼のピッチ円直径、$H$ は翼の高さ、$\beta$ は経験係数。**分子がトルク**であることが急所で、機械の出力を上げるほど、この横押し力は**比例して強く**なります。[[link:whirl-instability|自励振動の節]]で「高出力機ほど危ない」と書いた根拠がこの式です。

:::analogy @scale-weight 体重計の目盛りは、乗る人の重さに正直に比例する
この式の恐ろしさは、「出力を上げた分だけ、きっちり比例して横押しが増える」ことにあります。体重計の目盛りが乗る人の重さに正直なように、アルフォード力は機械がしている仕事に正直です。油膜なら油温や荷重で逃げ道がありますが、出力を上げたい機械に「仕事を減らせ」とは言えません。だから対策は、綱引きの相手（減衰）を強くするか、同じ仕事でも $\beta$ やすきまの不均一を小さくする設計（翼先・シールの形、すきまの管理）になります。限界：$\beta$ は段の設計で大きく変わる経験係数で、符号が負になることもあり、体重計ほど正確な目盛りではありません。
:::

しかも発生源は空力なので、油膜と違って**油を替えても直接は消えません**。$q = \beta T/(DH)$ の形から、効くのは：

- **βT を小さく・均一にする**：負荷や運転点でトルクが変われば q も変わる。翼先やシールの形で β を抑えることも設計変数です。
- **翼先すきまの管理**：偏心そのものを小さく（すきまを均一に保つ）。
- **シュラウド付き動翼**：翼先を環でつないで、すきまの働きの差を鈍らせる。ただしシュラウドの外側には別のシールが要り、そのシールが今度は旋回流の q を生みうるので、話は一筋縄ではいきません。
- **綱引きの相手を強くする**：[[link:stability-chart|安定の地図]]で見たとおり、ダンパ軸受などで減衰 c を増やし、運転点を安定域の奥へ。

:::field 規格は Alford の式で「まず見積もる」
圧縮機の規格 API 617 の第一段階の安定性審査は、各段のクロスカップリングをこの式を改めた簡易式で見積もり、全段の合計をロータの中央に置いて対数減衰率を計算します（[[link:stability-chart|安定の地図]]の実務の囲み）。つまりアルフォード力は、規格が最初に疑う犯人です。現場の勘所を三つ。第一に、圧縮機では $\beta$ が負になる（力が安定化に働く）報告もあり、符号も大きさも段の設計に依存します。第二に、すきまは運転中に熱膨張と遠心力で変わるので、冷間の寸法で計算しても当たりません。第三に、出力を上げる改造（アップレート）は、q をそのぶん増やす改造でもあります。改造後に 1× より低いピークが育ち始めたら、この力を疑ってください。
:::

:::history トーマスとアルフォード——二度発見された力
この力は歴史上、二度「発見」されています。1958年、H. J. Thomas が**蒸気タービン**の不安定振動の原因として、シールと翼のすきまからの蒸気の漏れによる力を指摘し、1965年、J. S. Alford が**ジェットエンジンの圧縮機**で独立に同じ機構を報告しました。だから蒸気系ではトーマス力、ガスタービン・圧縮機系ではアルフォード力と呼び分けられますが、中身は同じ「翼先すきまの不均一が生む接線力の偏り」です。

係数 $\beta$（アルフォードの β）は段の設計に依存する経験値で、タービンではおおむね 1〜1.5、圧縮機では負値（安定化に働く場合がある）も報告されるなど、単純ではありません。確からしい値の見積もりが難しいことが、いまも高出力ターボ機械の安定性評価を悩ませています。1970〜80 年代には高圧の遠心圧縮機で出力を上げたとたんに亜同期振動が出る事例が相次ぎ、Alford の式を使った審査が規格に取り込まれていきました。
:::

## ひとことで

- ロータが偏ると翼先すきまが片側で狭くなり、狭い側の翼だけよく働く。接線力の偏りが残って、変位と直角の力（q）になる。
- その大きさは段のトルクに比例し、翼の直径と高さに反比例する。出力を上げるほど、きっちり比例して危なくなる。
- 空力の力なので油の対策では消えない。βT とすきまの不均一を抑え、減衰を足して綱引きに勝つ。規格はこの式でまず見積もる。
