# 翼先のすきまが生む力——アルフォード力

[[link:whirl-instability|自励振動の節]]で、「犯人は違っても数学は同じ」と言いました。油膜・シール・翼端すきま——どれも[[q|クロスカップリング q]] を生み、[[c|減衰 c]] に勝てば前向きに発散する。この節では、その犯人の一人の**顔をちゃんと見て**おきます。タービンや圧縮機の**翼の先っぽ**で生まれる、アルフォード力（蒸気タービンではトーマス力）です。

舞台は、ケーシングの中で回る**動翼つきのロータの断面**。設計どおりなら、翼先とケーシングのすきまは全周で均一です。でもロータがわずかに横へずれたら？

## からくり：漏れの差が、力の差になる

翼先のすきまは、仕事をせずに素通りする**漏れ道**です。すきまが狭い側の翼は漏れが少なく、ガスをしっかり掴んで**大きな接線力**（ロータを回す力）を出します。広い側は漏れが多く、力が小さい。

接線力そのものはロータを「回す」だけの力です。でも**左右で大きさが違う**と、全周の合計が打ち消しきれず、**変位と直角の正味の力**が残ります（上のブロックで実際に足し算しています）。右へずれたロータは上へ押され、上へずれたら左へ押され……と、力はいつも**変位の90°先**を押し続ける。これは[[link:whirl-instability|自励振動の節]]で見た「回転と同じ向きに押し続ける力」そのもの——**前向き振れ回りにエネルギーを注ぐ**構図です。

## トルクに比例する——高出力ほど危ない

Alford がこの力を整理した式は、驚くほどシンプルです。

$$q = \frac{\beta\,T}{D\,H}$$

$T$ は段のトルク（＝どれだけ仕事をしているか）、$D$ は翼のピッチ円直径、$H$ は翼の高さ、$\beta$ は経験係数。**分子がトルク**であることが急所で、機械の出力を上げるほど、この横押し力は**比例して強く**なります。[[link:whirl-instability|自励振動の節]]で「高出力機ほど危ない」と書いた根拠がこの式です。

しかも発生源は空力なので、油膜と違って**回転数を下げても油を替えても消えません**。効くのは：

- **翼先すきまの管理**：偏心そのものを小さく（すきまを均一に保つ）。
- **シュラウド付き動翼**：翼先を環でつないで、すきまの働きの差を鈍らせる。
- **綱引きの相手を強くする**：[[link:stability-chart|安定の地図]]で見たとおり、ダンパ軸受などで減衰 c を増やし、運転点を安定域の奥へ。

:::deep トーマスとアルフォード——二度発見された力
この力は歴史上、二度「発見」されています。1958年、H. J. Thomas が**蒸気タービン**の不安定振動の原因として指摘し、1965年、J. S. Alford が**ジェットエンジンの圧縮機**で独立に同じ機構を報告しました。だから蒸気系ではトーマス力、ガスタービン・圧縮機系ではアルフォード力と呼び分けられますが、中身は同じ「翼先すきまの不均一が生む接線力の偏り」です。

係数 $\beta$（アルフォードの β）は段の設計に依存する経験値で、タービンではおおむね 1〜1.5、圧縮機では負値（安定化に働く場合がある）も報告されるなど、単純ではありません。確からしい値の見積もりが難しいことが、いまも高出力ターボ機械の安定性評価を悩ませています。
:::

**模式・出典について**：断面図は偏心とすきまを**大きく誇張した模式**です（実機のすきまは翼高さの1%オーダー）。接線力の分布 $F(\theta)=F_0(1+\kappa\cos\theta)$ と、その合計が変位と直角に $N F_0 \kappa/2$ で残ることは計算どおり（独立検証済み）。$q=\beta T/(DH)$ は Alford (1965)・Thomas (1958) による古典的整理です。
