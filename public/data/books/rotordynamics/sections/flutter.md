# 翼自身が励起源になるとき——フラッタ

旗が風にはためく様子を思い浮かべてください。風は一定で、誰も旗を揺すっていないのに、旗は勝手に波打ちます。風が旗を押し、押された旗が傾いて風の受け方を変え、変わった力がまた旗を押す——揺れが自分で自分を育てる仕組みです。吊り橋が風で大きくうねって落ちたタコマ橋の事故も、同じ族の現象でした。

翼振動の章ではこれまで、ノズルの後流や部分噴射といった「外から叩く手」による**強制振動**を扱ってきました。この節で見るのは、叩く手がなくても翼が勝手に揺れ出す**自励振動**、翼の世界で**フラッタ**と呼ばれるものです。[[link:whirl-instability|軸受の自励振れ回り]]を学んだ方は、構図がそっくりなことに気づくはずです。あのときは油膜のクロスカップリングが「負の減衰」として働きました。ここでは、流れが翼にする仕事がその役を演じます。

## 減衰が負になる、とは

振動する翼のまわりの流れは、翼の動きに応じて変わり、翼に力を返します。この力のうち、翼の**速度と同じ向き**に働く成分が正味で正なら、1周期のあいだに流れが翼に**正味の仕事**をします（正弦波で書くと、力が変位より位相で**進んで**いる状態です）。流れが翼にエネルギーを渡し続ければ、振幅は毎周期少しずつ育ちます。式で書けば、流れの効果は等価的な減衰比 $\xi_\text{aero}$ として扱え、

$$\xi_\text{total} = \xi_\text{aero} + \xi_s$$

の合計が負になった瞬間、[[link:transmissibility|減衰のある1自由度系]]の解 $e^{-\xi\omega t}$ の指数が正に転じて、振幅は指数関数で膨らみます。$\xi_s$ は材料・摩擦などの構造減衰です。フラッタの判定はこの一行に尽きます。**空力減衰が構造減衰を食いつぶすかどうか**です。

:::analogy ブランコを「逆らって押す」か「合わせて押す」か
減衰とは、揺れに逆らう向きに働く力のことです。ブランコが手前に来るたびに押し返せば揺れは小さくなり（正の減衰）、遠ざかる瞬間に背中を押せば揺れは育ちます（負の減衰）。流れが翼に返す力は、翼の変位とぴったり同じ拍子ではなく、少し位相がずれます。そのずれ方によっては、1 往復のうち「動きに合わせて押している時間」が「逆らっている時間」よりわずかに長くなります。すると毎回ほんの少しずつエネルギーが足され、やがて揺れが膨らみます。ブランコでは押し手が向きを選びますが、翼では流れの「位相のずれ」が自動的に向きを決めてしまう——そこが自励振動の怖さです。
:::

## 翼列では隣が効く——翼間位相角

一枚の翼でも、曲げとねじりが連成するフラッタや失速フラッタは起こりえます。けれど翼列では、一枚の動きが隣の流路を通じて他の翼の空気力を変えるため、隣との関係が主役になります。ここで思い出してほしいのが、[[link:bladed-disk-nd|翼付き円盤の節直径]]と[[link:traveling-waves|進行波]]です。翼列の振動は、隣の翼とどれだけ位相がずれているかで性格が決まります。隣との位相差を**翼間位相角** [[IBPA|σ]] と呼び、翼が $N$ 枚で周期対称なら、許される値は

$$\sigma_n = \frac{2\pi n}{N},\qquad -\frac{N}{2} < n \le \frac{N}{2}$$

のとびとびの値だけです（Lane の仮定）。$|n|$ が節直径、符号が進行波の向きに対応します。この本の約束（[[link:traveling-waves|第II部]]）に合わせると、翼 $j$ の変位を $u_j = \Re\{U e^{i(\omega t + \sigma j)}\}$、$\sigma = 2\pi q/N$（$q$ は符号付きの折り返し次数）と書き、翼番号は回転の向きに付けます。この定義では**正の $\sigma$ は翼番号が減る向き＝後ろ向きに進む波**、負の $\sigma$ が前向きの波です。符号の約束は著者や解析ソフトによって逆のことがあるので、論文や図を読むときは必ず定義を確かめてください。言葉にすると、翼間位相角は「隣の翼が自分よりどれだけ先に（または後に）動いているか」の角度で、翼列全体では「波がどの向きに、どれくらい細かく進んでいるか」を表します。

:::analogy スタジアムのウェーブ
観客席のウェーブは、隣の人が自分より少し先に立ち上がることで波になります。この「少し先」が翼間位相角です。隣との位相差が小さいほど周方向の波長は長く（小さな節直径）、位相差が大きいほど細かい波になります。波が進む速さは、位相差だけでなく振動数との組合せで決まります。全員が同時に立てば波ではなく一斉起立（σ = 0）、隣と交互なら最も細かい波（σ = 180°）です。観客席と違うのは、翼では「隣がいつ動くか」で自分と隣の間の流路の広がり方が変わり、**自分が受ける力まで変わる**ことです。この一点が、位相角が安定・不安定を分ける理由になります。
:::

なぜ位相角が効くのか。隣の翼が自分より少し先に（あるいは後に）動いていると、翼と翼の間の流路の広がり方が変わり、自分の翼に返ってくる空気力の位相が変わります。つまり**空力減衰は σ の関数**であり、ある σ では正（流れが揺れを吸い取る）、別の σ では負（流れが揺れを育てる）になりえます。Carta が1967年に示した枠組みでは、翼・円盤・シュラウドの連成モードごとに、流れが1周期にする仕事の符号で安定性を判定します。これが今日まで使われる**エネルギー法**の原型です。

## 無次元振動数——揺れの速さを流れの速さで測る

:::analogy 川の流れの中で手を動かす
川に手を入れて、ゆっくり向きを変えると、水は手の向きに素直についてきて、強く押し返してきます。逆に手を素早く小刻みに震わせると、水はその動きに追いつけず、手はほぼ「平均の向き」に対する力しか受けません。翼がゆっくり揺れて流れが速い（流れが追いつける）ほど、流れは翼に大きな力を返し、仕事をしやすい。翼が速く揺れて流れが遅いほど、流れは翼を素通りしてしまい、仕事をしにくい。この「流れが追いつけるかどうか」を一つの数にしたのが、次の無次元振動数です。ただし本当に揺れが育つかどうかは、力の大きさだけでなく「どんな位相で返ってくるか」（上のブランコの話）で決まります。
:::

もう一つの主役が**無次元振動数**（reduced frequency）[[k_red|k*]] です。

$$k^{*} = \frac{\omega\, c}{V}$$

$\omega$ は翼の振動の角振動数、$c$ は翼弦長、$V$ は翼に当たる流れの相対速度。意味は「流体が翼の上を通り抜ける時間 $c/V$ を、翼の振動の周期で測った比」で、正確にはその比の $2\pi$ 倍です。つまり「翼が 1 回揺れる間に、流れが翼を何枚ぶん通り過ぎるか」の逆数のようなもので、値が小さいほど流れが翼の動きに追いつけます（翼弦の代わりに半翼弦 $b = c/2$ を使う流儀もあり、その場合は値が半分になります。論文を読むときは定義を確認してください）。

- $k^{*}$ が**小さい**＝翼がゆっくり揺れ、流れは速い。流れは翼の動きに「ついて行けて」、翼の姿勢変化に応じて大きな力を返します。流れが仕事をしやすく、一般には**危険側に寄りやすい**。
- $k^{*}$ が**大きい**＝翼が速く揺れ、流れはその間に翼を通り過ぎてしまう。流れは平均的な姿勢しか見えず、返す力は小さい。一般には**安全側に寄りやすい**。

ただし $k^{*}$ の大小だけで安定・不安定は決まりません。流れがする仕事はマッハ数・迎え角・モード形・翼間位相角・衝撃波や剥離の有無で非単調に変わり、$k^{*}$ が大きくても非定常の付加質量や位相のずれは残ります。実機の判定は、各翼間位相角・各運転点について 1 周期の空力仕事を計算して行います。

長くて柔らかい翼（固有振動数が低い）が速い流れの中にある——これが最もフラッタに弱い組み合わせです。ファンの前縁の長い翼や、低圧タービンの細長い最終段翼で問題になるのはこのためで、低圧タービンのフラッタは「低い無次元振動数と小さな節直径で起きる」とまとめられています。

## 図の読み方

- $k^{*}$ を下げる（長い翼・速い流れ）と、曲線の底が沈んで臙脂の領域が広がり、特定の節直径の点がそこへ落ちます。表示される「最も危ないモード」は、たいてい**小さな節直径の進行波**です。向きは模式の置き方（曲線の底の位置 σmin）で決まるので実機の値ではありませんが、実機のファンでも「前向き波・節直径4でフラッタ」といった報告があります。
- 構造減衰 $\xi_s$ を上げると、曲線ごと持ち上がって負の領域が消えます。摩擦ダンパやシュラウドで構造減衰を稼ぐことが、フラッタ対策にもなる理由です。ただし、ブリスク（翼と円盤が一体）では根元の摩擦がなく構造減衰がきわめて小さいため、構造減衰に頼れず、空力減衰そのものが正であることをすべてのモードで確かめる必要があります。
- 「進行波の乱れ $\mu$」を上げると、曲線の振れ幅が縮みます。これはミスチューニングの効果を振れ幅の縮小に置き換えた模式で、次の段落の話です。

## ミスチューニングは、フラッタには味方

[[link:mistuning|前の節]]では、翼ごとのわずかなばらつき（ミスチューニング）が強制振動の応答を増幅させる「困った性質」を見ました。ところがフラッタに対しては、同じミスチューニングが**味方**になります。

理由はこうです。負の空力減衰が働くのは、全翼がきれいな進行波で揃って動くときです。翼ごとに固有振動数が少しずつ違うと、きれいな進行波が組めず、揺れが一部の翼に局在します。すると「隣と決まった位相差で動くことで流れから仕事をもらう」仕組みが崩れ、最悪値が緩和されます。1980年代初頭の NASA ルイス研究センターの Kielb と Kaza の一連の研究は、解析した翼列モデルで「固有振動数のミスチューニングはフラッタの安定性を一貫して高めるが、強制応答には励起次数とマッハ数しだいで有益にも有害にもなる」ことを示し（これはそのモデルでの結論で、空力モデルやばらつきの量によっては一般化できません）、適度な**意図的ミスチューニング**（たとえば翼を交互に2種類の固有振動数で作る）が、シュラウドのない細長いターボファン翼のフラッタ対策として現実的だと結論づけました。後年の研究では「適度な量に最適値があり、多すぎると逆効果」という注意も加わっています。

ウェーブのたとえに戻せば、立つタイミングが人によってまちまちだと、波は途中で崩れて進めません。フラッタはきれいな波に乗って育つ現象なので、波が崩れることが幸いするのです。

強制応答には不利、フラッタには有利。翼のばらつきは、設計者にとって両刃の剣です。

## ロケットのターボポンプでは

ここまで読むと、ロケットエンジンのポンプを回すタービン翼で、フラッタの余裕が大きい**場合が多い**理由が見えてきます。翼は短く厚く（翼弦に対して翼長が短い）、[[link:blade-single|固有振動数は数 kHz]] と高い。つまり $k^{*}$ が大きくなりやすく、流れが仕事をする暇が少ない。ただしこれはロケットタービン一般の結論ではなく、実機の $k^{*}$、翼間位相角ごとの空力仕事、構造減衰で個別に判定するものです。この章の主役が一貫して「強制振動」と「[[link:zzenf-reading|ZZENF 線図]]」だったのは、そのためです。

ただし油断は禁物です。ポンプ側のインデューサでは、キャビテーションと翼の連成した自励振動が別の形で現れますし、タービンでも大きな迎え角で前縁に剥離が生じると、非定常の圧力分布が翼を不安定化する側に働くことが NASA の振動翼列実験で示されています。設計点から外れた部分負荷の運転では、この**ストールフラッタ**の芽を数字で確かめておく必要があります。「うちの翼は硬いから大丈夫」ではなく、「$k^{*}$ はいくつか」「構造減衰はいくつか」を数字で確かめるのが、専門家の作法です。

:::deep エネルギー法——1周期の仕事で安定を測る
翼の振動を $h(t) = \hat h\,\sin\omega t$（たわみ）とし、流れが翼に及ぼす非定常の力を $F(t) = \hat F \sin(\omega t + \psi)$ と置きます。1周期に流れが翼にする仕事は

$$W = \oint F\, dh = \pi\,\hat F\,\hat h\,\sin\psi$$

で、力が変位に対して進んでいれば（$0 < \psi < \pi$）正、遅れていれば負です。構造減衰が1周期に散逸するエネルギー $D = 2\pi\,\xi_s\,\omega^{2}\,m\,\hat h^{2}$（$m$ は等価質量）と比べ、$W > D$ なら振幅が育ちます。両辺を $\pi \omega^{2} m \hat h^{2}$ で割って整理すると、空力の効果は等価減衰比

$$\xi_\text{aero} = -\frac{W}{2\pi\,\omega^{2}\,m\,\hat h^{2}}$$

として、構造減衰と同じ土俵に乗ります。本文の $\xi_\text{total} = \xi_\text{aero} + \xi_s$ はこの意味です。

翼列では、翼間位相角 $\sigma$ ごとに流れ場が違うので $\hat F$ と $\psi$ も $\sigma$ の関数になり、$\xi_\text{aero}(\sigma)$ の曲線が得られます。線形化した非定常 CFD で「全翼を同じモード形・位相差 $\sigma$ で振動させたときの仕事」を計算するのが現代の標準手順で、$N$ 枚の翼なら $N$ 通りの $\sigma_n$ について評価すれば翼列全体の安定性が分かります（図の点がそれです）。
:::

## ひとことで

- フラッタは「叩く手」がなくても起きる揺れ。流れが返す力の位相がずれて、翼の速度と同じ向きの成分が残ると、ブランコを揺れに合わせて押すのと同じで、揺れが自分で育つ。
- 育つかどうかは、隣の翼とのタイミングのずれ（翼間位相角）と、流れが翼の動きに追いつけるか（無次元振動数）で決まる。長くて柔らかい翼に速い流れ、が最も危ない。
- 短く硬い翼は余裕が大きいことが多いが、「硬いから大丈夫」ではなく数字で確かめる。翼のばらつきは、強制振動には敵だがフラッタには味方。

**模式・出典について**：図の曲線 $\xi_\text{aero}(\sigma) = \xi_0 - A\cos(\sigma - \sigma_\text{min})$ と、$k^{*}$・ミスチューニングへの依存は、傾向を伝えるための模式です。「σ に対して正弦状」「k* が小さいほど危険側に寄る」「ミスチューニングが最悪値を緩和」の3点は下記の文献の定性的な傾向に沿わせた模式で、本文に書いたとおり実機では成り立たない条件もあります。係数は実機の値ではありません。
