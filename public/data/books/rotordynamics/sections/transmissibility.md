# 揺れを伝えない——外部加振と防振の√2

ここまでの主役は不釣り合い、つまり**自分の中にある加振**でした。この節では視点を切り替えます。**外から来る揺れ**——基礎や土台の振動、隣の機械の揺れ——から精密機器をどう守るか。そして裏返しに、機械が生む揺れを**床へ伝えない**にはどうするか。顕微鏡や半導体装置の除振台、エアコン室外機の下の防振ゴム。あれらは全部、この節の一枚のグラフで説明できます。

鍵になるのは**伝達率 T**——「入ってきた揺れ（または力）が、何倍になって向こう側へ伝わるか」です。これも [[r_ratio|回転数比 r]]（ここでは加振の振動数と[[omega_n|固有角振動数 ωn]]の比）と[[zeta|減衰比 ζ]]だけで決まります。

$$T(r) = \sqrt{\frac{1+(2\zeta r)^2}{(1-r^2)^2+(2\zeta r)^2}}$$

## √2 という境界線

グラフには不思議な一点があります。**r = √2 ≈ 1.41 で、どの ζ の曲線も必ず T = 1 を通る**のです。減衰がいくつであっても、です。そしてこの点より右（r > √2）では必ず T < 1——入ってきた揺れより伝わる揺れの方が小さい、**防振域**です。

これが防振ゴムの原理です。守りたい機械をやわらかいばねで支えて、**固有振動数を加振振動数の 1/√2 より下げる**。そうすれば揺れは向こう側へ届く前に目減りします。逆に、ばねが中途半端に硬いと r が 1 の近く——共振——に落ちて、揺れを**増幅する台**になってしまいます。「防振のつもりが加振」は、実際に起こる失敗です。

## 減衰のパラドックス

もうひとつ、直感に反する事実があります。防振域（r > √2）では、**減衰 ζ を増やすと伝達はかえって悪化する**のです。上のグラフで r = 2 あたりにカーソルを置いて ζ を上げてみてください。曲線が持ち上がり、T がじわじわ 1 へ近づきます。

理由はこう考えられます。速い揺れに対して、ばねは「柔らかく受け流す」ことで機械を切り離しています。ところがダンパは速度に比例して力を出すので、速い揺れほど**硬い棒のように両側をつないでしまう**。切り離したいのに握手してしまうわけです。

では減衰はゼロがよいか——というと、そうもいきません。機械の起動・停止のたびに、運転点は r = 0 から共振（r = 1）を**通過**します。減衰がなければ通過時に大暴れします（[[link:natural-frequency|危険速度の節]]で見た、あの鋭い山です）。だから実際の防振設計は「**通過をしのげる程度の減衰は入れつつ、定常運転では小さめに**」という妥協点を探します。

:::deep 式の導出の要点と、「力」と「変位」が同じ式になる話
床が $y = Y\cos\Omega t$ で揺れるとき、ばね・ダンパで支えられた機械（変位 $x$）の運動方程式は

$$m\ddot x + c(\dot x - \dot y) + k(x - y) = 0$$

定常応答の振幅比をとると $|X/Y| = \sqrt{k^2+(c\Omega)^2}/\sqrt{(k-m\Omega^2)^2+(c\Omega)^2}$。分母・分子を $k$ で割り、$r=\Omega/\omega_n$、$2\zeta r = c\Omega/k$ と置き直すと本文の $T(r)$ になります。これが**変位伝達率**（床→機械）。

一方、機械自身が力 $F_0\cos\Omega t$ で揺れているとき、床へ伝わる力はばねとダンパ経由の $F_T = kx + c\dot x$ です。応答 $x$ を代入して振幅比 $|F_T/F_0|$ を計算すると、**まったく同じ式**が出てきます。これが**力伝達率**（機械→床）。「外の揺れから守る」も「自分の揺れを外に漏らさない」も、同じ一枚のグラフで足りるのはこのためです。

√2 の出どころも単純で、$T=1$ とおくと $(2\zeta r)^2$ が両辺から消え、$(1-r^2)^2 = 1$、すなわち $r^2 = 2$。減衰の項が**きれいに相殺する**ので、交点は ζ によらないのです。
:::

なお、伝わる揺れの「大きさ」だけでなく「向き（遅れ）」も r とともに変わります。その話は[[link:phase-lag|位相の節]]で見たS字カーブと同じ仕組みです。

**模式・出典について**：グラフは1自由度系の伝達率 $T(r)=\sqrt{1+(2\zeta r)^2}/\sqrt{(1-r^2)^2+(2\zeta r)^2}$ をそのまま描いたもので、値に脚色はありません。r=√2 で T=1、防振域で ∂T/∂ζ > 0 であることは数値的にも確認済みです。防振設計の実務では、ここで扱わなかった質量の効果（除振台の重さ）や複数方向の揺れも考えます。
