# 揺れを減らす——減衰とダンパ

ブランコを一度だけ押して手を離すと、揺れはだんだん小さくなって止まります。空気の抵抗、ロープのこすれ、座板のきしみ——揺れのエネルギーを少しずつ熱に変える働きを、この本では[[zeta|減衰]]と呼んできました。翼も同じです。ただし翼の減衰は、ブランコよりずっと小さい。金属の塊そのものはほとんどエネルギーを失わず、しかも翼は真空に近い薄い気体の中を高速で切っていく。[[link:zzenf-reading|ZZENF線図]]でどうしても避けられない共振が運転範囲に残ったとき、翼の寿命を決めるのは、**この小さな減衰をどれだけ正確に知っているか、そしてどれだけ作り足せるか**です。

## 共振の高さを決めるのは減衰だけ

[[link:natural-frequency|第1章]]で見た1自由度の応答を思い出してください。共振のど真ん中では、振幅は静的なたわみの $1/(2\zeta)$ 倍になります。この倍率を **Q 値**（[[Q|Q]]）と呼びます。

$$Q = \frac{1}{2\zeta}$$

減衰比 $\zeta$ が 0.5% なら $Q = 100$。つまり共振では、同じ力で静かに押したときの **100 倍** 揺れます。$\zeta$ が 0.1% なら 500 倍。翼の減衰はこの程度の小ささなので、共振を踏んだときの振幅は、減衰の見積もりが 2 倍違うだけで 2 倍違います。[[link:transmissibility|伝達率の節]]で「共振の近くでは減衰がすべて」と書いたのは、翼ではなおさら切実です。

翼の減衰には、大きく3つの源があります。

- **材料減衰**：金属の内部摩擦。ニッケル基超合金では極めて小さく、単体の翼を真空中で鳴らすと $\zeta$ は 0.1% を切ることも珍しくありません。
- **空力減衰**：翼が揺れると周囲の気流が反力を返し、その一部が速度に比例する減衰として働きます。流れの密度と速度が高いほど大きく、ガスタービンの圧縮機ではしばしば主役になります。ただし条件によっては**負**になり、それが[[link:flutter|フラッタ]]です。
- **摩擦減衰**：翼の根元（ダブテール）、シュラウドの接触面、プラットフォーム間のダンパなど、**接触面の微小な滑り**がエネルギーを熱に変えます。差し込み翼の減衰の大半はここから来ます。

実測では、実機のタービン翼のモードの $Q$ は 100〜400 程度が「典型」だと、翼振動監視の特許文献（EPRI, US 5,471,880）は述べています（$\zeta$ にして 0.1〜0.5%）。回転中の翼付き円盤で測った例では、減衰比は振幅とともに増え、しかも翼ごとに大きく散らばることが報告されています。一方、翼と円盤を一体にした **ブリスク** には摩擦面がないので、構造減衰は極端に小さく、空力減衰が頼みになります。ロケットターボポンプのタービンは翼が小さく剛性が高いうえ、作動流体（水素リッチガスなど）の条件も特殊で、空力減衰を当てにしにくい——だから「**減衰を作り足す**」設計が重要になります。

## 減衰を作り足す道具たち

翼に減衰を足す道具は、どれも「**接触面をこすらせる**」か「**翼どうしをつないで形を変える**」かのどちらかです。

- **シュラウド（tip shroud / part-span shroud）**：翼先端や中間高さで隣の翼とつなぐ覆い。隣とつながることでモード形が変わり（[[link:mistuning|前節]]の「結合 κc」が上がる）、接触面の滑りが減衰を生みます。
- **レーシングワイヤ・タイボス**：翼の途中に通す針金や突起で隣とつなぐ。古典的な蒸気タービンの長翼で多用されました。
- **アンダープラットフォームダンパ（under-platform damper）**：翼の付け根（プラットフォーム）の下に小さな金属片を置き、遠心力で隣り合う2枚のプラットフォームに押し付けます。翼が揺れると、ダンパとプラットフォームの間に微小な滑りが起き、摩擦でエネルギーを吸います。ガスタービンの動翼で最も一般的な摩擦ダンパです。
- **ダンパピン・ダンパワイヤ**：プラットフォームの隙間や翼の内部に入れた棒や線。原理は同じで、遠心力で押し付けられた接触面の滑りです。
- **リングダンパ（ブリスク用）**：ブリスクには翼どうしの接触面がないので、円盤の裏側の溝に**輪**を入れ、遠心力で溝の壁に押し付けて、円盤とのこすれで減衰を得ます。もともとラビリンスシールや歯車で使われていた発想が、ブリスクに転用されました。

どの道具も、押し付け力は**遠心力**で決まります。ここに落とし穴があります。回転数が上がると押し付けが強くなり、ある点を超えると**滑らなくなる**。滑らないダンパは、ただの硬い部品です。

## 摩擦ダンパは「押し付けすぎ」が効かない

摩擦ダンパの振る舞いを最初に設計の言葉で整理したのが J. H. Griffin（1980）です。翼を1自由度のばね・質量とし、そこに「ばねと直列のクーロン摩擦要素」としてダンパを付けると、押し付け力 $N$ に対して共振振幅が**谷の形**になることを示しました。

下のブロックはその最小モデルです。左は、翼の変位に対してダンパが返す力を描いた**ヒステリシス・ループ**。ループが囲む面積が1往復でダンパが吸う仕事です。右は、押し付け力を 0 から増やしたときの共振振幅で、最適点に印をつけてあります。

}
:::

読み方のポイントを3つ。

- **押し付けが弱い**（左端）：摩擦力 $\mu N$ が小さく、ループは薄い。よく滑るが、吸える仕事はわずか。
- **最適付近**：ループが最も太る。1往復あたりの散逸 $E = 4\mu N(X - \mu N/k_d)$ が最大になる点で、共振振幅は最も小さい。
- **押し付けすぎ**（右側）：滑り出すのに必要な変位 $\mu N/k_d$ が振幅 $X$ を超えると、ダンパは一度も滑らない。ループは直線になり、散逸はゼロ。翼はダンパの分だけ硬くなるだけで、減衰は元の小ささに戻ります。これが **ロックアップ（固着）** です。

励振力 $F$ を動かすと、最適な押し付け力も動きます。つまり摩擦ダンパは「この運転条件・この励起の強さ」に合わせて設計する部品で、条件が変われば最適から外れます。しかも押し付け力は遠心力なので回転数の2乗で増える。低回転で効いていたダンパが、高回転では固着する——実機で実際に起きたことです。

:::history SSME 高圧燃料ターボポンプの翼が折れた
スペースシャトル主エンジン（SSME）の開発初期、1977年11月17日と12月1日のわずか2週間の間に、高圧燃料ターボポンプ（HPFTP）の第1段タービン翼が折れる事故が2件続けて起きました。1件目はエンジン 0002 の試験で、推力 70% の運転中に翼が1枚折れて両段のタービンを損傷。2件目はエンジン 0103 で 80% を少し超えたところで発生し、破片でロータが固着、燃料が止まって酸素過多の燃焼になり、高温ガス系が広く焼けました（エンジン外への貫通はなし）。

この HPFTP のタービンは、第1段が 41 枚の静翼（ノズル）と 63 枚の動翼、第2段が 39 枚の静翼と 59 枚の動翼——枚数をわざと互いに違えて共振の重なりを避けていました。翼は長さ約 1 インチ、幅約 0.5 インチ。1枚あたり約 600 馬力を出し、曲げ応力と遠心応力がそれぞれ約 50,000 psi（約 345 MPa）、温度は約 2,000 °R（約 1,100 K）、しかも無冷却。翼の間には「ダンパ」と呼ばれる小さなばね状の部品が挟まっていました。

Rocketdyne、GE、TRW、AiResearch を巻き込む総合試験が組まれ、翼を最高 38,000 rpm まで回しながらひずみゲージで応力を測る「ワーリギグ」と呼ばれる回転試験機で、各種ダンパの効きを評価しました。結論は、**疲労破壊の原因は翼の固着（ロックアップ）**であること、そして試験したダンパ構成はいずれも翼の有害な振動モードを下げる効きを持つこと。軽量で精密公差の新ダンパが選ばれ、円盤との間や翼どうしのロックアップを防ぐ設計変更と、組立時に「ゆるみ」を確認する手順が追加されました。

1985年の NASA Marshall の技術会議では、Dayton 大学の R. J. Dominic がこの第1段翼の摩擦ダンパを集中定数モデルで解析し、ダンパの性能を決める主因が**摩擦係数・接触面の垂直力・励振力の大きさ・隣の翼との位相差・材料のヒステリシス減衰**であること、さらに**高回転では遠心力がダンパを過剰に押し付けて翼をプラットフォームで固着させ、翼だけの軽い共振を残す**ことを示しました。スピンピット試験でも、量産ダンパ付きの翼にだけ「翼部だけの共振」が現れ、軽い試作ダンパでは現れなかった——まさに上のブロックの「押し付けすぎ」の実例です。

その後の代替ターボポンプ（HPFTP/AT）でも、燃焼試験の初期に翼の疲労亀裂が出ました。Pratt & Whitney は隣り合うプラットフォームの隙間に薄い Haynes 188 の板を差し込む「フェザーシール・ダンパ」を設計し、隙間を塞いで効率と熱環境を改善しながら微小滑りで減衰を得る方式に変えました。36,000 rpm の回転試験で最初の2つの共振モードが消え、その後は疲労亀裂が報告されていません。
:::

## 減衰は「作る」だけでなく「測る」もの

ダンパで減衰を足しても、設計で使う $\zeta$ の値は**測って確かめる**必要があります。理由は2つあります。

第一に、摩擦減衰は**振幅に依存**します。小さな振幅では滑らず、大きな振幅ではよく滑る。つまり減衰比が一定ではなく、共振の山の形も線形系の形から崩れます（山の頂上が振幅によって左右に傾く）。小さな加振力でハンマリング試験をしても、実運転の振幅での減衰は分かりません。

第二に、減衰は**個体差が大きい**。接触面の状態、組付けのわずかな差、表面の摩耗で変わります。測定値はつねに散らばる、という前提で設計に余裕を持たせます。

:::field 減衰の測り方と、設計で使う値の決め方
- **半値幅法**：周波数応答の山の高さが $1/\sqrt{2}$ になる幅 $\Delta f$ から $\zeta = \Delta f/(2 f_n)$。簡便だが、山が歪む非線形な摩擦減衰には注意。
- **自由減衰（対数減衰率）**：叩いて放したあとの波形の減り方から。振幅に依存する減衰なら、振幅ごとに値が変わることがそのまま見える。
- **真空と大気の比較**：真空中で測った減衰（材料＋構造）と大気中（＋空力）の差から空力減衰を分離する。回転試験機（スピンリグ）で回転中に測れば、遠心力でダンパが押し付けられた実条件の値になる。
- **設計値の置き方**：解析の減衰は「測定の下限側」を使う。ミスチューニングの増幅率（[[link:mistuning|前節]]）は減衰が小さいほど大きいので、減衰を楽観すると二重に危険側になる。
- **ブリスクの場合**：摩擦面がない前提で、空力減衰をCFDや翼列試験で見積もり、不足ならリングダンパ等を追加する。
:::

:::deep 調和バランスで摩擦ダンパを解く
翼を無次元化（質量 1、剛性 1、固有角振動数 1）し、ダンパをばね $k_d$ と直列のクーロン摩擦要素（滑り出す力 $\mu N$）とします。翼が $x = X\cos\omega t$ で揺れるとき、ダンパが滑り出す変位は $d = \mu N / k_d$ です。

**$X \le d$（固着）**：ダンパはばね $k_d$ そのもの。散逸 0、剛性が $1 + k_d$ に上がるだけ。

**$X > d$（滑り）**：力と変位の関係は平行四辺形のヒステリシスを描き、1サイクルの散逸は

$$E = 4\mu N\,(X - d)$$

です。これを粘性減衰で置き換えると、1サイクルの散逸 $\pi c_{eq}\omega X^2$ と等しいとして

$$c_{eq}\,\omega = \frac{4\mu N (X - d)}{\pi X^2}$$

また、ヒステリシスの1次成分（変位と同位相の分）が等価剛性を与えます。$\cos\theta = 1 - 2d/X$ と置くと

$$k_{eq} = \frac{k_d}{\pi}\left(\theta - \sin\theta\cos\theta\right)$$

で、$X = d$ で $k_d$、$X \to \infty$ で 0 に向かいます（よく滑るほど、ばねとして効かなくなる）。

共振振幅は**エネルギー収支**から直接求まります。共振では励振力と速度が同位相なので、1サイクルに外力がする仕事は $\pi F X$。これが粘性減衰の散逸 $2\pi\zeta\omega_r X^2$ とダンパの散逸 $4\mu N(X - d)$ の和に等しいと置くと

$$2\zeta\omega_r X^2 + \left(\frac{4\mu N}{\pi} - F\right)X - \frac{4\mu N d}{\pi} = 0$$

という $X$ の2次方程式になり、正の根が共振振幅です（$\omega_r = \sqrt{1 + k_{eq}(X)}$ は数回の反復で合わせます）。ダンパなしの共振振幅 $F/(2\zeta\sqrt{1+k_d})$ が $d$ 以下なら固着で、ダンパは減衰に寄与しません。押し付け力 $N$ を変えると $d$ と $\mu N$ が同時に変わるので、散逸 $E$ は $N$ について**上に凸**——これが最適点の正体です。$E$ を $N$ で微分して 0 と置くと、振幅が固定なら $\mu N_{opt} = k_d X/2$、すなわち「滑り出す変位がちょうど振幅の半分」のときに最も吸うことが分かります。
:::

共振を避けきれないとき、減衰は翼を守る最後の砦です。しかし減衰を足しても、翼は**平均応力（遠心力）の上に振動応力が乗る**という条件で何億回も繰り返し荷重を受けます。どこまでの振動応力なら「永遠に」耐えられるのか——それを決めるのが[[link:blade-hcf|次節]]の Goodman 線図です。
