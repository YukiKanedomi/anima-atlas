# 分解能と平均化——細かさも静けさも、時間で買う

スペクトルの実務で必ずぶつかる2つの悩みがあります。**「近い2つの山が分かれて見えない」**と**「ノイズがざらざらで小さな山が読めない」**。どちらの答えも、実は同じ通貨で支払います——**時間**です。

たとえば運転中の機械で、1×（回転数）のすぐ隣に別の山がいるかもしれない、という場面を考えます。8 Hz と 8.75 Hz——これを見分けられるでしょうか。

## 目盛りの細かさは Δf = 1/T

FFTの周波数軸は、連続ではなく**とびとびの目盛り**です。その間隔は

$$\Delta f = \frac{1}{T}$$

——**記録した時間 T の逆数**。1秒の記録なら1 Hz刻み、4秒なら0.25 Hz刻み。8 Hz と 8.75 Hz（差0.75 Hz）を割るには、この例ではおよそ4秒の記録が必要でした。

直感的には、**2つの波の「ずれ」が見えるまで待つ**必要があるからです。8 Hz と 8.75 Hz は、1秒ではまだ位相が3/4周ずれただけ。差がはっきり積み上がるまで記録を続けて、はじめて別の波だと分かる——細かさは時間でしか買えません。

なお、ブロックをよく見ると**Δf ぎりぎりでは足りない**ことにも気づきます（2秒＝Δf 0.5 Hz でもまだ1山）。前節の窓（Hann）が山を約2目盛りぶんに太らせるためで、実務では「見たい差の2〜3倍細かい Δf」が目安です。

## ノイズは平均でならす

記録を長くしても、ノイズの**ざらざら**は消えません。そこで**平均**の出番です。スペクトルを何枚も撮って重ね合わせると、成分の山は毎回同じ場所に立つので残り、ノイズのでこぼこはランダムなので**ならされて**いきます。荒れの目安は

$$\text{ざらつき} \propto \frac{1}{\sqrt{M}} \quad (M = \text{平均回数})$$

4回平均で半分、16回で1/4。ただし M 回撮るには M 倍の時間がかかる——ここでも支払いは時間です。**細かさ（T）も静けさ（M）も時間で買う**。現場で「計測にどれだけ回せるか」を決めるのは、いつもこの取引です。

:::deep 平均の流儀と、上限の話
- **何を平均するか**：ここで平均しているのは振幅（パワー）スペクトルです。位相を捨てて重ねるので、非同期のノイズも「床」として残ります（床が**滑らかになる**のであって、下がるわけではありません）。位相ごと平均して非同期成分を**消す**方法は、次節の回転同期平均で扱います。
- **オーバーラップ平均**：記録を50%ずつ重ねて窓を掛けると、同じ長さの記録から約2倍の平均回数が取れます（Welch法）。Hann窓と相性がよく、実務の定番です。
- **サンプリング速度の役割**：$f_s$ を上げて伸びるのは**測れる上限**（$f_s/2$、[[link:aliasing|エイリアシング]]の節）で、目盛りの細かさではありません。「上限は $f_s$、細かさは $T$」と役割がきれいに分かれています。
:::

**模式・出典について**：スペクトルは本物のFFT（Hann窓・振幅平均）です。T=0.5〜2秒で1山に融合し4秒で2山に分解すること、ノイズ床の荒れが平均回数とともに $1/\sqrt{M}$ で縮むことを独立検証済み。ノイズは再現性のため乱数の種を固定しています。
