# スペクトル——振動を周波数に分解して原因を知る

現場でロータの振動を測ると、たいてい波形は**ごちゃっと**しています。いくつもの原因が同時に揺らしているからです。そのままでは何が起きているか分かりません。ところがベテランの診断技術者は、その横でたった1枚のグラフを見て「これは不釣り合いですね」「軸心がずれていますね」と言い当てます。魔法ではありません。**スペクトル**を読んでいるのです。

[[link:fourier-synthesis|フーリエの目の章]]で見るとおり、どんな波も正弦波の**足し算**でできています。**FFT（高速フーリエ変換）** はその足し算を逆にほどいて、「どの周波数の成分がどれだけ含まれているか」を取り出す道具。この節では仕組みには深入りせず、それが**診断でどう効くか**を先に体験します。

## ピークの「住所」が犯人を指す

回転機械のスペクトルは、横軸を Hz ではなく「回転数の何倍か」＝**次数**で読みます。基準は [[order_1x|1×]]（回転と同じ速さ）。ピークの位置が、そのまま原因の候補を教えてくれます。

- **1×**（回転数と同じ）→ **不釣り合い**。いちばん基本。
- **2×**（回転数の2倍）→ **ミスアライメント**（軸心のずれ）など。
- **0.43〜0.48×**（回転数より遅い分数調波）→ **オイルホワール**（流体軸受の不安定）。

振動の**大きさ**（[[rms|実効値]]などで測ります）は「どれだけ悪いか」を教えますが、それだけでは誰が悪いのかは分かりません。**周波数は犯人の指紋**——位置が原因を、高さが深刻さを語る。この分業がスペクトル診断の骨格です。

## 回転より遅い揺れは、別格の警報

なかでも特別なのが3つ目です。0.43× のスライダーだけ上げてみてください。時間波形に**回転より遅いうねり**が現れ、スペクトルでは 1× の**左側**にピークが立ちます。

1× や 2× は、不釣り合いやずれに回転が**叩かれて**揺れる、いわば行儀のよい揺れです。ところが回転数より**遅い**ピークは、回転に同期した力では説明がつきません。その正体は、外から叩かれなくても勝手に育つ[[link:whirl-instability|油膜の自励不安定（オイルホワール）]]——「1×より低い位置のピーク」は、大きさによらず存在するだけで警戒すべきサインです。

## ここから「診断の実戦」へ

スペクトルが読めると、たった1枚のグラフから「不釣り合いか、ミスアライメントか、不安定か」の切り分けが始められます。ここが**ロータ診断の実戦の入口**です。この先は2つの道に分かれます。

- **仕組みを知る**：なぜ波を周波数に分解できるのか、そして計測にはどんな罠（[[link:aliasing|エイリアシング]]や窓の切り取り）があるのか——[[link:fourier-synthesis|フーリエの目の章]]で。
- **読み方を鍛える**：回転数が変わる実機でピークをどう追うか（[[link:order-reading|次数の読み方]]）、昇速の全体を1枚で見る[[link:waterfall|ウォーターフォール線図]]へ。

:::deep この図の中身——本物のFFTであること
上のブロックは、各成分 $a_i\sin(2\pi f_i t)$ を足し合わせた信号に **Hann窓** をかけ、**Cooley–Tukey FFT** を実際に計算して描いています。お約束の絵を貼っているのではありません。

- **窓をかける理由**：信号は有限の長さで切り取るしかなく、切り口の不連続がスペクトルのすそ野を汚します（リーケージ）。Hann窓は切り口をなめらかに絞って、これを抑えます。詳しくは[[link:leakage|窓とリーケージの節]]で。
- **横軸が次数の理由**：Hz のままだと、回転数が変わるたびに犯人の住所が動いてしまいます。回転数を 1 とする物差しで測れば、不釣り合いはいつも 1× に立つ——回転機械ならではの読み方です。
- ピークの**位置**と**相対的な高さ**は計算どおりですが、縦軸のスケールは見やすさのために正規化しています。
:::

**模式・出典について**：図は各成分 $a_i\sin(2\pi f_i t)$ を足した信号に **Hann窓** をかけ、**実際に Cooley–Tukey FFT** を計算して描いています。横軸は次数（基本回転数の倍数）、ピーク位置と相対的な高さは計算どおりです。「1×＝不釣り合い、2×＝ミスアライメント、分数調波＝オイルホワール」という対応は、振動診断の標準的な経験則の代表例で、実際の切り分けでは位相や運転条件もあわせて確認します。
