# スペクトル——振動を周波数に分解して原因を知る

![携帯型の振動計の画面：上に時間波形、下にスペクトル](data/books/rotordynamics/images/spectrum-1.jpg "写真：携帯型の振動計・バランサの画面。上段が 2 チャンネルの時間波形、下段がその FFT スペクトル。回転数の整数倍の位置に目印が付いている。（Wikimedia Commons, NotecA, CC BY-SA 4.0）"){right}

工場の送風機の軸受箱に加速度計を当てて波形を見ると、たいてい**ごちゃっと**しています。いくつもの原因が同時に揺らしているからです。そのままでは何が起きているか分かりません。ところがベテランの診断技術者は、その横でたった1枚のグラフを見て「これは不釣り合いですね」「軸心がずれていますね」と言い当てます。魔法ではありません。**スペクトル**を読んでいるのです。

[[link:fourier-synthesis|フーリエの目の章]]で見るとおり、どんな波も正弦波の**足し算**でできています。**FFT（高速フーリエ変換）** はその足し算を逆にほどいて、「どの周波数の成分がどれだけ含まれているか」を取り出す道具。この節では仕組みには深入りせず、それが**診断でどう効くか**を先に体験します。測る道具は[[link:sensors|センサの節]]、読む手順は[[link:fault-signatures|故障の指紋の節]]へ続きます。

## ピークの「住所」が犯人を指す

回転機械のスペクトルは、横軸を Hz ではなく「回転数の何倍か」＝**次数**で読みます。基準は [[order_1x|1×]]（回転と同じ速さ）。ピークの位置が、そのまま原因の候補を教えてくれます。

- **1×**（回転数と同じ）→ **不釣り合い**。いちばん基本。
- **2×**（回転数の2倍）→ **ミスアライメント**（軸心のずれ）など。
- **0.43〜0.48×**（回転数より遅い分数調波）→ **オイルホワール**（流体軸受の不安定）。

振動の**大きさ**（[[rms|実効値]]などで測ります）は「どれだけ悪いか」の手がかりですが、それだけでは誰が悪いのかは分かりません。**周波数は犯人の指紋**。位置が原因を、高さが深刻さの傾向を語る。この分業がスペクトル診断の骨格です。ただし高さは、センサの種類と単位、測定点、周波数帯、途中の構造の共振で大きく変わります。「高さで深刻さを比べる」のは、同じ機械を同じ点・同じ条件で測った記録どうしの話で、上の部品のように縦軸を見やすく正規化した図では、ピークの相対的な高さしか比べられません。

:::analogy @fingerprint 指紋は本人を、傷の深さは重さを
事件の現場に残った指紋は「誰か」を教えてくれますが、「どれだけひどいか」は教えてくれません。それは別の証拠から読みます。スペクトルも同じで、ピークの**位置**（次数）が誰の仕業かを、ピークの**高さ**がどれだけ悪いかの傾向を、別々に教えます。片方だけ見ていると、「大きいけれど無害な 1×」と「小さいけれど危険な 0.45×」を取り違えます。限界：指紋は一人に一つですが、同じ次数に複数の原因が重なることがあり（たとえば 1× には不釣り合いも軸の曲がりも立つ）、最後は位相や運転条件で切り分けます。高さも、同じ条件で測った記録どうしでしか比べられません。
:::

## 回転より遅い揺れは、別格の警報

なかでも特別なのが3つ目です。0.43× のスライダーだけ上げてみてください。時間波形に**回転より遅いうねり**が現れ、スペクトルでは 1× の**左側**にピークが立ちます。

1× や 2× は、不釣り合いやずれに回転が**叩かれて**揺れる、いわば行儀のよい揺れです。ところが回転数より**遅い**ピークは、回転に同期した力の素直な応答では説明がつきません。有力な候補の一つが、外から叩かれなくても勝手に育つ[[link:whirl-instability|油膜の自励不安定（オイルホワール）]]。ただし 1× より低い位置には、ラビング（接触）や緩みのような非線形な応答が作る 1/2× や 1/3×、回転数のゆらぎ、解析上の見かけの成分も立ちます。だから「1× より低い位置のピーク」は、大きさによらず**原因を突き止めるまで放置しない**サインであって、見つけた時点で自励と決めつける印ではありません。

## 読む順番——五つの問い

スペクトルを前にしたら、どこから見るかの順番を決めておくと迷いません。診断の現場で広く使われる手順を、五つの問いにまとめます。

1. **いまの回転数はいくつか。** キーフェイザか回転計で確かめ、1× の位置に目印を置く。これをしないと、どのピークが何次か分からない。
2. **1× の整数倍はどこに立つか。** 2×、3× と並ぶ列（**高調波**）は、ずれ・緩み・ぶつかりなど、回転のたびに「かど」のある力が働いている印。
3. **1× より左に何かあるか。** 分数調波は自励かラビングか緩みか。存在そのものが「調べよ」の警報。
4. **高いところに山はないか。** ここは三種類に分けて見る。まず翼の通過（翼枚数 × 回転数）や歯車のかみ合い（歯数 × 回転数）のような**高い整数次**。次に転がり軸受の損傷周波数のように回転数に比例するが**整数にならない次数**。最後に電源周波数の 2 倍のように**回転数と無関係な固定の Hz**。どれも計算で住所の予想が立ち、回転数を変えたときに一緒に動くかどうかで三種類を見分けられる。
5. **大きな山の両脇に、等間隔の小さな山（側帯波）はないか。** かみ合い周波数の両脇に回転数の間隔で並ぶ側帯波は、歯車の偏心や歯の欠けのように「かみ合いが 1 回転ごとに強弱する」印。

この五つの問いに「はい」と答えた場所ごとに、原因の候補が絞られます。候補ごとのスペクトルの形は[[link:fault-signatures|故障の指紋の節]]でまとめて見ます。

:::analogy @piano 和音を聞き分ける耳
ピアノで「ド・ミ・ソ」を同時に弾くと、慣れない耳には一つの音に聞こえますが、音楽家は三つの音を聞き分けます。さらに「どの音が大きいか」「濁った音が混じっていないか」も分かる。スペクトルを読むとは、機械の出す和音を鍵盤の上に並べ直して、どの鍵が押されているかを見ることです。1× は根音、2× や 3× は倍音、分数調波は楽譜にない音です。限界：ピアノの鍵は決まった高さですが、機械の「鍵盤」の多くは回転数で伸び縮みするので、回転に付いてくる成分は次数に直して読みます。一方で固有振動数や電源周波数のように Hz で固定された成分は、次数に直すとかえって動いて見えるので、Hz の目盛も捨てずに両方を使い分けます。
:::

## 読み解きの例——言葉で追う

数字は模式ですが、読む流れを一度通しておきます。毎分 3,000 回転（50 Hz）の電動機で直結のポンプを回している機械で、軸受箱の振動速度が増えてきたとします。スペクトルを撮ると、50 Hz（1×）に大きな山、100 Hz（2×）にその半分ほどの山、そして 100 Hz のすぐ近くに別の鋭い山が立っていた、という場面を考えます。

まず 1× の山は不釣り合いの候補ですが、1× だけなら「大きさはどうか」を規格のゾーンで見ればよい。2× が目立つなら、電動機とポンプの軸心のずれを疑います。問題は 100 Hz のそばの鋭い山で、50 Hz 電源の国では**電源周波数の 2 倍**がちょうど 100 Hz に来ます。電動機の中で固定子と回転子を引き合わせる磁気の力は磁束の 2 乗に比例するので、電源周波数で振動する磁束からは必ずその 2 倍の周波数の力が出ます。健全な機械でも小さく存在し、固定子と回転子のすきまにむらがあると、この力が偏って大きくなります。2× と電源 2 倍は紙一重の位置にあり、[[link:resolution|分解能]]を上げるか、電源を切った瞬間に消えるかどうかで切り分けます。この例が教えるのは、スペクトルは「山の住所を候補に変換する」道具であって、最後の一手は運転条件を変えて確かめることだ、という点です。

:::field 時間波形を捨てない
スペクトルは便利ですが、時間波形を見ずに判断すると落とし穴があります。たとえば 1 回転に 1 回「コツン」と当たるラビング（接触）は、スペクトルでは 1× とその高調波の列になり、ずれや緩みと区別がつきません。時間波形を見れば、波の頂上が平らに潰れていたり、一瞬のとがりが周期的に入っていたりと、「当たっている」形が直接見えます。歯車の欠けや軸受の傷も、時間波形の中の周期的な衝撃として先に見つかることがあります。スペクトルを撮ったら、必ず同じ記録の時間波形を一度は眺める。順番は、波形で形を見て、スペクトルで住所を確かめる、です。
:::

:::history 掃引からフィルタの束へ、そして FFT へ
計算機で FFT を回せるようになる前、スペクトルは電気の回路で取っていました。一つは周波数を少しずつ変えながら狭い帯域のフィルタを通す**掃引型**で、一回の測定に時間がかかり、昇速中のように変わり続ける信号には向きません。もう一つは周波数ごとに並べた多数のフィルタの出力を同時に表示する**フィルタバンク型**（リアルタイムアナライザ）で、音声の研究などで使われ、結果は紙に焼き付けて記録していました。1965 年に Cooley と Tukey が高速フーリエ変換のアルゴリズムを発表し（[[link:fourier-synthesis|フーリエの目の章]]）、1970 年代にはそれを組み込んだ FFT アナライザが現場に入ります。いま携帯型の振動計が一瞬でスペクトルを出せるのは、この半世紀の積み重ねの上にあります。
:::

## ここから「診断の実戦」へ

スペクトルが読めると、たった1枚のグラフから「不釣り合いか、ミスアライメントか、不安定か」の切り分けが始められます。ここが**ロータ診断の実戦の入口**です。この先は三つの道に分かれます。

- **仕組みを知る**：なぜ波を周波数に分解できるのか、そして計測にはどんな罠（[[link:aliasing|エイリアシング]]や窓の切り取り）があるのか。[[link:fourier-synthesis|フーリエの目の章]]で。
- **読み方を鍛える**：回転数が変わる実機でピークをどう追うか（[[link:order-reading|次数の読み方]]）、昇速の全体を1枚で見る[[link:waterfall|ウォーターフォール線図]]へ。
- **候補を覚える**：故障の種類ごとのスペクトルの形を[[link:fault-signatures|故障の指紋の節]]で一覧する。

:::deep この図の中身——本物のFFTであること
上のブロックは、各成分 $a_i\sin(2\pi f_i t)$ を足し合わせた信号に **Hann窓** をかけ、**Cooley–Tukey FFT** を実際に計算して描いています。お約束の絵を貼っているのではありません。

- **窓をかける理由**：信号は有限の長さで切り取るしかなく、切り口の不連続がスペクトルのすそ野を汚します（リーケージ）。Hann窓は切り口をなめらかに絞って、これを抑えます。詳しくは[[link:leakage|窓とリーケージの節]]で。
- **横軸が次数の理由**：Hz のままだと、回転数が変わるたびに犯人の住所が動いてしまいます。回転数を 1 とする物差しで測れば、不釣り合いはいつも 1× に立つ。回転機械ならではの読み方です。
- ピークの**位置**と**相対的な高さ**は計算どおりですが、縦軸のスケールは見やすさのために正規化しています。
:::

## ひとことで

- 時間波形では原因が混ざるが、スペクトルでは周波数の住所ごとに分かれて立つ。位置が原因を、高さが（同じ条件で測った記録どうしなら）深刻さの傾向を語る。
- 回転機械では回転に付いてくる成分を次数（回転数の何倍か）で読み、固定 Hz の成分は Hz で読む。1× は不釣り合い、2× はずれなど、分数調波は自励やラビングを疑う警報。
- 読む順番は、回転数の確認、高調波の列、1× より左、高い整数次・非整数次・固定 Hz の山、側帯波の五つ。
- スペクトルは候補を絞る道具で、決め手は運転条件を変えた確認と時間波形。

**模式・出典について**：図は各成分 $a_i\sin(2\pi f_i t)$ を足した信号に **Hann窓** をかけ、**実際に Cooley–Tukey FFT** を計算して描いています。横軸は次数（基本回転数の倍数）、ピーク位置と相対的な高さは計算どおりです。「1×＝不釣り合い、2×＝ミスアライメント、分数調波＝オイルホワール」という対応は、振動診断の標準的な経験則の代表例で、実際の切り分けでは位相や運転条件もあわせて確認します。部品の縦軸は最大ピークに合わせて正規化しているので、ピークの絶対的な高さや、設定を変えた前後の高さの比較はできません。読み解きの例の数値は説明のための模式で、特定の機械の実測ではありません。電源周波数の 2 倍の電磁加振は電動機の診断で広く知られた現象ですが、ここでは原理の説明にとどめ、数値は示していません。Cooley と Tukey の 1965 年は Wikipedia「Cooley–Tukey FFT algorithm」、フィルタバンク型のアナライザが計算機以前の方法だったことは Wikipedia「Spectrogram」によります。写真の携帯型振動計の画面は Commons の CC BY-SA 4.0、Convair の分析装置はサンディエゴ航空宇宙博物館アーカイブのパブリックドメイン写真で、年代は記載されていません。
